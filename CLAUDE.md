# CLAUDE.md

This directory holds the projects for a tutorial I'm creating.

Each project lives in its own subdirectory here, so expect this repo to grow
into a collection of independent project folders rather than a single codebase.

## Layout

```
.
├── CLAUDE.md          # this file
├── <project-1>/       # one subdirectory per tutorial project
├── <project-2>/
└── ...
```

## Notes

- Treat each subdirectory as a self-contained project with its own setup,
  dependencies, and instructions.
- When working on a specific project, scope changes to that project's
  subdirectory unless asked otherwise.
