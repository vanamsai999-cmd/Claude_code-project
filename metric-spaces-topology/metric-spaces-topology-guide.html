Chapter 0: Preliminaries

⏱ 2:10–2:30 (20 min)Read quickly. These are tools you'll use in every later chapter. Make sure you can apply the preimage rules and negate quantifiers without thinking.

0.1 Logic and quantifiers

Almost every definition in this course is a chain of "for all" (∀) and "there exists" (∃). To negate a statement, swap ∀ ↔ ∃ and negate the final condition.

Example: negating convergence

xₙ → x means: ∀ε > 0 ∃N ∀n ≥ N : d(xₙ, x) < ε.

xₙ ↛ x means: ∃ε > 0 ∀N ∃n ≥ N : d(xₙ, x) ≥ ε. In words, infinitely many terms stay at least ε away from x.

Proof methods you will use: direct, contrapositive (to prove P ⇒ Q, prove not Q ⇒ not P), contradiction, and induction.

0.2 Sets

  • De Morgan's laws: (⋃ Aᵢ)ᶜ = ⋂ Aᵢᶜ and (⋂ Aᵢ)ᶜ = ⋃ Aᵢᶜ. These are why "unions of open sets are open" turns into "intersections of closed sets are closed".
  • A \ B = A ∩ Bᶜ.
  • To prove A = B, show A ⊆ B and B ⊆ A. Take an arbitrary element of one set and show it lies in the other.

0.3 Functions, images and preimages

Definitions

Let f : X → Y.

  • The image of A ⊆ X is f(A) = {f(a) : a ∈ A}.
  • The preimage (inverse image) of B ⊆ Y is f⁻¹(B) = {x ∈ X : f(x) ∈ B}. This makes sense even when f has no inverse.
  • f is injective (one-to-one) if f(x) = f(y) ⇒ x = y.
  • f is surjective (onto) if every y ∈ Y equals f(x) for some x.
  • f is bijective if it is both. Exactly then there is an inverse function f⁻¹ : Y → X.
Preimages preserve everything (memorise this)
  • f⁻¹(⋃ Bᵢ) = ⋃ f⁻¹(Bᵢ)
  • f⁻¹(⋂ Bᵢ) = ⋂ f⁻¹(Bᵢ)
  • f⁻¹(Y \ B) = X \ f⁻¹(B)

Images are less well behaved: f(⋃ Aᵢ) = ⋃ f(Aᵢ), but only f(A ∩ B) ⊆ f(A) ∩ f(B) (equality holds if f is injective). Also A ⊆ f⁻¹(f(A)) and f(f⁻¹(B)) ⊆ B.

Why this matters

Continuity is defined using preimages ("the preimage of an open set is open") because preimages respect complements, unions and intersections. Images don't, which is why "the image of an open set is open" is not the definition of continuity.

0.4 Countability

A set is countable if it is finite or in bijection with ℕ. ℕ, ℤ and ℚ are countable, and a countable union of countable sets is countable. ℝ is uncountable (Cantor's diagonal argument). These facts come up with dense sets and separability.

0.5 The real numbers: supremum and infimum

Definition

An upper bound of A ⊆ ℝ is an M with a ≤ M for all a ∈ A. The supremum sup A is the least upper bound. The infimum inf A is the greatest lower bound.

Completeness axiom of ℝ: every non-empty subset of ℝ that is bounded above has a supremum in ℝ. This is exactly what ℚ lacks. For example, {q ∈ ℚ : q² < 2} has no supremum in ℚ.

Approximation property

If s = sup A, then for every ε > 0 there is an a ∈ A with s − ε < a ≤ s. You'll use this all the time, for example with d(x, A) = inf and with diameters.

0.6 Inequalities

  • Triangle inequality: |a + b| ≤ |a| + |b|.
  • Reverse triangle inequality: | |a| − |b| | ≤ |a − b|.
  • Cauchy–Schwarz: (Σ aᵢbᵢ)² ≤ (Σ aᵢ²)(Σ bᵢ²).
  • Minkowski: √Σ(aᵢ+bᵢ)² ≤ √Σaᵢ² + √Σbᵢ². This is the triangle inequality for the Euclidean metric.

0.7 Sequences in ℝ (you'll generalise all of this)

  • xₙ → x ⇔ ∀ε > 0 ∃N ∀n ≥ N : |xₙ − x| < ε.
  • Monotone convergence theorem: a bounded monotone sequence of reals converges.
  • Bolzano–Weierstrass: every bounded sequence in ℝ (or ℝⁿ) has a convergent subsequence.
  • A subsequence (x_{n_k}) uses indices n₁ < n₂ < n₃ < …, so n_k ≥ k.

Chapter 1: Metric spaces

⏱ 2:30–3:05 (35 min)Learn the three axioms by heart. Work through the standard examples, especially the ℝⁿ metrics, the discrete metric and C[a,b]. Practise one "prove this is a metric" proof and one "show this is NOT a metric" counterexample.

1.1 The big idea

Intuition. Analysis on ℝ (limits, continuity, convergence) only ever uses one thing: the distance |x − y|. A metric space is any set with a sensible notion of distance. Once we have one, we can do analysis on sets of points, vectors, functions, strings, and so on.

Definition 1.1: metric space

A metric on a set X is a function d : X × X → ℝ such that for all x, y, z ∈ X:

  1. (M1) Positivity: d(x, y) ≥ 0, and d(x, y) = 0 ⇔ x = y.
  2. (M2) Symmetry: d(x, y) = d(y, x).
  3. (M3) Triangle inequality: d(x, z) ≤ d(x, y) + d(y, z).

The pair (X, d) is a metric space.

Exam tip

When asked to "prove d is a metric", check all three axioms explicitly and in order. M1 and M2 are usually one line each. All the work goes into M3.

1.2 Standard examples (know all of these)

(a) The real line

X = ℝ, d(x, y) = |x − y|. This is the usual or standard metric.

(b) Three metrics on ℝⁿ

For x = (x₁,…,xₙ) and y = (y₁,…,yₙ):

d₁(x,y) = Σᵢ |xᵢ − yᵢ| (taxicab / Manhattan)
d₂(x,y) = √( Σᵢ (xᵢ − yᵢ)² ) (Euclidean)
d_∞(x,y) = maxᵢ |xᵢ − yᵢ| (sup / max / Chebyshev)

M1 and M2 are immediate. For M3: d₁ and d_∞ follow from the triangle inequality in ℝ, applied coordinate by coordinate. d₂ needs Minkowski / Cauchy–Schwarz.

Comparison inequalities in ℝⁿ
d_∞(x,y) ≤ d₂(x,y) ≤ d₁(x,y) ≤ n·d_∞(x,y), and d₂ ≤ √n·d_∞.

These show the three metrics are Lipschitz equivalent (§1.5). So they have the same open sets, the same convergent sequences and the same continuous functions.

(c) The discrete metric

On any set X: d(x, y) = 0 if x = y and d(x, y) = 1 if x ≠ y.

M1 and M2 are clear. For M3, if x = z the left side is 0 ≤ anything. If x ≠ z, then y can't equal both x and z, so at least one term on the right is 1. Then d(x,z) = 1 ≤ d(x,y) + d(y,z).
Why the discrete metric matters

It's the go-to counterexample machine. In it, every set is open and closed, every function out of it is continuous, convergent sequences are eventually constant, and it is always complete. It is compact only if X is finite. Whenever you suspect a statement is false in general, test it here first.

(d) Function spaces C[a, b]

C[a,b] is the set of continuous functions f : [a,b] → ℝ.

d_∞(f,g) = sup_{t∈[a,b]} |f(t) − g(t)| (uniform / sup metric)
d₁(f,g) = ∫ₐᵇ |f(t) − g(t)| dt (L¹ / integral metric)

The sup is finite because |f − g| is continuous on a closed bounded interval, so it attains a maximum. For d₁, continuity is needed for M1: if f ≠ g then |f − g| > 0 on a small interval (by continuity), so the integral is > 0. On merely integrable functions, d₁ fails M1. For example, a function that is 0 except at one point has integral 0.

Picture: d_∞(f,g) is the largest vertical gap between the graphs. d₁(f,g) is the area between them.

(e) Sequence spaces

  • ℓ¹: sequences with Σ|xᵢ| < ∞, with d(x,y) = Σ|xᵢ − yᵢ|.
  • ℓ²: sequences with Σxᵢ² < ∞, with d(x,y) = √Σ(xᵢ − yᵢ)².
  • ℓ^∞: bounded sequences, with d(x,y) = sup|xᵢ − yᵢ|.

(f) Normed spaces

Definition 1.2: norm

A norm on a real vector space V is a map ‖·‖ : V → ℝ such that:

  1. ‖v‖ ≥ 0, and ‖v‖ = 0 ⇔ v = 0;
  2. ‖λv‖ = |λ|‖v‖;
  3. ‖u + v‖ ≤ ‖u‖ + ‖v‖.

Every norm gives a metric d(u, v) = ‖u − v‖. All the examples in (b), (d) and (e) come from norms. The discrete metric does not come from a norm on any non-zero vector space, because d(λv, 0) would have to equal |λ| d(v, 0).

(g) Other examples that come up in exams

  • Hamming metric: on strings of length n, d(x,y) is the number of positions where x and y differ.
  • Bounded metric: d'(x,y) = d(x,y) / (1 + d(x,y)) is a metric, and every distance is < 1. It is proved in §1.6.
  • British Rail / SNCF metric on ℝ²: d(x,y) = ‖x − y‖ if x, y and the origin are collinear, and ‖x‖ + ‖y‖ otherwise. All journeys go via London (the origin).
  • Subspace (induced) metric: if Y ⊆ X, restricting d to Y × Y makes Y a metric space. For example, ℚ or [0,1] with |x − y|.
  • Product metric: on X × Y, use max{d_X(x,x'), d_Y(y,y')} or d_X + d_Y.

1.3 Things that are NOT metrics

Standard failures
  • d(x,y) = (x − y)² on ℝ fails M3: d(0,2) = 4 > d(0,1) + d(1,2) = 2.
  • d(x,y) = |x² − y²| on ℝ fails M1: d(1, −1) = 0 but 1 ≠ −1.
  • d(x,y) = x − y fails M1 (it can be negative) and M2.
  • d(f,g) = |f(0) − g(0)| on C[0,1] fails M1: two different functions can agree at 0. (This is called a pseudometric.)

To disprove an axiom you only need one specific counterexample with numbers.

1.4 Useful consequences of the axioms

Lemma 1.3
  1. Reverse triangle inequality: |d(x,z) − d(y,z)| ≤ d(x,y).
  2. Polygon inequality: d(x₁, xₙ) ≤ d(x₁,x₂) + d(x₂,x₃) + … + d(xₙ₋₁, xₙ).
  3. |d(x,y) − d(x',y')| ≤ d(x,x') + d(y,y').
For (1): by M3, d(x,z) ≤ d(x,y) + d(y,z), so d(x,z) − d(y,z) ≤ d(x,y). Swapping x and y (and using M2) gives d(y,z) − d(x,z) ≤ d(x,y). Together these give the absolute value.
Definition 1.4: bounded, diameter, distance to a set
  • A ⊆ X is bounded if there are x₀ ∈ X and M with d(a, x₀) ≤ M for all a ∈ A. Equivalently, A lies inside some ball.
  • Diameter: diam A = sup{d(a,b) : a, b ∈ A}. A is bounded ⇔ diam A < ∞.
  • Distance from a point to a set: d(x, A) = inf{d(x,a) : a ∈ A}.
  • Distance between sets: d(A, B) = inf{d(a,b) : a ∈ A, b ∈ B}.
Common mistakes
  • d(x, A) = 0 does not mean x ∈ A. For example, d(0, (0,1)) = 0. It means x is in the closure of A (Chapter 2).
  • "Bounded" depends on the metric. ℝ is unbounded under |x−y| but bounded under the discrete metric or d/(1+d).
Definition 1.5: isometry

A map f : (X,d_X) → (Y,d_Y) is an isometry if d_Y(f(x), f(y)) = d_X(x,y) for all x, y. Isometries are automatically injective, by M1.

1.5 Equivalent metrics

Definition 1.6
  • d and d' on X are Lipschitz (strongly) equivalent if there are constants α, β > 0 with α·d(x,y) ≤ d'(x,y) ≤ β·d(x,y) for all x, y.
  • They are topologically equivalent if they give the same open sets (Chapter 2). Equivalently, the identity map is continuous in both directions.
Fact

Lipschitz equivalent ⇒ topologically equivalent, but not conversely. On ℝ, d = |x−y| and d' = d/(1+d) are topologically equivalent but not Lipschitz equivalent. If d ≤ β d' held, d would be bounded, because d' < 1.

Example: d₁ and d_∞ on C[0,1] are NOT equivalent

Always d₁(f,g) ≤ d_∞(f,g), because the area is at most (height × width 1). There is no reverse inequality. Take fₙ(t) = tⁿ: then d₁(fₙ, 0) = 1/(n+1) → 0, but d_∞(fₙ, 0) = 1 for all n. So fₙ → 0 in d₁ but not in d_∞.

1.6 Worked proof: d/(1+d) is a metric

Claim

If d is a metric on X, then ρ(x,y) = d(x,y) / (1 + d(x,y)) is a metric on X.

Let φ(t) = t/(1+t) = 1 − 1/(1+t) for t ≥ 0. Then φ(t) ≥ 0, φ(t) = 0 ⇔ t = 0, and φ is increasing. So M1 and M2 for ρ follow from those for d.
Subadditivity: for a, b ≥ 0, φ(a+b) = a/(1+a+b) + b/(1+a+b) ≤ a/(1+a) + b/(1+b) = φ(a) + φ(b). M3: since d(x,z) ≤ d(x,y) + d(y,z) and φ is increasing, ρ(x,z) = φ(d(x,z)) ≤ φ(d(x,y) + d(y,z)) ≤ φ(d(x,y)) + φ(d(y,z)) = ρ(x,y) + ρ(y,z).
General recipe

If φ : [0,∞) → [0,∞) is increasing, subadditive, and φ(t) = 0 ⇔ t = 0, then φ ∘ d is a metric. Examples are √d, min{d, 1} and d/(1+d), but not d².

1.7 Practice questions

EASY 1. Show that d(x,y) = |x³ − y³| is a metric on ℝ.

Solution

M1: |x³ − y³| ≥ 0, and it is 0 ⇔ x³ = y³ ⇔ x = y, since cubing is injective on ℝ. M2 is clear. M3: |x³ − z³| = |(x³ − y³) + (y³ − z³)| ≤ |x³ − y³| + |y³ − z³|. In general, |f(x) − f(y)| is a metric whenever f is injective. Compare |x² − y²|, which fails because squaring isn't injective.

EASY 2. Compute d₁, d₂, d_∞ between (1, 2) and (4, −2) in ℝ².

Solution

The differences are 3 and 4. So d₁ = 7, d₂ = 5 and d_∞ = 4. Check: 4 ≤ 5 ≤ 7 ≤ 2·4. ✓

MEDIUM 3. Is d(x,y) = min{1, |x − y|} a metric on ℝ? Is it Lipschitz equivalent to the usual metric?

Solution

Yes, it's a metric. φ(t) = min{1,t} is increasing, satisfies φ(t) = 0 ⇔ t = 0, and is subadditive: if a or b ≥ 1 the right side is ≥ 1 ≥ φ(a+b); otherwise φ(a+b) ≤ a + b = φ(a) + φ(b). It is not Lipschitz equivalent to |x − y|: we would need |x−y| ≤ β·min{1,|x−y|} ≤ β for all x, y, which is impossible. It is topologically equivalent, because small balls (radius < 1) are the same in both metrics.

HARD 4. Let p be prime. For x ∈ ℤ \ {0}, let v(x) be the largest power k with pᵏ | x. Define d(x,y) = p^{−v(x−y)} for x ≠ y and d(x,x) = 0. Show that d satisfies the ultrametric inequality d(x,z) ≤ max{d(x,y), d(y,z)}, and hence is a metric.

Solution

M1 and M2 are clear (v(−a) = v(a)). If pᵏ divides both x − y and y − z, it divides their sum x − z. So v(x − z) ≥ min{v(x−y), v(y−z)}, and therefore d(x,z) = p^{−v(x−z)} ≤ max{d(x,y), d(y,z)}. (The cases where two of the points are equal are trivial.) Since max{a,b} ≤ a + b, M3 follows. A strange consequence: in an ultrametric space, every point of a ball is its centre.

HARD 5. Prove that d₂ satisfies the triangle inequality on ℝⁿ.

Solution

Let a = x − y and b = y − z, so x − z = a + b. We need ‖a+b‖ ≤ ‖a‖ + ‖b‖, where ‖a‖ = √Σaᵢ². Square both sides: ‖a+b‖² = Σaᵢ² + 2Σaᵢbᵢ + Σbᵢ² ≤ ‖a‖² + 2‖a‖‖b‖ + ‖b‖² = (‖a‖+‖b‖)², using Cauchy–Schwarz, Σaᵢbᵢ ≤ ‖a‖‖b‖. Both sides are non-negative, so take square roots.

Chapter 2: Open and closed sets, convergence, topological spaces

⏱ 3:15–3:50 (35 min)This is the most terminology-heavy chapter, and the language every later chapter uses. Learn the definitions of open, closed, interior, closure, boundary, limit point and dense word for word. Fill in the worked table in §2.4 yourself before checking it.

2.1 Balls

Definition 2.1

For x ∈ X and r > 0:

  • Open ball: B(x, r) = {y ∈ X : d(x,y) < r}
  • Closed ball: B̄(x, r) = {y ∈ X : d(x,y) ≤ r}
  • Sphere: S(x, r) = {y ∈ X : d(x,y) = r}

2.2 Open and closed sets

Definition 2.2: open set

U ⊆ X is open if for every x ∈ U there is an r > 0 with B(x, r) ⊆ U.

Intuition: every point of U has some breathing room. You can move a little in any direction and stay in U. No point of U sits on its edge.

Definition 2.3: closed set

F ⊆ X is closed if its complement X \ F is open.

Equivalently (Theorem 2.10), F contains the limit of every convergent sequence of points in F: you can't escape F by taking limits.

Lemma 2.4: open balls are open

For any x and r > 0, B(x, r) is open. Closed balls and spheres are closed.

Let y ∈ B(x,r) and put s = r − d(x,y) > 0. If z ∈ B(y, s), then d(x,z) ≤ d(x,y) + d(y,z) < d(x,y) + s = r, so z ∈ B(x,r). Hence B(y,s) ⊆ B(x,r).
For closed balls, show the complement is open. If d(x,y) > r, put s = d(x,y) − r. For z ∈ B(y,s), d(x,z) ≥ d(x,y) − d(y,z) > d(x,y) − s = r.
Exam tip: the "r − d(x,y)" trick

This radius choice is the single most reused idea in the course. Draw the picture: a small ball around y that fits inside the big ball.

Theorem 2.5: properties of open sets
  1. ∅ and X are open.
  2. Any union (even infinitely many) of open sets is open.
  3. A finite intersection of open sets is open.

Taking complements (De Morgan): ∅, X are closed, any intersection of closed sets is closed, and a finite union of closed sets is closed.

(2): if x ∈ ⋃Uᵢ, then x ∈ Uⱼ for some j, and some B(x,r) ⊆ Uⱼ ⊆ ⋃Uᵢ. (3): if x ∈ U₁ ∩ … ∩ Uₙ, choose B(x, rᵢ) ⊆ Uᵢ and let r = min{r₁,…,rₙ} > 0. The minimum of finitely many positive numbers is positive. This step fails for infinitely many: an infimum can be 0.
Why "finite" matters: counterexamples
  • ⋂ₙ (−1/n, 1/n) = {0}: infinitely many open sets whose intersection is not open in ℝ.
  • ⋃ₙ [1/n, 1] = (0, 1]: infinitely many closed sets whose union is not closed.
The most common misconception: sets are not doors

"Not open" does not mean "closed". A set can be:

  • both open and closed ("clopen"): ∅ and X always, and every subset in a discrete space;
  • neither: [0,1) in ℝ, or ℚ in ℝ;
  • exactly one of the two.

2.3 Interior, closure, boundary, limit points

Definition 2.6

Let A ⊆ X.

  • Interior point of A: an x with B(x,r) ⊆ A for some r > 0.
    Interior int A: the set of all interior points. It is the largest open set contained in A, which equals the union of all open subsets of A.
  • Closure cl A: the smallest closed set containing A, which equals the intersection of all closed supersets of A.
  • Limit point (accumulation point, cluster point) of A: an x such that every ball B(x,r) contains a point of A other than x. The set of limit points is the derived set A'.
  • Isolated point of A: a point a ∈ A with B(a,r) ∩ A = {a} for some r.
  • Boundary: ∂A = cl A \ int A.
  • Exterior: ext A = int(X \ A).
Theorem 2.7: characterisations of closure (all equivalent; very examinable)

For x ∈ X, the following are equivalent:

  1. x ∈ cl A;
  2. every open ball B(x, r) meets A (that is, B(x,r) ∩ A ≠ ∅);
  3. there is a sequence (aₙ) in A with aₙ → x;
  4. d(x, A) = 0;
  5. x ∈ A ∪ A'.

Also: A is open ⇔ A = int A; A is closed ⇔ A = cl A ⇔ A' ⊆ A.

(1)⇒(2): if some B(x,r) misses A, then X \ B(x,r) is a closed set containing A, so it contains cl A. That gives x ∉ cl A. (2)⇒(3): pick aₙ ∈ B(x, 1/n) ∩ A. Then d(aₙ, x) < 1/n → 0. (3)⇒(4): d(x,A) ≤ d(x,aₙ) → 0. (4)⇒(2): for any r, by the definition of inf there is a ∈ A with d(x,a) < r. (2)⇒(1): let E be the set of points satisfying (2). Its complement is open: if B(y,r) ∩ A = ∅, then every z ∈ B(y,r) has a small ball inside B(y,r), which misses A. So E is a closed set containing A, and hence cl A ⊆ E.
Theorem 2.8: useful identities
  • X \ cl A = int(X \ A) and X \ int A = cl(X \ A).
  • ∂A = cl A ∩ cl(X \ A). In words, x ∈ ∂A ⇔ every ball around x meets both A and its complement. ∂A is always closed, and ∂A = ∂(X\A).
  • cl(A ∪ B) = cl A ∪ cl B, but only cl(A ∩ B) ⊆ cl A ∩ cl B. For example, with A = ℚ and B = ℝ \ ℚ, the left side is ∅ and the right side is ℝ.
  • int(A ∩ B) = int A ∩ int B, but only int(A ∪ B) ⊇ int A ∪ int B.
  • A ⊆ B ⇒ int A ⊆ int B and cl A ⊆ cl B.
Trap: closure of an open ball ≠ closed ball (in general)

In the discrete metric, cl B(x,1) = cl{x} = {x}, but B̄(x,1) = X. What is always true is cl B(x,r) ⊆ B̄(x,r). Equality holds in normed spaces such as ℝⁿ and C[a,b].

Definition 2.9: dense, separable, nowhere dense
  • A is dense in X if cl A = X. Equivalently, every non-empty open set meets A, or every point is a limit of points of A. Examples: ℚ and ℝ \ ℚ are dense in ℝ; polynomials are dense in (C[a,b], d_∞) (Weierstrass).
  • X is separable if it has a countable dense subset. Examples: ℝⁿ (via ℚⁿ) and C[a,b]. An uncountable discrete space is not separable.
  • A is nowhere dense if int(cl A) = ∅. Examples: ℤ or the Cantor set in ℝ.

2.5 Convergence of sequences

Definition 2.10

xₙ → x in (X, d) if d(xₙ, x) → 0 in ℝ. Explicitly:

∀ε > 0 ∃N ∈ ℕ ∀n ≥ N : d(xₙ, x) < ε.

Equivalently, every open set (or ball) containing x contains xₙ for all but finitely many n (the sequence is eventually in it).

Theorem 2.11: basic facts
  1. Limits are unique in a metric space.
  2. A convergent sequence is bounded.
  3. If xₙ → x, every subsequence also converges to x.
  4. Sequential closedness: F is closed ⇔ whenever xₙ ∈ F and xₙ → x ∈ X, we have x ∈ F.
(1): if xₙ → x and xₙ → y, then 0 ≤ d(x,y) ≤ d(x,xₙ) + d(xₙ,y) → 0, so d(x,y) = 0 and x = y. (4) ⇒: suppose x ∉ F. Since X \ F is open, some B(x,r) misses F, so d(xₙ, x) ≥ r for all n. That contradicts xₙ → x. (4) ⇐: by Theorem 2.7(3), any x ∈ cl F is a limit of points of F, so x ∈ F. Hence cl F = F.
What convergence means in specific spaces
  • ℝⁿ (any of d₁, d₂, d_∞): convergence ⇔ each coordinate converges.
  • (C[a,b], d_∞): convergence ⇔ uniform convergence.
  • (C[a,b], d₁): convergence "in mean". This is weaker: tⁿ → 0 in d₁ but not in d_∞.
  • Discrete metric: xₙ → x ⇔ (xₙ) is eventually constant and equal to x (take ε = ½).

2.6 Topological spaces

Intuition. Notice that convergence, continuity and closure can all be described using only which sets are open. So we can forget the distances and just keep the collection of open sets. That collection is a topology.

Definition 2.12: topology

A topology on a set X is a collection τ of subsets of X (called open sets) such that:

  1. (T1) ∅ ∈ τ and X ∈ τ;
  2. (T2) any union of members of τ is in τ;
  3. (T3) any finite intersection of members of τ is in τ (it's enough to check intersections of two).

(X, τ) is a topological space. A set is closed if its complement is in τ. A neighbourhood of x is a set containing an open set that contains x.

Standard topologies
  • Metric topology: the open sets of a metric space (Theorem 2.5 checks T1–T3).
  • Discrete topology: τ is every subset of X. It comes from the discrete metric.
  • Indiscrete (trivial) topology: τ = {∅, X}.
  • Cofinite topology: U is open ⇔ U = ∅ or X \ U is finite.
  • Sierpiński space: X = {0,1}, τ = {∅, {1}, {0,1}}.
Example: checking a topology

Is τ = {∅, {a}, {b}, {a,b,c}} a topology on {a,b,c}? No: {a} ∪ {b} = {a,b} ∉ τ, so T2 fails. Adding {a,b} fixes it.

Definition 2.13: comparing topologies, basis, metrizable, Hausdorff
  • τ₁ is coarser (weaker) than τ₂ if τ₁ ⊆ τ₂; then τ₂ is finer (stronger). The indiscrete topology is the coarsest possible and the discrete topology is the finest.
  • A basis ℬ for τ is a collection of open sets such that every open set is a union of members of ℬ. Example: open balls are a basis for a metric topology, and intervals with rational endpoints are a basis for ℝ.
  • (X,τ) is metrizable if some metric on X produces exactly τ.
  • (X,τ) is Hausdorff (T₂) if any two distinct points x ≠ y have disjoint open neighbourhoods U ∋ x and V ∋ y.
Theorem 2.14: every metric space is Hausdorff
If x ≠ y, let r = d(x,y)/2 > 0. If z were in B(x,r) ∩ B(y,r), then d(x,y) ≤ d(x,z) + d(z,y) < 2r = d(x,y), a contradiction.
Exam use: proving a space is NOT metrizable

Show it isn't Hausdorff. The indiscrete topology on ≥ 2 points, the cofinite topology on an infinite set (any two non-empty open sets intersect) and Sierpiński space are all non-Hausdorff, so none of them is metrizable.

Weird behaviour in non-Hausdorff spaces

In the indiscrete topology, every sequence converges to every point, so limits aren't unique. Uniqueness of limits really comes from the Hausdorff property. Also, in general topological spaces, sequences aren't always enough to detect closure. That's why topology uses open sets as the basic notion.

2.7 Subspaces

Definition 2.15: subspace topology

If Y ⊆ X, the subspace topology on Y is τ_Y = {U ∩ Y : U open in X}. For metric spaces this is the same as the topology of the restricted metric, and B_Y(y,r) = B_X(y,r) ∩ Y.

Facts
  • F ⊆ Y is closed in Y ⇔ F = C ∩ Y for some C closed in X.
  • If Y is open in X, then "open in Y" ⇔ "open in X" for subsets of Y. The same holds for closed sets when Y is closed.
  • Example: in Y = ℚ, the set {q ∈ ℚ : q² < 2} is clopen. It equals (−√2, √2) ∩ ℚ = [−√2, √2] ∩ ℚ.

2.8 Practice questions

EASY 1. Prove that U = {(x,y) ∈ ℝ² : x > 0} is open, directly from the definition.

Solution

Let p = (a,b) ∈ U, so a > 0. Take r = a. If (x,y) ∈ B(p, a) (Euclidean), then |x − a| ≤ d₂((x,y),(a,b)) < a, so x > 0. Hence B(p,a) ⊆ U. (Quicker method in Ch 3: U = f⁻¹((0,∞)) for the continuous map f(x,y) = x.)

EASY 2. Prove that every finite subset of a metric space is closed.

Solution

First, {p} is closed. If x ≠ p, then B(x, d(x,p)) doesn't contain p, so the complement of {p} is open. A finite set is a finite union of singletons, and finite unions of closed sets are closed.

MEDIUM 3. In a discrete metric space, find int A, cl A and ∂A for any A.

Solution

Every set is open (B(x,½) = {x} ⊆ A) and so every set is also closed. Hence int A = A, cl A = A and ∂A = ∅.

MEDIUM 4. Show that ∂A = ∅ ⇔ A is clopen.

Solution

∂A = cl A \ int A is empty ⇔ cl A ⊆ int A. Since int A ⊆ A ⊆ cl A always, that holds ⇔ int A = A = cl A ⇔ A is both open and closed.

HARD 5. Let X be infinite with the cofinite topology. (a) Show it's a topology. (b) Show it's not Hausdorff. (c) Which sequences converge, and to what?

Solution

(a) T1: ∅ by definition, and X \ X = ∅ is finite. T2: if the Uᵢ are non-empty open sets, X \ ⋃Uᵢ = ⋂(X \ Uᵢ) is contained in a finite set. T3: X \ (U ∩ V) = (X\U) ∪ (X\V) is a union of two finite sets. (b) If U, V are non-empty open and disjoint, then X = X \ (U ∩ V) = (X\U) ∪ (X\V) is finite, a contradiction. (c) Suppose no value is repeated infinitely often (for example, all xₙ are distinct). Then xₙ → x for every x ∈ X. An open U ∋ x misses only finitely many points, so only finitely many xₙ are outside U. This is another example of non-unique limits.

HARD 6. Prove that in any metric space, cl B(x,r) ⊆ B̄(x,r), and give an example where the inclusion is strict.

Solution

B̄(x,r) is closed (Lemma 2.4) and contains B(x,r). The closure is the smallest such closed set, so the inclusion follows. For a strict example, use the discrete metric with r = 1 and |X| ≥ 2: cl B(x,1) = {x} ≠ X = B̄(x,1). Another example: X = [0,1] ∪ [2,3] ⊂ ℝ with x = 0, r = 2. Then cl B = [0,1], but B̄ = [0,1] ∪ {2}.

Chapter 3: Continuity and homeomorphisms

⏱ 3:50–4:25 (35 min)Learn the four equivalent definitions of continuity and how to switch between them. Memorise the uniform continuity hierarchy and its counterexamples. Be able to show two spaces are or are not homeomorphic.

3.1 Four equivalent definitions

Intuition. f is continuous if "close inputs give close outputs". If you want f(y) within ε of f(x), you can guarantee it by taking y within δ of x.

Definition 3.1: ε–δ continuity

f : (X,d_X) → (Y,d_Y) is continuous at a ∈ X if

∀ε > 0 ∃δ > 0 ∀x ∈ X : d_X(x,a) < δ ⇒ d_Y(f(x), f(a)) < ε.

In terms of balls: f(B(a,δ)) ⊆ B(f(a), ε). f is continuous if it is continuous at every point.

Theorem 3.2: equivalent forms (core exam theorem)

For f : X → Y between metric spaces, the following are equivalent:

  1. (ε–δ) f is continuous at every point.
  2. (Sequential) xₙ → x in X ⇒ f(xₙ) → f(x) in Y.
  3. (Open sets) V open in Y ⇒ f⁻¹(V) open in X.
  4. (Closed sets) C closed in Y ⇒ f⁻¹(C) closed in X.

For topological spaces, (3) is the definition of continuity.

(1)⇒(3): let V be open and a ∈ f⁻¹(V). Since f(a) ∈ V, choose ε with B(f(a),ε) ⊆ V, then δ from (1). Then f(B(a,δ)) ⊆ B(f(a),ε) ⊆ V, so B(a,δ) ⊆ f⁻¹(V).
(3)⇒(1): B(f(a),ε) is open, so f⁻¹(B(f(a),ε)) is open and contains a. Hence it contains some B(a,δ), which is exactly the ε–δ statement.
(3)⇔(4): take complements, using f⁻¹(Y \ C) = X \ f⁻¹(C).
(1)⇒(2): given ε, take δ from (1), then N with d(xₙ,x) < δ for n ≥ N. Then d(f(xₙ),f(x)) < ε.
(2)⇒(1), by contrapositive: if (1) fails at a, there is an ε such that for each δ = 1/n some xₙ has d(xₙ,a) < 1/n but d(f(xₙ),f(a)) ≥ ε. Then xₙ → a but f(xₙ) ↛ f(a).
Which form should you use?
  • To show f is continuous with a formula: use ε–δ, or combine known continuous functions.
  • To show f is not continuous: find one sequence xₙ → x with f(xₙ) ↛ f(x), or one open set whose preimage isn't open.
  • To show a set is open or closed: write it as f⁻¹(open) or f⁻¹(closed) for a continuous f. This is often a one-line proof.
  • For abstract or topological questions: use the open-set form.

3.2 Building continuous functions

Theorem 3.3
  • Constant maps and identity maps (X,d) → (X,d) are continuous.
  • Compositions of continuous maps are continuous: (g∘f)⁻¹(V) = f⁻¹(g⁻¹(V)).
  • If f, g : X → ℝ are continuous, so are f + g, fg, |f|, max(f,g), min(f,g), and f/g where g ≠ 0.
  • f = (f₁,…,fₙ) : X → ℝⁿ is continuous ⇔ each component fᵢ is continuous.
  • Any function out of a discrete space is continuous, because every preimage is open.
  • For fixed a, x ↦ d(x,a) is continuous. More generally, x ↦ d(x,A) is 1-Lipschitz: |d(x,A) − d(y,A)| ≤ d(x,y).
  • Restrictions of continuous maps to subspaces are continuous.
One-line open/closed proofs
  • {(x,y) : x² + y² < 1} is open: it is f⁻¹((−∞,1)) with f(x,y) = x²+y² continuous.
  • {(x,y) : xy = 1} is closed: it is g⁻¹({1}) with g(x,y) = xy, and {1} is closed.
  • {f ∈ C[0,1] : f(½) > 0} is open in d_∞: the evaluation map f ↦ f(½) is 1-Lipschitz, since |f(½) − g(½)| ≤ d_∞(f,g).
  • The zero set {x : f(x) = 0} of any continuous real-valued f is closed.
Continuity does NOT preserve open or closed sets under images
  • Open sets can map to non-open sets: f(x) = x² sends (−1,1) to [0,1).
  • Closed sets can map to non-closed sets: arctan sends the closed set ℝ to (−π/2, π/2). Projecting the closed hyperbola xy = 1 to the x-axis gives ℝ \ {0}.

Only preimages behave well. (Exception: continuous images of compact sets are compact, see Ch 5.)

Continuity depends on the metrics

The identity (ℝ, discrete) → (ℝ, usual) is continuous, because everything is open in the domain. The identity (ℝ, usual) → (ℝ, discrete) is not: the preimage of the open set {0} is {0}, which is not open in the usual topology. Likewise, the identity (C[0,1], d_∞) → (C[0,1], d₁) is continuous (since d₁ ≤ d_∞), but the reverse is not (tⁿ → 0 in d₁ only).

3.3 Uniform continuity and Lipschitz maps

Definition 3.4
  • f is uniformly continuous if ∀ε > 0 ∃δ > 0 ∀x, y ∈ X : d(x,y) < δ ⇒ d(f(x),f(y)) < ε. The key difference from continuity is that δ depends only on ε, not on the point. Look at where "∀x" sits in the quantifiers.
  • f is Lipschitz with constant L if d(f(x),f(y)) ≤ L·d(x,y) for all x, y. If L < 1, f is a contraction (Ch 4).
Hierarchy
Lipschitz ⇒ uniformly continuous ⇒ continuous

Proof: x² is not uniformly continuous on ℝ

Take ε = 1. For any δ > 0, let x = 1/δ and y = 1/δ + δ/2. Then |x − y| < δ, but |x² − y²| = |x − y||x + y| = (δ/2)(2/δ + δ/2) > 1.

Why uniform continuity matters

A uniformly continuous map sends Cauchy sequences to Cauchy sequences. A merely continuous map need not: 1/x on (0,1) sends the Cauchy sequence 1/n to n. Also, any continuous function on a compact metric space is uniformly continuous (Heine–Cantor, Ch 5).

3.4 Homeomorphisms

Definition 3.5

A homeomorphism f : X → Y is a bijection such that f and f⁻¹ are both continuous. Then X and Y are homeomorphic, written X ≅ Y. A topological property is one preserved by homeomorphisms.

Intuition: a homeomorphism stretches and bends without tearing or gluing. Topologists treat a coffee mug and a doughnut as the same.

Examples
  • (−1, 1) ≅ ℝ via x ↦ x / (1 − |x|), or x ↦ tan(πx/2).
  • Any two open intervals are homeomorphic (via a linear map, then the example above). Similarly any two closed intervals.
  • Any isometry onto its image is a homeomorphism onto its image.
  • If d, d' are topologically equivalent, the identity (X,d) → (X,d') is a homeomorphism.
A continuous bijection is NOT automatically a homeomorphism
  • f : [0, 2π) → S¹, t ↦ (cos t, sin t) is a continuous bijection onto the circle. Its inverse is not continuous at (1,0): points just below (1,0) on the circle map to numbers near 2π, not near 0.
  • The identity (ℝ, discrete) → (ℝ, usual).

It is automatic when the domain is compact and the codomain is Hausdorff (Ch 5).

3.5 Practice questions

EASY 1. Prove from ε–δ that f(x) = 3x + 2 is continuous on ℝ.

Solution

Given ε > 0, let δ = ε/3. If |x − a| < δ, then |f(x) − f(a)| = 3|x − a| < ε. It's in fact 3-Lipschitz, so it's uniformly continuous.

EASY 2. Show that f(x) = 1 for x ≥ 0 and f(x) = 0 for x < 0 is not continuous on ℝ, using two different methods.

Solution

Sequences: xₙ = −1/n → 0, but f(xₙ) = 0 ↛ 1 = f(0). Open sets: f⁻¹((½, 2)) = [0, ∞), which is not open.

MEDIUM 3. Let A ⊆ X be non-empty. Show that |d(x,A) − d(y,A)| ≤ d(x,y), and deduce that cl A = {x : d(x,A) = 0} is closed.

Solution

For any a ∈ A, d(x,A) ≤ d(x,a) ≤ d(x,y) + d(y,a). Taking inf over a gives d(x,A) ≤ d(x,y) + d(y,A). Swapping x and y gives the absolute value. So x ↦ d(x,A) is 1-Lipschitz and hence continuous, and {x : d(x,A) = 0} is the preimage of the closed set {0}.

MEDIUM 4. Show that I : C[0,1] → ℝ, I(f) = ∫₀¹ f, is continuous with respect to d_∞, and also with respect to d₁.

Solution

|I(f) − I(g)| = |∫(f − g)| ≤ ∫|f − g| = d₁(f,g) ≤ d_∞(f,g). So I is 1-Lipschitz for both metrics, and therefore uniformly continuous.

HARD 5. Is the evaluation map E(f) = f(0) continuous from (C[0,1], d₁) to ℝ?

Solution

No. Let fₙ(t) = max{0, 1 − nt} (a spike of height 1 at 0). Then d₁(fₙ, 0) = 1/(2n) → 0, so fₙ → 0. But E(fₙ) = 1 ↛ 0 = E(0). (With d_∞, it is continuous: |f(0) − g(0)| ≤ d_∞(f,g).)

HARD 6. Let f, g : X → Y be continuous, with Y a metric space. Show that {x : f(x) = g(x)} is closed. Deduce that if f = g on a dense subset, then f = g everywhere.

Solution

h(x) = d_Y(f(x), g(x)) is continuous, because it's a composition of continuous maps (or argue with sequences). The set is h⁻¹({0}), which is closed. If it contains a dense set D, then it contains cl D = X. Application: a continuous function on ℝ is determined by its values on ℚ.

Chapter 4: Completeness

4.1 Cauchy sequences

Intuition. A sequence is Cauchy if its terms eventually get as close to each other as you like, so they look as if they're converging. Completeness says that whenever this happens, there really is a limit in the space. ℚ is incomplete because 1, 1.4, 1.41, 1.414, … "wants" to converge to √2, which isn't in ℚ. The space has holes.

Definition 4.1: Cauchy sequence

(xₙ) is Cauchy if

∀ε > 0 ∃N ∀m, n ≥ N : d(xₘ, xₙ) < ε.

Notice that, unlike the definition of convergence, this one doesn't mention a limit.

Theorem 4.2: basic facts (with proofs, all short)
  1. Every convergent sequence is Cauchy.
  2. Every Cauchy sequence is bounded.
  3. A Cauchy sequence with a convergent subsequence converges, to the same limit.
(1): if xₙ → x, choose N with d(xₙ,x) < ε/2 for n ≥ N. Then d(xₘ,xₙ) ≤ d(xₘ,x) + d(x,xₙ) < ε. (2): with ε = 1, all xₙ with n ≥ N lie in B(x_N, 1). Only finitely many terms remain outside, so take the radius 1 + max{d(xᵢ, x_N) : i < N}. (3): let x_{n_k} → x. Given ε, choose N from the Cauchy condition with ε/2, and k with n_k ≥ N and d(x_{n_k}, x) < ε/2. For n ≥ N, d(xₙ, x) ≤ d(xₙ, x_{n_k}) + d(x_{n_k}, x) < ε.

4.2 Complete metric spaces

Definition 4.3

(X, d) is complete if every Cauchy sequence in X converges to a point of X. A complete normed vector space is a Banach space.

Complete spaces
  • ℝ. A Cauchy sequence is bounded, so it has a convergent subsequence (Bolzano–Weierstrass), so it converges by 4.2(3). This uses the completeness axiom.
  • ℝⁿ with d₁, d₂ or d_∞. Each coordinate is Cauchy in ℝ, so it converges.
  • Any closed subset of ℝⁿ, such as [0,1], ℤ, or the Cantor set.
  • Any discrete metric space. A Cauchy sequence (with ε = ½) is eventually constant.
  • (C[a,b], d_∞): uniform limits of continuous functions are continuous. Proof below.
  • ℓ¹, ℓ², ℓ^∞.
  • Any compact metric space (Ch 5).

Theorem 4.4: closed ⇔ complete (very examinable)
  1. If X is complete and F ⊆ X is closed, then F is complete.
  2. If Y ⊆ X is complete (with the induced metric), then Y is closed in X, for any metric space X.

So inside a complete space: a subset is complete ⇔ it is closed.

(1): a Cauchy sequence in F is Cauchy in X, so it converges to some x ∈ X. F is closed, so x ∈ F (Theorem 2.11(4)). (2): let yₙ ∈ Y with yₙ → x ∈ X. Then (yₙ) is convergent, hence Cauchy, so it converges in Y to some y. Limits are unique in X, so x = y ∈ Y. Hence Y is closed.

Proof that (C[a,b], d_∞) is complete

Let (fₙ) be Cauchy in d_∞. Step 1, candidate limit: for each t, |fₙ(t) − fₘ(t)| ≤ d_∞(fₙ,fₘ), so (fₙ(t)) is Cauchy in ℝ and converges. Call the limit f(t). Step 2, uniform convergence: given ε, choose N with |fₙ(t) − fₘ(t)| < ε for all t and all m,n ≥ N. Let m → ∞: |fₙ(t) − f(t)| ≤ ε for all t and all n ≥ N, so d_∞(fₙ, f) → 0. Step 3, f is continuous (the "ε/3 argument"): fix n with sup|fₙ − f| < ε/3. fₙ is continuous at s, so choose δ with |fₙ(t) − fₙ(s)| < ε/3 when |t − s| < δ. Then |f(t) − f(s)| ≤ |f(t) − fₙ(t)| + |fₙ(t) − fₙ(s)| + |fₙ(s) − f(s)| < ε. So f ∈ C[a,b] and fₙ → f.
General 3-step template for "prove X is complete"
  1. Take a Cauchy sequence and find a candidate limit (usually pointwise or coordinatewise).
  2. Show the sequence converges to the candidate in the metric.
  3. Show the candidate actually belongs to X.

4.3 The Contraction Mapping Theorem (Banach Fixed Point Theorem)

Definition 4.5

f : X → X is a contraction if there is a constant k with 0 ≤ k < 1 such that d(f(x), f(y)) ≤ k·d(x,y) for all x, y. A fixed point is an x* with f(x*) = x*.

Theorem 4.6: Contraction Mapping Theorem

Let (X, d) be a non-empty complete metric space and let f : X → X be a contraction with constant k. Then:

  1. f has a unique fixed point x*;
  2. for any starting point x₀, the iterates xₙ₊₁ = f(xₙ) converge to x*;
  3. error bound: d(xₙ, x*) ≤ kⁿ/(1 − k) · d(x₀, x₁).
Step 1, successive distances shrink geometrically: by induction, d(xₙ, xₙ₊₁) ≤ kⁿ d(x₀, x₁). Step 2, Cauchy: for m > n, by the polygon inequality and a geometric series, d(xₙ, xₘ) ≤ Σ_{j=n}^{m−1} kʲ d(x₀,x₁) ≤ kⁿ/(1−k) · d(x₀,x₁) → 0 as n → ∞ (because k < 1). Step 3, convergence: X is complete, so xₙ → x* for some x* ∈ X. Step 4, fixed point: f is Lipschitz and hence continuous, so f(x*) = lim f(xₙ) = lim xₙ₊₁ = x*. Step 5, uniqueness: if f(x) = x and f(y) = y, then d(x,y) = d(f(x),f(y)) ≤ k·d(x,y). So (1 − k)d(x,y) ≤ 0, giving d(x,y) = 0. Error bound: let m → ∞ in Step 2.
Every hypothesis is needed
  • Completeness: f(x) = x/2 on (0, 1] is a contraction with no fixed point (0 is missing).
  • k < 1 strictly, with a fixed k: f(x) = x + 1/x on [1, ∞) satisfies |f(x) − f(y)| < |x − y| for x ≠ y, but has no fixed point. (|f(x) − f(y)| = |x−y|(1 − 1/(xy)), and the factor can be arbitrarily close to 1.)
  • k = 1 isn't enough: f(x) = x + 1 on ℝ is an isometry with no fixed point.
  • f must map X into X: always check this first in applications.
Application: solving cos x = x

Let X = [0, 1], which is closed in ℝ and so complete, and f(x) = cos x. (i) f maps X into [cos 1, 1] ⊆ [0,1]. (ii) By the Mean Value Theorem, |cos x − cos y| = |sin ξ||x − y| ≤ sin(1)·|x − y|, and k = sin 1 ≈ 0.84 < 1. So there is a unique solution in [0,1] (≈ 0.739), and iterating cos from any starting point finds it.

Other standard applications: Picard–Lindelöf existence and uniqueness for ODEs y′ = F(t,y) (apply it to the integral operator on C[a,b]), integral equations, Newton's method convergence, and the inverse function theorem.

Exam recipe for applying the theorem
  1. Name a complete space X. Justify it, for example "closed subset of ℝ" or "(C[a,b], d_∞) is complete".
  2. Show f(X) ⊆ X.
  3. Find k < 1, usually via the MVT (sup|f′| < 1) or a direct estimate.
  4. Conclude there is a unique fixed point, with the iterates converging to it.

4.4 Further results (for harder questions)

Theorem 4.7: Cantor Intersection Theorem

Let X be complete and F₁ ⊇ F₂ ⊇ … non-empty closed sets with diam Fₙ → 0. Then ⋂Fₙ is exactly one point. Conversely, if this holds for every such sequence, then X is complete.

Pick xₙ ∈ Fₙ. For m ≥ n, both xₘ and xₙ lie in Fₙ, so d(xₘ,xₙ) ≤ diam Fₙ → 0. The sequence is Cauchy, so xₙ → x. Each Fₙ is closed and contains the tail xₙ, xₙ₊₁, …, so x ∈ Fₙ for every n. If y is also in the intersection, d(x,y) ≤ diam Fₙ → 0.
Hypotheses needed

Without closedness: ⋂(0, 1/n) = ∅. Without diam → 0: ⋂[n, ∞) = ∅ in ℝ.

Theorem 4.8: Baire Category Theorem

In a complete metric space, a countable intersection of dense open sets is dense. Equivalently, a non-empty complete metric space is not a countable union of nowhere-dense sets. Consequences: ℝ is uncountable (it isn't a countable union of singletons); ℚ is not complete under any metric equivalent to the usual one; there exist continuous nowhere-differentiable functions.

Theorem 4.9: Completion

Every metric space X sits isometrically as a dense subset of a complete metric space X̂ (its completion), which is unique up to isometry. For example, the completion of ℚ is ℝ, and the completion of (C[0,1], d₁) is L¹[0,1].

4.5 Practice questions

EASY 1. Is [0, ∞) complete? Is ℤ? Is {1/n : n ∈ ℕ}?

Solution

Yes: it's closed in the complete space ℝ. Yes: it's closed, and Cauchy sequences in ℤ are eventually constant. No: (1/n) is Cauchy, but its limit 0 isn't in the set (it isn't closed).

EASY 2. Show that xₙ = 1 + ½ + … + 1/n is not Cauchy in ℝ.

Solution

x_{2n} − xₙ = 1/(n+1) + … + 1/(2n) ≥ n·1/(2n) = ½ for every n. So with ε = ½, no N works. Note that xₙ₊₁ − xₙ → 0 is not enough for Cauchy.

MEDIUM 3. Show that f(x) = ½(x + 2/x) is a contraction on [1, 2]. What is its fixed point?

Solution

f′(x) = ½(1 − 2/x²). On [1,2], 2/x² ∈ [½, 2], so f′ ∈ [−½, ¼] and |f′| ≤ ½. The minimum of f is at √2, where f = √2; also f(1) = 1.5 and f(2) = 1.5. So f([1,2]) ⊆ [√2, 1.5] ⊆ [1,2]. [1,2] is complete, so there is a unique fixed point: x = ½(x + 2/x) ⇔ x² = 2, giving x = √2. This is the Babylonian / Newton method for √2. On [1,2] ∩ ℚ, f is still a contraction mapping ℚ to ℚ but has no fixed point, which shows completeness is needed.

HARD 4. Show that (C[0,1], d₁) is not complete.

Solution

Define fₙ(t) = 0 on [0, ½], linear from 0 to 1 on [½, ½ + 1/n], and 1 on [½ + 1/n, 1] (for n ≥ 2). For m > n, fₘ and fₙ differ only on [½, ½ + 1/n], by at most 1, so d₁(fₘ, fₙ) ≤ 1/n. The sequence is Cauchy.
Suppose fₙ → f ∈ C[0,1] in d₁. On [0,½]: ∫₀^{½}|f| = ∫₀^{½}|f − fₙ| ≤ d₁(f, fₙ) → 0, so f = 0 on [0,½] (by continuity). For any c > ½, once ½ + 1/n < c, the same argument on [c, 1] gives f = 1 there. Hence f = 1 on (½, 1]. Then f jumps at ½ and is not continuous, a contradiction.

HARD 5. Let X be complete and f : X → X with fᵐ (the m-th iterate) a contraction for some m. Show that f has a unique fixed point.

Solution

By the theorem, fᵐ has a unique fixed point x*. Then fᵐ(f(x*)) = f(fᵐ(x*)) = f(x*), so f(x*) is also a fixed point of fᵐ. By uniqueness, f(x*) = x*. Any fixed point of f is a fixed point of fᵐ, so it is unique. (This is used in the ODE version of Picard's theorem on large intervals.)

Chapter 5: Compactness

⏱ 5:10–5:35 (25 min)Learn the open-cover definition word for word, the three equivalent forms in metric spaces, Heine–Borel (and where it fails), and the theorems on continuous maps from compact spaces. Practise "show this is not compact" by finding a bad open cover or a bad sequence.

5.1 The idea

Intuition. Compactness is the topological version of "finite". Finite sets have nice properties: every function on them has a maximum, and every sequence in them repeats some value infinitely often. Compact sets keep those properties even when infinite. In ℝⁿ, compact simply means closed and bounded. In general spaces you need the definition below.

5.2 Definitions

Definition 5.1: open cover, compact
  • An open cover of K ⊆ X is a collection {Uᵢ}_{i∈I} of open sets with K ⊆ ⋃ Uᵢ.
  • A subcover is a subcollection that still covers K. It is finite if it has finitely many sets.
  • K is compact if every open cover of K has a finite subcover.
The #1 misreading

"Has a finite open cover" is always true: {X} is one. The definition says that every open cover can be reduced to finitely many sets. To prove compactness you must handle an arbitrary cover. To disprove it, you only need one cover with no finite subcover.

Definition 5.2: sequentially compact, totally bounded
  • X is sequentially compact if every sequence in X has a subsequence converging to a point of X.
  • X is totally bounded if for every ε > 0, X is covered by finitely many balls of radius ε (an ε-net).

Totally bounded ⇒ bounded, but not conversely. An infinite discrete space is bounded (diam = 1), but with ε = ½ each ball is a single point, so infinitely many balls are needed.

5.3 The main equivalence (metric spaces)

Theorem 5.3: for a metric space X, the following are equivalent
  1. X is compact;
  2. X is sequentially compact;
  3. X is complete and totally bounded.

In general topological spaces, (1) and (2) can differ. In metric spaces you can use whichever is most convenient. Sequences are usually easiest.

Sketch. (1)⇒(2): if a sequence had no convergent subsequence, each point x would have a ball containing xₙ for only finitely many n. Finitely many such balls cover X, so the sequence would have only finitely many terms, which is a contradiction. (2)⇒(3): a Cauchy sequence has a convergent subsequence, so it converges by 4.2(3). If X weren't totally bounded, you could choose points pairwise ≥ ε apart, and that sequence has no Cauchy (so no convergent) subsequence. (3)⇒(2): from any sequence, use finite ε-nets with ε = 1, ½, ⅓, … and a diagonal argument to extract a Cauchy subsequence. It converges by completeness. (2)⇒(1): use the Lebesgue number lemma (5.9) together with total boundedness.

5.4 Heine–Borel and its limits

Theorem 5.4: Heine–Borel

A subset of ℝⁿ (usual metric) is compact ⇔ it is closed and bounded.

⇒: Theorem 5.5. ⇐: a bounded sequence in ℝⁿ has a convergent subsequence (Bolzano–Weierstrass, coordinate by coordinate). Its limit lies in the set because the set is closed. So the set is sequentially compact.
Theorem 5.5: compact ⇒ closed and bounded (in any metric space)
Bounded: the balls B(x₀, n), n ∈ ℕ, form an open cover. A finite subcover means K ⊆ B(x₀, N). Closed: if kₙ ∈ K and kₙ → x, some subsequence converges in K. That subsequence also converges to x, so by uniqueness of limits x ∈ K. (In topological spaces: compact subsets of Hausdorff spaces are closed.)
Closed + bounded does NOT imply compact outside ℝⁿ
  • Infinite discrete space: closed and bounded. The cover by singletons {{x} : x ∈ X} has no finite subcover.
  • Closed unit ball of ℓ²: the vectors eₙ = (0,…,0,1,0,…) satisfy d(eₙ, eₘ) = √2 for n ≠ m, so no subsequence is Cauchy.
  • Closed unit ball of (C[0,1], d_∞): fₙ(t) = tⁿ has no uniformly convergent subsequence, because the pointwise limit is discontinuous.
  • X = (0,1] with the usual metric: X is closed in itself and bounded, but not compact. 1/n has no subsequence converging in X.
  • ℝ with d/(1+d): bounded, closed in itself, not compact.

The right generalisation is complete + totally bounded.

5.5 Key theorems about compact sets

Theorem 5.6: closed subsets of compact sets are compact
Let F ⊆ K be closed and {Uᵢ} an open cover of F. Then {Uᵢ} ∪ {X \ F} is an open cover of K. Take a finite subcover and drop X \ F; what remains still covers F. (Sequential version: a sequence in F has a subsequence converging in K, and its limit is in F because F is closed.)
Theorem 5.7: continuous image of compact is compact

If f : X → Y is continuous and K ⊆ X is compact, then f(K) is compact.

Let {Vᵢ} be an open cover of f(K). Then {f⁻¹(Vᵢ)} is an open cover of K, because each f⁻¹(Vᵢ) is open by continuity. A finite subcover f⁻¹(V₁), …, f⁻¹(Vₙ) gives f(K) ⊆ V₁ ∪ … ∪ Vₙ.
Corollary 5.8: Extreme Value Theorem

A continuous f : K → ℝ on a non-empty compact space is bounded and attains its max and min. Proof: f(K) is a compact, hence closed and bounded, subset of ℝ, so it contains its sup and inf.

Failure without compactness: f(x) = x on (0,1) attains no max or min, and 1/x on (0,1] is unbounded.

Theorem 5.9: Heine–Cantor

A continuous function from a compact metric space to a metric space is uniformly continuous.

Suppose not. Then there are ε > 0 and xₙ, yₙ with d(xₙ, yₙ) < 1/n but d(f(xₙ), f(yₙ)) ≥ ε. By sequential compactness, some subsequence x_{n_k} → x. Then y_{n_k} → x too, since d(y_{n_k}, x) ≤ 1/n_k + d(x_{n_k}, x). By continuity, f(x_{n_k}) and f(y_{n_k}) both converge to f(x), so their distance tends to 0. That contradicts ≥ ε.
Theorem 5.10: compact → Hausdorff bijections are homeomorphisms

If f : X → Y is a continuous bijection, X is compact and Y is Hausdorff (for example, a metric space), then f is a homeomorphism.

We need f⁻¹ to be continuous, that is, (f⁻¹)⁻¹(C) = f(C) closed for every closed C ⊆ X. A closed subset of a compact space is compact (5.6), its continuous image is compact (5.7), and compact subsets of a Hausdorff space are closed (5.5).
Compare

This is why [0,2π) → S¹ fails to be a homeomorphism: [0,2π) is not compact. The same map on the compact space [0,2π] isn't a bijection, but it passes to a homeomorphism once the endpoints are glued together.

Theorem 5.11: Lebesgue Number Lemma

If X is a compact metric space and {Uᵢ} is an open cover, there is a δ > 0 (a Lebesgue number) such that every set of diameter < δ lies inside a single Uᵢ.

Theorem 5.12: finite intersection property (FIP)

A collection of sets has the FIP if every finite subcollection has non-empty intersection. X is compact ⇔ every collection of closed sets with the FIP has non-empty total intersection. Proof: take complements in the open-cover definition. Consequence: nested non-empty compact sets K₁ ⊇ K₂ ⊇ … have non-empty intersection.

Other facts worth knowing
  • Finite unions of compact sets are compact. Arbitrary intersections of compact sets in a Hausdorff space are compact.
  • A compact metric space is complete, totally bounded, bounded and separable.
  • Products: X × Y is compact ⇔ X and Y are (Tychonoff's theorem extends this to arbitrary products).
  • If K is compact, F is closed and K ∩ F = ∅, then d(K, F) > 0. This can fail for two disjoint closed sets: the x-axis and the curve y = 1/x are at distance 0.
  • Compactness is a topological property.

5.6 Compactness in topological spaces

Examples
  • Any finite space is compact, under any topology.
  • Any indiscrete space is compact (the only open cover is {X}, possibly with ∅).
  • Any set with the cofinite topology is compact. One open set U₀ covers everything except finitely many points, and finitely many more sets cover those.
  • An infinite discrete space is not compact.

5.7 Practice questions

EASY 1. Show directly from the definition that (0, 1) is not compact.

Solution

The sets Uₙ = (1/n, 1), n ≥ 2, form an open cover. Any finite subcollection has union (1/N, 1) for its largest index N, and this misses 1/(2N). So there is no finite subcover.

EASY 2. Which are compact? (a) [0,1] ∪ [2,3] (b) {1/n : n ∈ ℕ} ∪ {0} (c) ℤ (d) {(x,y) : x² + y² = 1} (e) ℚ ∩ [0,1]

Solution

(a) Yes: closed and bounded. (b) Yes: closed (it contains its only limit point, 0) and bounded. (c) No: unbounded. (d) Yes: closed (preimage of {1}) and bounded. (e) No: not closed, since √2/2 is a limit of points in it but not in the set.

MEDIUM 3. Prove directly from the open-cover definition that K = {0} ∪ {1/n : n ∈ ℕ} is compact.

Solution

Let {Uᵢ} be any open cover. Some U₀ contains 0. It is open, so it contains (−ε, ε) for some ε, and hence contains 1/n for all n > 1/ε. Only finitely many points 1, ½, …, 1/N are left, and each lies in some Uᵢ. Together that's N + 1 sets. This is the standard "the limit point swallows the tail" argument.

MEDIUM 4. Let K be compact and f : K → ℝ continuous with f(x) > 0 for all x. Show there's a c > 0 with f(x) ≥ c for all x.

Solution

By the EVT, f attains its minimum at some x₀. Let c = f(x₀) > 0. (It fails on (0,1] with f(x) = x: the inf is 0 but not attained.)

HARD 5. Let (X, d) be compact and f : X → X satisfy d(f(x), f(y)) < d(x,y) for all x ≠ y. Prove that f has a unique fixed point. (Contrast with x + 1/x on [1,∞) from Ch 4.)

Solution

Let g(x) = d(x, f(x)). It is continuous, and X is compact, so g attains its minimum at some x₀. If f(x₀) ≠ x₀, then g(f(x₀)) = d(f(x₀), f(f(x₀))) < d(x₀, f(x₀)) = g(x₀), which contradicts minimality. So f(x₀) = x₀. Uniqueness: if x ≠ y are both fixed, d(x,y) = d(f(x),f(y)) < d(x,y), which is impossible. Compactness replaces the need for a uniform k < 1.

HARD 6. Show that an isometry f : X → X of a compact metric space into itself is surjective.

Solution

Suppose a ∉ f(X). f(X) is compact, hence closed, so ε = d(a, f(X)) > 0. Let xₙ = fⁿ(a). For m > n, since f preserves distances, d(xₙ, xₘ) = d(a, f^{m−n}(a)) ≥ ε, because f^{m−n}(a) ∈ f(X). So (xₙ) has no Cauchy subsequence, which contradicts sequential compactness.

Bonus: connectedness (if your course covers it)

Some courses put this in Chapter 5 or 6. It's short and often appears in exam questions about homeomorphisms, so it's worth skimming even if it isn't on your list.

Definitions
  • X is disconnected if X = U ∪ V with U, V open, disjoint and non-empty (a separation). Otherwise X is connected. Equivalently, the only clopen sets are ∅ and X, or every continuous f : X → {0,1} is constant.
  • X is path-connected if any two points are joined by a continuous path γ : [0,1] → X.
  • A connected component is a maximal connected subset.
Key results
  • The connected subsets of ℝ are exactly the intervals.
  • Continuous images of connected spaces are connected. This gives the Intermediate Value Theorem.
  • Path-connected ⇒ connected, but not conversely. The topologist's sine curve {(x, sin(1/x)) : x > 0} ∪ ({0} × [−1,1]) is connected but not path-connected.
  • Open connected subsets of ℝⁿ are path-connected.
  • The closure of a connected set is connected. A union of connected sets sharing a common point is connected.
  • ℚ is totally disconnected: {q < √2} and {q > √2} separate it. Discrete spaces with ≥ 2 points are disconnected.
Using connectedness to show X ≇ Y

If f : X → Y is a homeomorphism, then X \ {p} ≅ Y \ {f(p)}. Removing any point disconnects ℝ, but ℝ² minus a point stays connected, so ℝ ≇ ℝ². Removing 0 from [0,1) leaves it connected, but removing any point from (0,1) disconnects it, so [0,1) ≇ (0,1). Similarly S¹ ≇ [0,1].
