Section 3: Metric space fundamentals

New metrics from old

Metric induced by a norm (Exercise 3.1)

$d(x,y)=\|y-x\|$ is a metric. Later in the course: every metric space is isometric to a subset of a real normed space.

Proposition (Metric induced by an injection)

If $\phi:A\to E$ is injective into a metric space, then $d(s,t):=d_E(\phi(s),\phi(t))$ is a metric on $A$.

Examples: the standard metric on $\C$, via $\C\to\R^2$, $x_1+ix_2\mapsto(x_1,x_2)$, which recovers $|v-u|$. The bounded metric $|\tan^{-1}y-\tan^{-1}x|$ on $\R$, via the injection $\tan^{-1}:\R\to\R$.

Proposition (New metric via an increasing subadditive function)

Let $\alpha:[0,\infty[\to[0,\infty[$ satisfy

  • $\alpha(s)=0\iff s=0$;
  • increasing: $s\le t\Rightarrow\alpha(s)\le\alpha(t)$;
  • subadditive: $\alpha(s+t)\le\alpha(s)+\alpha(t)$.

Then $d'=\alpha\circ d$ is a metric for every metric $d$.

Symmetry is immediate. (MS1): $\alpha(d(s,t))=0\iff d(s,t)=0\iff s=t$. (MS3): $\alpha(d(r,t))\le\alpha(d(r,s)+d(s,t))\le\alpha(d(r,s))+\alpha(d(s,t))$, using increasing then subadditive. ∎

Examples: $at$ ($a>0$); $\min\{t,1\}$; $t/(1+t)$; $\tan^{-1}t$; $t^{1/p}$ ($p\ge1$); and $1$ for $t\ne0$, $0$ for $t=0$ (this always gives the discrete metric). The 2nd, 3rd and 4th give bounded metrics. In the 3rd, 4th and 5th, α is invertible.

Metric subspace

For $A\subset S$, $d|_{A\times A}$ is the metric induced on $A$, and $(A,d|_{A\times A})$ is a metric subspace.

Warning: a subspace can look completely different from the whole space. The standard basis vectors $\{e_1,\dots,e_n\}\subset\R^n$ get the metric $\sqrt2\,d_{\text{discr}}$. This is unlike linear subspaces.

Product metrics

Finite products: $d_p(x,y)=\|(d_1(x_1,y_1),\dots,d_N(x_N,y_N))\|_p$, for $p\in[1,\infty]$.

Countable products: $d(x,y)=\sum_{k\ge1}2^{-k}\frac{d_k(x_k,y_k)}{1+d_k(x_k,y_k)}$ (Exercise 3.5).

Isometries, Lipschitz maps, contractions

Definitions

Isometry: $d_F(f(x),f(y))=d_E(x,y)$ for all $x,y$. $E$ and $F$ are isometric if there is an isometric bijection. Isometric spaces are indistinguishable as metric spaces (like isomorphic vector spaces). Examples: inclusions of subspaces; rotations, reflections and translations of $\mathbb E^N$; $f\mapsto f(-\,\cdot)$ on $(C[-1,1],d_{\sup})$.

Lipschitz: $\exists M\ \forall x,y:\ d_F(f(x),f(y))\le M\,d_E(x,y)$. The Lipschitz constant is $\operatorname{Lip}f=\sup\{d_F(f(x),f(y))/d_E(x,y):x\ne y\}$.

Strict contraction: Lipschitz with $\operatorname{Lip}f<1$.

Bi-Lipschitz ("Lipeomorphism"): a Lipschitz bijection whose inverse is Lipschitz.

Isometries are Lipschitz (constant 1), so isometric bijections are bi-Lipschitz. $\operatorname{Lip}f=0$ means $f$ is constant.

Example (continuously differentiable ⇒ Lipschitz)

If $f\in C^1(I;\R)$, then $|f'|\le M$ (Uniform Continuity Theorem). By FTC, $|f(t)-f(s)|=|\int_s^tf'|\le M|t-s|$, so $\operatorname{Lip}f\le d_{\sup}(f',0)$. Hence $C^1(I;\R)\subset C_{\text{Lip}}(I;\R)\subset C(I;\R)\subset\F_b(I;\R)$.

Example (Lipschitz bijection that is not bi-Lipschitz)

$f:I\to I$, $x\mapsto x^2$. It is Lipschitz since $\frac{|y^2-x^2|}{|y-x|}=|x+y|\le2$. Its inverse $g(t)=\sqrt t$ is not Lipschitz: by the Mean Value Theorem, for $s,t\in\,]0,1/M[$ we get $\frac{|g(t)-g(s)|}{|t-s|}=\frac1{2\sqrt u}\ge\frac{\sqrt M}2$ for some $u$ between them. $M$ is arbitrary, so $\operatorname{Lip}g=\infty$.

Distance from a set

For nonempty $A$: $\operatorname{dist}_A(x)=\inf\{d(x,a):a\in A\}$. It is 1-Lipschitz (Exercise 3.7). $\operatorname{dist}_A(x)=0$ iff some sequence in $A$ converges to $x$. Later this is the statement "$x\in\overline A$".

Boundedness and the paradigm space $\ell^\infty(S;E)$

Diameter, bounded

$\operatorname{diam}A=\sup\{d(x,y):x,y\in A\}$ (possibly $\infty$). $A$ is bounded if $\operatorname{diam}A<\infty$. A metric (space) is bounded if $E$ itself is.

Facts:

  • Discrete spaces are bounded.
  • The supremum need not be attained.
  • $A$ is bounded iff $\sup_{a\in A}d(p,a)<\infty$ for some (equivalently, all) $p$.
  • $A\subset B\Rightarrow\operatorname{diam}A\le\operatorname{diam}B$.
Proposition (the metric space $\ell^\infty(S;E)$)

$\F_b(S;E)$ is the set of bounded functions $S\to E$ (those with $\operatorname{diam}\operatorname{Ran}f<\infty$). The sup metric $d_{\sup}(f,g)=\sup_{s\in S}d_E(f(s),g(s))$ is a metric on it.

Finite by Exercise 3.14.

(MS1): $d_{\sup}=0\iff\forall s:\ d_E(f(s),g(s))=0\iff f=g$.

(MS2): pointwise symmetry.

(MS3): for each $t$, $d_E(f(t),h(t))\le d_E(f(t),g(t))+d_E(g(t),h(t))\le d_{\sup}(f,g)+d_{\sup}(g,h)$. The right side is independent of $t$; take the sup over $t$. ∎

$\ell^\infty(\{1..N\};\R)\cong\ell^\infty(N)$ isometrically, so this massively extends the max metric. Later in the course: every metric space embeds isometrically in some $\ell^\infty(S;\R)$.

Balls and sequences

Balls and spheres

Open ball $B_r(a)=\{x:d(x,a)<r\}$. Closed ball $B_r[a]=\{x:d(x,a)\le r\}$. Sphere $S_r(a)=\{x:d(x,a)=r\}$.

The open ball and the sphere partition the closed ball. For $R>r$: $\{a\}\subset B_r(a)\subset B_r[a]\subset B_R(a)$.

Balls do not usually look like balls: in a discrete space, $B_r(a)=\{a\}$ if $r\le1$ and $B_r(a)=E$ if $r>1$.

Diameters of balls

$\operatorname{diam}B_r[a]\le\operatorname{diam}B_R(a)\le\operatorname{diam}B_R[a]\le2R$ for $R>r$.

In a discrete space, $\operatorname{diam}B_r(a)$ is $0$ if $r\le1$ or $E=\{a\}$, and $1$ if $r>1$ and $\#E\ge2$. So diam can be much less than $2r$.

In normed spaces, $\operatorname{diam}B_R(a)=\operatorname{diam}B_R[a]=2R$ (no surprises).

Openness property of open balls

$\forall p\in B\ \exists r>0:\ B_r(p)\subset B$ (Exercise 3.10 with $b=a$, $s=r$).

Sequences in a metric space

Bounded: the set of terms is bounded, equivalently $(d(a,x_n))_n$ is bounded in $\R$ for some or all $a$.

Cauchy: $\forall\eps>0\ \exists N\ \forall n,m\ge N:\ d(x_n,x_m)<\eps$. Equivalently, $\lim_N\sup_pd(x_N,x_{N+p})=0$.

Convergent to $a$: $d(x_n,a)\to0$ in $\R$.

Proposition: convergent ⇒ Cauchy ⇒ bounded (Exercise 3.11). The converses fail in general metric spaces.

Exercises for Section 3, with full solutions

Exercise 3.1 (Metric induced by a norm) 5 marks
Solution

$d(x,y)=\|y-x\|\in[0,\infty[$.

(MS1): $\|y-x\|=0\iff y-x=0\iff x=y$, by (N1) and $\|0\|=0$.

(MS2): $\|x-y\|=\|(-1)(y-x)\|=|-1|\,\|y-x\|$, by (N2).

(MS3): $\|z-x\|=\|(z-y)+(y-x)\|\le\|z-y\|+\|y-x\|$, by (N3). ∎

Exercise 3.2 (Metric induced by an injection)
Solution

$d(s,t)=d_E(\phi(s),\phi(t))\ge0$ and is finite.

(MS1): $d(s,t)=0\iff\phi(s)=\phi(t)\iff s=t$. The last step is exactly injectivity; without it, (MS1b) fails.

(MS2) and (MS3) are inherited directly from $d_E$, applied to the points $\phi(r),\phi(s),\phi(t)$. ∎

Exercise 3.3 (Associated bounded metric, $\alpha(t)=t/(1+t)$) 10 marks
Solution

Check the three hypotheses of the Proposition.

$\alpha(t)=0\iff t=0$.

Increasing: $\alpha(t)=1-\frac1{1+t}$ and $\frac1{1+t}$ decreases.

Subadditive: $\alpha(s+t)=\frac{s}{1+s+t}+\frac{t}{1+s+t}\le\frac s{1+s}+\frac t{1+t}$, since enlarging a positive denominator decreases the fraction.

Hence $\alpha\circ d$ is a metric, and it is bounded by $1$. ∎

Exercise 3.4 (Rearranged Triangle Inequality, $\ell^1$, $\ell^\infty$, convergence) 15 marks
Solution

(a) Rearranged Triangle Inequality: $|d(x,z)-d(y,z)|\le d(x,y)$. By (MS3), $d(x,z)\le d(x,y)+d(y,z)$, so $d(x,z)-d(y,z)\le d(x,y)$. Swapping $x$ and $y$ and using (MS2): $d(y,z)-d(x,z)\le d(x,y)$. Combine the two. For norms: $\big|\|x\|-\|y\|\big|\le\|x-y\|$ (take $z=0$).

(b)(i) $d_1(x,y)=\sum|y_i-x_i|$. (MS1): a sum of nonnegative terms is zero iff each term is. (MS2): $|x_i-y_i|=|y_i-x_i|$. (MS3): add the inequalities $|z_i-x_i|\le|y_i-x_i|+|z_i-y_i|$ over $i$.

(b)(ii) $d_\infty=\max_i|y_i-x_i|$. (MS1): the max is zero iff all terms are. (MS2) is clear. (MS3): for each $i$, $|z_i-x_i|\le|y_i-x_i|+|z_i-y_i|\le d_\infty(x,y)+d_\infty(y,z)$; take the max over $i$.

(c) "$x_n\to a$" means $d(x_n,a)\to0$ in $\R$, i.e. $\forall\eps>0\ \exists N\ \forall n\ge N:\ d(x_n,a)<\eps$. ∎

Exercise 3.5 (Metric on a countable product)
Solution

$d(x,y)=\sum_k(\alpha_k\circ d_k)(x_k,y_k)$ with $\alpha_k(t)=2^{-k}\frac t{1+t}$. Each $\alpha_k$ satisfies the hypotheses of the Proposition (a positive multiple of the function in Exercise 3.3), so each $\rho_k:=\alpha_k\circ d_k$ is a metric on $S_k$ with $\rho_k\le2^{-k}$. The series therefore converges by comparison with $\sum2^{-k}=1$, and $0\le d\le1$.

(MS1): $d(x,y)=0\iff$ every term is $0$ $\iff\forall k:\ x_k=y_k\iff x=y$ (equality in a product is componentwise).

(MS2): termwise.

(MS3): for each $K$, $\sum_{k\le K}\rho_k(x_k,z_k)\le\sum_{k\le K}\rho_k(x_k,y_k)+\sum_{k\le K}\rho_k(y_k,z_k)\le d(x,y)+d(y,z)$. Let $K\to\infty$ (order preservation under limits). ∎

Exercise 3.6 (Isometric bijections have isometric inverses)
Solution

(a) $f(x)=f(y)\Rightarrow d_E(x,y)=d_F(f(x),f(y))=0\Rightarrow x=y$. So every isometry is injective.

(b) For $u,v\in F$: $d_E(g(u),g(v))=d_F(f(g(u)),f(g(v)))=d_F(u,v)$, using the isometry property and then $f\circ g=\mathrm{id}_F$. ∎

Exercise 3.7 ("Distance from a set" function)
Solution

(a) For any $a\in A$: $\operatorname{dist}_A(x)\le d(x,a)\le d(x,y)+d(y,a)$. So $\operatorname{dist}_A(x)-d(x,y)$ is a lower bound for $\{d(y,a):a\in A\}$, giving $\operatorname{dist}_A(x)-d(x,y)\le\operatorname{dist}_A(y)$. By symmetry, $|\operatorname{dist}_A(x)-\operatorname{dist}_A(y)|\le d(x,y)$. Hence $\operatorname{dist}_A$ is Lipschitz with $\operatorname{Lip}\le1$.

(b) (i)⇒(ii): by the infimum version of Approximation of suprema by sequences, there are $a_n\in A$ with $d(x,a_n)\to\operatorname{dist}_A(x)=0$. Concretely, pick $d(x,a_n)<1/n$. (ii)⇒(i): $0\le\operatorname{dist}_A(x)\le d(x,a_n)\to0$, so $\operatorname{dist}_A(x)=0$ by order preservation.

(c) Apply (b) at every $x\in E$. ∎ (Later: (ii) says $A$ is dense in $E$.)

Exercise 3.8 (Diameter of a union)
Solution

(a) $A,B\subset A\cup B$, and diam is monotone under inclusion.

(b) Assume $A,B\ne\emptyset$ and both are bounded (otherwise the inequality is trivial). Let $x,y\in A\cup B$. If both are in $A$, $d(x,y)\le\operatorname{diam}A$, which is at most the right side; similarly if both are in $B$. If $x\in A$ and $y\in B$, then for any $a\in A$, $b\in B$: $d(x,y)\le d(x,a)+d(a,b)+d(b,y)\le\operatorname{diam}A+d(a,b)+\operatorname{diam}B$. Taking the infimum over $a,b$ gives $d(x,y)\le\operatorname{diam}A+I+\operatorname{diam}B$. Take the sup over $x,y$. ∎

Exercise 3.9 (Unit spheres in $\ell^p(2)$) 10 marks
Solution (picture)

$S_1(0)=\{x:|x_1|^p+|x_2|^p=1\}$ (or $\max\{|x_1|,|x_2|\}=1$ for $p=\infty$).

  • $p=1$: a diamond (square rotated 45°) with vertices $(\pm1,0),(0,\pm1)$.
  • $p=2$: the circle.
  • $p=\infty$: the square with corners $(\pm1,\pm1)$.
  • $1<p<2$: a convex curve between the diamond and the circle.
  • $2<p<\infty$: a convex curve between the circle and the square.

As $p$ increases, the spheres grow outward: since $\|x\|_\infty\le\|x\|_q\le\|x\|_p$ for $p\le q$, the ball $B_1^{(p)}\subset B_1^{(q)}$. All of them pass through $(\pm1,0)$ and $(0,\pm1)$.

Exercise 3.10 (Balls in an intersection of balls)
Solution

Take $t=\min\{r-d(p,a),\ s-d(p,b)\}$. It is $>0$ because $p$ is in both open balls. If $d(x,p)<t$, then $d(x,a)\le d(x,p)+d(p,a)<t+d(p,a)\le r$, and similarly $d(x,b)<s$. So $B_t(p)\subset B_r(a)\cap B_s(b)$. ∎

Exercise 3.11 (Convergent ⇒ Cauchy ⇒ Bounded)
Solution

(a) If $x_n\to a$ and $\eps>0$, choose $N$ with $d(x_n,a)<\eps/2$ for $n\ge N$. Then $d(x_n,x_m)\le d(x_n,a)+d(a,x_m)<\eps$.

(b) With $\eps=1$, choose $N$ with $d(x_n,x_m)<1$ for $n,m\ge N$. Let $R=\max\{d(x_1,x_N),\dots,d(x_{N-1},x_N),1\}$. Then every $x_n\in B_R[x_N]$, so $\operatorname{diam}\{x_n\}\le2R<\infty$. ∎

Exercise 3.12 (Convergence of metric values)
Solution

(a) By the Rearranged Triangle Inequality, $|d(x_n,p)-d(x_m,p)|\le d(x_n,x_m)$. So $(d(x_n,p))$ is Cauchy in ℝ, hence convergent by the completeness of ℝ.

(b) $|d(x_n,p)-d(a,p)|\le d(x_n,a)\to0$, so $d(x_n,p)\to d(a,p)$ by the Sandwich Principle. ∎

Exercise 3.13 (Convergence in product spaces)
Solution

The sum metric is $d(x,y)=d_1(x_1,y_1)+d_2(x_2,y_2)$.

(i)⇒(ii): if $x^{(n)}\to a=(a_1,a_2)$, then $0\le d_i(x_i^{(n)},a_i)\le d(x^{(n)},a)\to0$. Sandwich.

(ii)⇒(i): if $x_i^{(n)}\to a_i$, then $d(x^{(n)},(a_1,a_2))=d_1(\cdot)+d_2(\cdot)\to0+0$, by the algebra of limits. ∎

Exercise 3.14 (Finiteness of the sup metric on $\F_b(S;E)$) 5 marks
Solution

If $S=\emptyset$ there is nothing to prove (the sup of the empty set of nonnegative numbers is taken to be $0$). Otherwise fix $s_0\in S$. For every $s$: $d(f(s),g(s))\le d(f(s),f(s_0))+d(f(s_0),g(s_0))+d(g(s_0),g(s))\le\operatorname{diam}\operatorname{Ran}f+d(f(s_0),g(s_0))+\operatorname{diam}\operatorname{Ran}g$. This is a finite constant independent of $s$, so the sup is finite. ∎

In-text questions
Answers
  • Lipschitz constant 0? Then $d(f(x),f(y))\le0$, so $f(x)=f(y)$ for all $x,y$: $f$ is constant.
  • Basis vectors in $\R^n$: $\|e_i-e_j\|_2=\sqrt{1+1}=\sqrt2$ for $i\ne j$, so $d'=\sqrt2\,d_{\text{discr}}$.
  • Why is the $\tan^{-1}$ metric not induced by a norm? It is bounded (all distances are $<\pi$). A norm-metric on a nonzero space is unbounded, since $d(0,\lambda v)=|\lambda|\|v\|\to\infty$.
