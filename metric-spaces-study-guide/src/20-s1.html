Section 1: Sets, functions & countability

The language of the whole course. Expect exam questions on images and inverse images, injectivity and surjectivity, equivalence relations, countability and Cantor's theorem.

1.1 Sets and the Axiom of Choice

Definitions
  • Empty set $\emptyset$ (a letter from the Danish alphabet, not the Greek $\phi$).
  • $A\subset S$ (subset): $x\in A\Rightarrow x\in S$. $A\subsetneq S$ (proper subset): $A\subset S$ and $A\ne S$.
  • Set difference $A\setminus B:=\{s\in A:s\notin B\}=A\cap(S\setminus B)$. Here $S\setminus B$ is the complement of $B$ in the universe $S$, also written $B^\complement$.
  • Power set $\Pow(S)=\{A:A\subset S\}$.
  • For a family $\mathcal C$ of subsets of $S$: $\bigcup\mathcal C:=\{s\in S:\exists C\in\mathcal C\ s\in C\}$ and $\bigcap\mathcal C:=\{s\in S:\forall C\in\mathcal C\ s\in C\}$.
Distributive laws & de Morgan's laws $$A\cap\bigcup\mathcal C=\bigcup_{C\in\mathcal C}(A\cap C),\qquad A\cup\bigcap\mathcal C=\bigcap_{C\in\mathcal C}(A\cup C),$$ $$A\setminus\bigcup\mathcal C=\bigcap_{C\in\mathcal C}(A\setminus C),\qquad A\setminus\bigcap\mathcal C=\bigcup_{C\in\mathcal C}(A\setminus C).$$

Memory aid: taking a complement swaps $\cup$ and $\cap$.

Tricky case: $\mathcal C=\emptyset$$\bigcup\emptyset=\emptyset$ (no set contributes any element), but by convention $\bigcap\emptyset=S$ (every $s$ vacuously belongs to "all" members). This is why the universe must be known.
Cartesian products

$S\times T=\{(s,t):s\in S,t\in T\}$, and $S\times T=\emptyset\iff S=\emptyset$ or $T=\emptyset$. $S_1\times\dots\times S_N$ consists of $N$-tuples, and $S^N$ is the case where all factors are $S$.

For an indexed family $(S_\lambda)_{\lambda\in\Lambda}$: $\prod_{\lambda\in\Lambda}S_\lambda$ is the set of all families $(s_\lambda)_{\lambda\in\Lambda}$ with $s_\lambda\in S_\lambda$ (generalised sequences). Equality is componentwise: $a=b\iff\forall\lambda\ a_\lambda=b_\lambda$. If all $S_\lambda=S$, the product is written $S^\Lambda$. So $\R^\N$ is the set of all real sequences.

Strange cases. If $\Lambda=\emptyset$, the product has exactly one element (the empty family). If some $S_\mu=\emptyset$, the product is empty ("$s_\mu$ has nowhere to go").

Axiom of Choice (AC)

If $(S_\lambda)_{\lambda\in\Lambda}$ is a family of nonempty sets, then $\prod_\lambda S_\lambda\ne\emptyset$.

Equivalent form (choice function): for every indexed family $\{C_\lambda\}$ of nonempty subsets of $S$ there is $f\in\F(\Lambda;S)$ with $f(\lambda)\in C_\lambda$ for all $\lambda$.

AC is not deducible from the other axioms of set theory, but it (or an equivalent) is used throughout modern mathematics.

1.2 Functions, AC again & images

Function

A function $f$ has three ingredients: a domain (source) $S$, a codomain (target) $T$, and an unambiguous rule assigning to each $s\in S$ a unique $f(s)\in T$. We write $f:S\to T,\ s\mapsto f(s)$, and $\F(S;T)$ for the set of all such functions. Two functions are equal when all three ingredients agree.

Examples: $U\mapsto\dim U$ on the subspaces of $V$; the zero-set map $f\mapsto\{s:f(s)=0\}$; $\det:M_n(\R)\to\R$.

Basic classes of function
  1. Identity $\mathrm{id}_S:s\mapsto s$.
  2. Inclusion $\iota_{A\to S}:A\to S$, $a\mapsto a$.
  3. Indicator function $\mathbf 1_A:S\to\R$, equal to $1$ on $A$ and $0$ off $A$.
  4. Constant function equal to $t_0$.
  5. Canonical projection $\prod_jS_j\to S_k$, $(s_j)\mapsto s_k$.

Strange cases: $\F(\emptyset;T)$ has exactly one element (the empty function, whose rule is vacuous). If $S\ne\emptyset$ then $\F(S;\emptyset)=\emptyset$. If $\#S=n$ and $\#T=m$ then $\#\F(S;T)=m^n$, consistent with $m^0=1$ and $0^n=0$ for $n\ne0$.

Range, composition, restriction, extension, co-restriction
  • Range (image of $S$ under $f$): $\operatorname{Ran}f=\{f(s):s\in S\}=\{t\in T:\exists s\ f(s)=t\}$. For example $\operatorname{Ran}\mathbf 1_A$ is $\{1\}$ if $A=S$, $\{0\}$ if $A=\emptyset$, and $\{0,1\}$ otherwise. $f$ is constant $t_0$ iff $\operatorname{Ran}f=\{t_0\}$.
  • Composition $(g\circ f)(s)=g(f(s))$. It is associative, but usually $f\circ g\ne g\circ f$ (e.g. $\sin(x^2)\ne(\sin x)^2$). Also $f\circ\mathrm{id}_S=f=\mathrm{id}_T\circ f$.
  • Restriction $f|_A=f\circ\iota_{A\to S}$. An extension of $g\in\F(A;T)$ is any $f$ with $f|_A=g$.
  • Co-restriction: if $B\supset\operatorname{Ran}f$, then $f|^B:S\to B$, $s\mapsto f(s)$, satisfies $\iota_{B\to T}\circ f|^B=f$.
Injective, surjective, bijective
  • Injective: $f(s_1)=f(s_2)\Rightarrow s_1=s_2$. Equivalently (by the contrapositive) $s_1\ne s_2\Rightarrow f(s_1)\ne f(s_2)$.
  • Surjective: $\operatorname{Ran}f=T$, i.e. $\forall t\in T\ \exists s\in S\ f(s)=t$.
  • Bijective: both.

The codomain matters. $x\mapsto x^2$ is injective but not surjective as a map $\R_+\to\R$; surjective but not injective as $\R\to\R_+$; bijective as $\R_+\to\R_+$. Inclusions are injective. Canonical projections are surjective (if all factors are nonempty). Quotient maps are surjective.

Example. On $\N$, $f(n)=n+1$ is injective and $g(n)=n-1$ for $n\ge2$, $g(1)=1$ is surjective. Then $g\circ f=\mathrm{id}_\N$ is bijective, but $f\circ g$ is neither injective (since $(f\circ g)(1)=(f\circ g)(2)=2$) nor surjective (it never takes the value 1).

Proposition (Uniqueness of inverses)

If $g\circ f=\mathrm{id}_S$ and $f\circ h=\mathrm{id}_T$, then $g=h$.

$g=g\circ\mathrm{id}_T=g\circ(f\circ h)=(g\circ f)\circ h=\mathrm{id}_S\circ h=h$, by associativity. ∎
Proposition (Injectivity/surjectivity & left/right invertibility)

Let $f\in\F(S;T)$.

(a)* $f$ is injective $\iff$ there is a left inverse $g$ ($g\circ f=\mathrm{id}_S$). [*Exclude the case $S=\emptyset\ne T$.]

(b) $f$ is surjective $\iff$ there is a right inverse $h$ ($f\circ h=\mathrm{id}_T$).

(c) $f$ is bijective $\iff$ there is an inverse $k$ ($k\circ f=\mathrm{id}_S$ and $f\circ k=\mathrm{id}_T$), written $f^{-1}$.

The "if" parts follow from Exercise 1.4. For the "only if" parts (with $S,T\ne\emptyset$):

(a) Fix $s_0\in S$. Define $g(t)=s$ if $t=f(s)$, and $g(t)=s_0$ if $t\notin\operatorname{Ran}f$. This is well-defined because injectivity makes the $s$ with $f(s)=t$ unique. Then $g(f(s))=s$.

(b) Each fibre $f^{-1}(\{t\})$ is nonempty. By the Axiom of Choice there is $h:T\to S$ with $h(t)\in f^{-1}(\{t\})$, so $f(h(t))=t$.

(c) Combine (a), (b) and uniqueness of inverses. ∎

Remarks: left and right inverses are in general not unique. Even this basic result needs AC, in part (b).

Corollary (Injections entail surjections and vice versa)

Avoiding the case $S=\emptyset\ne T$: there is an injection $S\to T$ $\iff$ there is a surjection $T\to S$. (A left inverse of an injection is a surjection, and a right inverse of a surjection is an injection.)

Direct and inverse images

Direct image of $A\subset S$: $f(A)=\{f(s):s\in A\}$, sometimes written $f[A]$. It defines a set map $\Pow(S)\to\Pow(T)$. $f(S)=\operatorname{Ran}f$.

Inverse image (preimage) of $C\subset T$: $f^{-1}(C):=\{s\in S:f(s)\in C\}$, a set map $\Pow(T)\to\Pow(S)$.

Pitfall: the notation $f^{-1}(C)$ does not mean $f$ is invertible

Preimages exist for every function. Examples: $f^{-1}(\emptyset)=\emptyset$ and $f^{-1}(T)=S$. For $x\mapsto x^2$, $f^{-1}([1,4])=[-2,-1]\cup[1,2]$. For $f$ constant $t_0$, $f^{-1}(C)=S$ if $t_0\in C$ and $\emptyset$ otherwise. If $f$ is bijective with inverse $g$, then $f^{-1}(C)=g(C)$, so the two notations agree in that case.

Slogan: inverse images preserve every set operation. Direct images preserve only unions. This is why continuity is defined through inverse images of open sets in Section 4.

Counterexample showing $f(A\cap B)\subsetneq f(A)\cap f(B)$: $S=\{0,1\}$, $f$ constant, $A=\{0\}$, $B=\{1\}$. Then $f(A\cap B)=f(\emptyset)=\emptyset$, but $f(A)\cap f(B)=\operatorname{Ran}f\ne\emptyset$.

(Inverse image of intersection.) $s\in f^{-1}(\bigcap\mathcal C)\iff f(s)\in\bigcap\mathcal C\iff\forall C\ f(s)\in C\iff\forall C\ s\in f^{-1}(C)\iff s\in\bigcap f^{-1}(C)$. ∎
This uses the fact that $A=B$ iff ($\forall s$: $s\in A\iff s\in B$).

Schröder–Bernstein theorem

Theorem (Schröder–Bernstein): you must know the statement

If there is an injection $S\to T$ and an injection $T\to S$, then there is a bijection $S\to T$.

The same conclusion holds with surjections both ways, or with an injection $S\to T$ together with a surjection $S\to T$.

The proof is not examinable. Idea: find $P\subset S$ with $h(T\setminus g(P))=S\setminus P$. Then map $P$ by $g$ and $S\setminus P$ by $h^{-1}$. Such a $P$ is a fixed point of the monotone map $\psi(A)=S\setminus h(T\setminus g(A))$ on $\Pow(S)$. The Set Monotonicity Lemma provides it: $P=\bigcap\{\psi(A):\psi(A)\subset A\}$ satisfies $\psi(P)=P$.

1.3 Equivalence relations & partitions

Definition

A relation $\sim$ on a nonempty set $S$ is an equivalence relation if it is reflexive ($s\sim s$), symmetric ($s\sim t\Rightarrow t\sim s$) and transitive ($r\sim s\ \&\ s\sim t\Rightarrow r\sim t$).

The equivalence class is $[a]_\sim=\{s:s\sim a\}$. The quotient set is $S/{\sim}=\{[a]:a\in S\}$. The quotient map is $q:a\mapsto[a]$, and it is surjective. Key fact: $[a]=[b]\iff a\sim b$.

Examples: equality ($[a]=\{a\}$); the full relation ($[a]=S$); congruence mod $p$ on $\Z$ ($n\equiv_pm$ iff $p\mid(m-n)$, with classes $p\Z+k$ and $\Z=\bigcup_{k=0}^{p-1}[k]_p$). The empty relation on a nonempty set is symmetric and transitive but not reflexive, so it is not an equivalence relation.

Partition

$\mathcal C\subset\Pow(S)$ is a partition of $S$ if (1) $\bigcup\mathcal C=S$, (2) every $C\in\mathcal C$ is nonempty, and (3) $C\ne D\Rightarrow C\cap D=\emptyset$ (distinct blocks are disjoint).

Theorem (Partitions ≡ equivalence relations)

(i) If $\sim$ is an equivalence relation, then $S/{\sim}$ is a partition. (ii) If $\mathcal C$ is a partition, then $s\sim_{\mathcal C}t:\iff\exists C\in\mathcal C:\ s,t\in C$ is an equivalence relation. (iii) These two procedures are mutually inverse.

(i) By reflexivity $s\in[s]$, so the classes are nonempty and cover $S$. Suppose $r\in[s]\cap[t]$ and $u\in[t]$. Then $r\sim s$, $r\sim t$, $u\sim t$. By symmetry $u\sim t$, $t\sim r$, $r\sim s$, so by transitivity $u\sim s$. Hence $[t]\subset[s]$. Swapping the roles of $s$ and $t$ (using $r\in[t]\cap[s]$) gives $[s]\subset[t]$. So distinct classes are disjoint.

(ii) Reflexive: each $s$ lies in some $C$, because $\bigcup\mathcal C=S$. Symmetric: obvious. Transitive: if $r,s\in C$ and $s,t\in D$, then $s\in C\cap D\ne\emptyset$, so $C=D$ and hence $r,t\in C$. ∎

Theorem (Canonical decomposition of a function)

For $f\in\F(S;T)$: (a) $s_1\sim_fs_2\iff f(s_1)=f(s_2)$ is an equivalence relation. (b) $\tilde f:S/{\sim_f}\to I:=\operatorname{Ran}f$, $[s]\mapsto f(s)$, is a well-defined bijection. (c) $f=i\circ\tilde f\circ q$, where $q$ is the quotient map and $i$ is the inclusion.

Every function factorises as a surjection, then a bijection, then an injection. This is the basis of every "First Isomorphism Theorem" in algebra.

Well-defined: $[s_1]=[s_2]\Rightarrow s_1\sim s_2\Rightarrow f(s_1)=f(s_2)$. Injective: $f(s_1)=f(s_2)\Rightarrow s_1\sim s_2\Rightarrow[s_1]=[s_2]$. Surjective: $\operatorname{Ran}\tilde f=\operatorname{Ran}f=I$. Part (c) holds by definition. ∎

1.4 Countability and Cantor's theorem

Finite, countable

$S$ is finite if $S=\emptyset$ or there is a bijection $S\to\{1,\dots,K\}$. The number $K$ (0 for $\emptyset$) is unique and is called the cardinality $\#S$.

$S$ is countable if there is an injection $f:S\to\N$.

Rules for countability (memorise)
  1. $\emptyset$ and $\N$ are countable.
  2. For $S\ne\emptyset$: $S$ is countable $\iff$ there is a surjection $\N\to S$.
  3. Subsets of countable sets are countable.
  4. If $T$ is countable and there is an injection $S\to T$, or a surjection $T\to S$, then $S$ is countable.
  5. $S$ is countable $\iff$ $S$ is finite or there is a bijection $\N\to S$ (i.e. "countably infinite").
  6. $\N^N$ is countable, via the injection $(k_1,\dots,k_N)\mapsto p_1^{k_1}\cdots p_N^{k_N}$ (the first $N$ primes; uniqueness of prime factorisation).
  7. Finite products of countable sets are countable: if $\phi_i:\N\to S_i$ are surjections, then $(n_i)\mapsto(\phi_i(n_i))$ is a surjection $\N^N\to\prod S_i$.
  8. $\Q$ is countable: $\Z\times\N\to\Q$, $(n,m)\mapsto n/m$, is a surjection.
  9. A countable union of countable sets is countable: with surjections $\psi_n:\N\to C_n$, the map $(n,m)\mapsto\psi_n(m)$ is a surjection $\N\times\N\to\bigcup C_n$. (Choosing all the $\psi_n$ at once uses AC.)
Cantor's Theorem (two guises)

(1) There is no surjection $S\to\Pow(S)$, and hence no injection $\Pow(S)\to S$.

Suppose $\phi:S\to\Pow(S)$ is surjective. Let $D:=\{s\in S:s\notin\phi(s)\}$, the diagonal set. Then $D=\phi(x)$ for some $x$. If $x\in D$ then $x\notin\phi(x)=D$, a contradiction. If $x\notin D$ then $x\in\phi(x)=D$, a contradiction. ∎ (This is reminiscent of Russell's Paradox.)

(2) There is no surjection $S\to\F(S;\{0,1\})$, and no injection the other way.

Given $\phi$, write $\phi_s=\phi(s)$ and define the diagonal function $g(s)=1-\phi_s(s)$. Then $g(s)\ne\phi_s(s)$ for every $s$, so $g\ne\phi_s$ for all $s$, and $g\notin\operatorname{Ran}\phi$. ∎

Consequences. Using the bijections $\F(S;T)\cong T^S$ and $\Pow(S)\cong\F(S;\{0,1\})$ (Exercises 1.6–1.7), the sets $\Pow(\N)\cong\F(\N;\{0,1\})\cong\{0,1\}^\N$ are uncountable. Hence $\R$ is uncountable (Exercises 1.18 and 4.12). This was the key to Cantor's theory of infinite cardinals.

Theorem (Countably infinite sets are bijective to ℕ)

If $S$ is countable and infinite, then there is a bijection $S\to\N$.

Let $g:S\to\N$ be an injection and $I=g(S)$, which is infinite. Using the well-ordering of ℕ, define $i_1=\min I$ and $i_n=\min(I\setminus\{i_1,\dots,i_{n-1}\})$. Then $i_1<i_2<\cdots$ and $I=\{i_k\}$, so $k\mapsto i_k$ is a bijection $\N\to I$. Compose its inverse with the co-restriction $S\to I$ of $g$. ∎

Corollary (Schröder–Bernstein for ℕ). An injection $S\to\N$ together with a surjection $S\to\N$ gives a bijection $S\to\N$. ($S$ is countable, and it is infinite because it maps onto $\N$.)

1.5 Partial orders & Zorn's Lemma (self-study, non-examinable)

Definitions

Partial order $\le$: reflexive, antisymmetric ($s\le t\ \&\ t\le s\Rightarrow s=t$), transitive. An upper bound $u$ of $A$ satisfies $a\le u$ for all $a\in A$. A maximal element $x$ satisfies $s\ge x\Rightarrow s=x$. A chain is a totally ordered subset. A least upper bound is an upper bound below every other upper bound; it is unique by antisymmetry.

Strict partial order $<$: $s<t\Rightarrow t\not<s$, plus transitivity. Moving between $\le$ and $<$ ($s<t$ iff $s\le t$ and $s\ne t$) is a pair of mutually inverse procedures.

Total order: a partial order with comparability ($s\le t$ or $t\le s$). Strict total order: trichotomy (exactly one of $s<t$, $s=t$, $s>t$) plus transitivity.

Zorn's Lemma: if every chain in a poset has an upper bound, there is a maximal element. It is equivalent to AC. Application: the Hamel Basis Theorem (every vector space has a basis): apply Zorn to the linearly independent subsets ordered by inclusion, where a maximal element is a basis.

Exercise 1.1 (Simple intersection/union problem)

(a) TFAE: (i) $A\subset B$; (ii) $A\cap B=A$; (iii) $A\cup B=B$. (b) $(A\cup B)\setminus(A\cap B)=(A\setminus B)\cup(B\setminus A)=:A\Delta B$. (c) Draw it.

(b) $x\in(A\cup B)\setminus(A\cap B)$ ⟺ $x$ is in at least one of $A,B$ but not both ⟺ $x$ is in exactly one of them ⟺ ($x\in A$ and $x\notin B$) or ($x\in B$ and $x\notin A$) ⟺ $x\in(A\setminus B)\cup(B\setminus A)$.

Exercise 1.2 (Distributivity and de Morgan)

Verify (a) $A\cap\bigcup\mathcal C=\bigcup_{C}(A\cap C)$ and (b) $A\setminus\bigcap\mathcal C=\bigcup_C(A\setminus C)$.

Solution

(a) $x\in A\cap\bigcup\mathcal C$ ⟺ $x\in A$ and $\exists C\in\mathcal C:x\in C$ ⟺ $\exists C\in\mathcal C:\ x\in A\cap C$ ⟺ $x\in\bigcup_C(A\cap C)$.

(b) $x\in A\setminus\bigcap\mathcal C$ ⟺ $x\in A$ and not($\forall C:x\in C$) ⟺ $x\in A$ and $\exists C:x\notin C$ ⟺ $\exists C:x\in A\setminus C$ ⟺ $x\in\bigcup_C(A\setminus C)$. (The key step is negating a quantifier: $\lnot\forall=\exists\lnot$.) ∎

Exercise 1.3 (Counting injections and surjections)

$S=\{1,2\}$, $T=\{1,2,3\}$. How many (a) injections $S\to T$, (b) surjections $S\to T$, (c) surjections $T\to S$?

Solution

(a) $f(1)$ has 3 choices and $f(2)\ne f(1)$ has 2, giving 6.

(b) $\#\operatorname{Ran}f\le\#S=2<3$, so there are 0.

(c) There are $2^3=8$ functions $T\to S$. The non-surjective ones are the 2 constant functions, leaving 6. (This also illustrates the Corollary: injections $S\to T$ exist and so do surjections $T\to S$.)

Exercise 1.4 (Injectivity and surjectivity under composition)

$f:S\to T$, $g:T\to U$. (a)(i) $f,g$ injective ⇒ $g\circ f$ injective; (ii) $g\circ f$ injective ⇒ $f$ injective. (b)(i) $f,g$ surjective ⇒ $g\circ f$ surjective; (ii) $g\circ f$ surjective ⇒ $g$ surjective. (c)(i) $f,g$ bijective ⇒ $g\circ f$ bijective; (ii) $g\circ f$ bijective ⇒ $f$ injective and $g$ surjective.

Solution

(a)(i) $g(f(s_1))=g(f(s_2))\Rightarrow f(s_1)=f(s_2)$ ($g$ injective) $\Rightarrow s_1=s_2$ ($f$ injective).

(a)(ii) $f(s_1)=f(s_2)\Rightarrow g(f(s_1))=g(f(s_2))\Rightarrow s_1=s_2$, since $g\circ f$ is injective.

(b)(i) Given $u\in U$, there is $t$ with $g(t)=u$ and $s$ with $f(s)=t$, so $(g\circ f)(s)=u$.

(b)(ii) Given $u$, there is $s$ with $g(f(s))=u$, so $t:=f(s)$ satisfies $g(t)=u$.

(c) (i) follows from (a)(i) and (b)(i). (ii) follows from (a)(ii) and (b)(ii).

Note that $g\circ f$ injective does not force $g$ to be injective, and $g\circ f$ surjective does not force $f$ to be surjective. The $\N$ example ($g\circ f=\mathrm{id}$ with $f(n)=n+1$) shows both.

Exercise 1.5 (Simple injectivity problem) 10 marks

$f:\R\setminus\{1\}\to\R$, $x\mapsto\frac{2x}{x-1}$. (a) Show $f$ is injective. (b) Find $\operatorname{Ran}f$. (c) Find a left inverse $g:\R\to\R\setminus\{1\}$.

Solution

(a) If $\frac{2x}{x-1}=\frac{2y}{y-1}$ then $2x(y-1)=2y(x-1)$, i.e. $2xy-2x=2xy-2y$, so $x=y$.

(b) For $y\in\R$: $y=\frac{2x}{x-1}\iff y(x-1)=2x\iff x(y-2)=y$. If $y=2$ this says $0=2$, impossible. If $y\ne2$ then $x=\frac y{y-2}$, and $x\ne1$ (otherwise $y=y-2$). So $\operatorname{Ran}f=\R\setminus\{2\}$.

(c) Let $g(y)=\frac y{y-2}$ for $y\ne2$, and $g(2)=0$ (any value in $\R\setminus\{1\}$ works). Check: $f(x)-2=\frac{2}{x-1}$, so $g(f(x))=\frac{2x}{x-1}\cdot\frac{x-1}{2}=x$, i.e. $g\circ f=\mathrm{id}_{\R\setminus\{1\}}$. The value $g(2)$ is arbitrary, which shows left inverses are not unique.

Exercise 1.6 ($\F(S;T)\equiv T^S$)

$\phi:P=\prod_{s\in S}T_s\to F=\F(S;T)$, $(t_s)_{s\in S}\mapsto f$ with $f(s)=t_s$. Define an inverse $\psi$ and verify it. You may assume $S,T\ne\emptyset$.

Solution

(a) Define $\psi:F\to P$ by $\psi(f)=(f(s))_{s\in S}$. This lies in $P$ because each $f(s)\in T=T_s$.

(b) $\psi(\phi((t_s)_s))=\psi(f)$ where $f(s)=t_s$, which equals $(f(s))_s=(t_s)_s$, so $\psi\circ\phi=\mathrm{id}_P$ (equality in $P$ is componentwise). Next, $\phi(\psi(f))$ is the function $s\mapsto f(s)$, which has the same domain, codomain and values as $f$. So $\phi\circ\psi=\mathrm{id}_F$. Hence $\phi$ is a bijection with inverse $\psi$. ∎

Exercise 1.7 ($\Pow(S)\equiv\F(S;\{0,1\})$) 10 marks

$\chi:A\mapsto\mathbf 1_A$. (a) Define $\sigma:F\to P$. (b) Show $\sigma\circ\chi=\mathrm{id}_P$ and $\chi\circ\sigma=\mathrm{id}_F$.

Solution

(a) $\sigma(g):=g^{-1}(\{1\})=\{s\in S:g(s)=1\}$.

(b) $\sigma(\chi(A))=\{s:\mathbf 1_A(s)=1\}=A$. For $g\in F$, let $A=\sigma(g)$. If $s\in A$ then $\mathbf 1_A(s)=1=g(s)$. If $s\notin A$ then $g(s)\ne1$, so $g(s)=0=\mathbf 1_A(s)$, because $g$ only takes the values $0$ and $1$. Hence $\chi(\sigma(g))=g$. ∎

Exercise 1.8 (Images of unions and intersections)

(a) $f(\bigcup\mathcal A)=\bigcup f(A)$; (b) $f(\bigcap\mathcal A)\subset\bigcap f(A)$; and, from the text, (c) $f(A\setminus B)\supset f(A)\setminus f(B)$.

Solution

(a) $t\in f(\bigcup\mathcal A)$ ⟺ $\exists s\in\bigcup\mathcal A$ with $f(s)=t$ ⟺ $\exists A\in\mathcal A\ \exists s\in A$ with $f(s)=t$ ⟺ $\exists A:t\in f(A)$ ⟺ $t\in\bigcup f(A)$.

(b) If $t=f(s)$ with $s\in\bigcap\mathcal A$, then $s\in A$ for every $A$, so $t\in f(A)$ for every $A$. The reverse inclusion fails in general; see the constant-function example above. Equality holds if $f$ is injective.

(c) Let $t\in f(A)\setminus f(B)$, so $t=f(a)$ with $a\in A$. If $a\in B$ then $t\in f(B)$, a contradiction. So $a\in A\setminus B$ and $t\in f(A\setminus B)$. (Strict inclusion example: $f$ constant, $A=\{0,1\}$, $B=\{1\}$. Then $f(A\setminus B)=\operatorname{Ran}f$ but $f(A)\setminus f(B)=\emptyset$.) ∎

Exercise 1.9 (Unions and complements under inverse images) 10 marks

Show $f^{-1}(\bigcup\mathcal C)=\bigcup f^{-1}(C)$ and $f^{-1}(D\setminus C)=f^{-1}(D)\setminus f^{-1}(C)$; in particular $f^{-1}(T\setminus C)=S\setminus f^{-1}(C)$.

Solution

$s\in f^{-1}(\bigcup\mathcal C)$ ⟺ $f(s)\in\bigcup\mathcal C$ ⟺ $\exists C:f(s)\in C$ ⟺ $\exists C:s\in f^{-1}(C)$ ⟺ $s\in\bigcup f^{-1}(C)$.

$s\in f^{-1}(D\setminus C)$ ⟺ $f(s)\in D$ and $f(s)\notin C$ ⟺ $s\in f^{-1}(D)$ and $s\notin f^{-1}(C)$ ⟺ $s\in f^{-1}(D)\setminus f^{-1}(C)$.

Take $D=T$ and use $f^{-1}(T)=S$. ∎

Exercise 1.10 (Disjoint union of equivalence relations)

$A_1\cap A_2=\emptyset$, with $\sim_i$ an equivalence relation on $A_i$. Define $x\sim y$ iff ($x,y\in A_1$ and $x\sim_1y$) or ($x,y\in A_2$ and $x\sim_2y$). Show $\sim$ is an equivalence relation on $A_1\cup A_2$.

Solution

Reflexive: $x\in A_i$ for some $i$, and $x\sim_ix$. Symmetric: if $x,y\in A_i$ with $x\sim_iy$, then $y\sim_ix$, so $y\sim x$.

Transitive: suppose $x\sim y$ (so $x,y\in A_i$ with $x\sim_iy$) and $y\sim z$ (so $y,z\in A_j$ with $y\sim_jz$). Then $y\in A_i\cap A_j$. Since $A_1\cap A_2=\emptyset$, this forces $i=j$. By transitivity of $\sim_i$, $x\sim_iz$, so $x\sim z$. (Disjointness is used exactly here.) The resulting partition is the union of the two partitions. ∎

Exercise 1.11 (Symmetry + Transitivity ⇏ Reflexivity) 10 marks

(a) Find the logical error in the "proof" that symmetry and transitivity give reflexivity. (b) Give a counterexample.

Solution

(a) The argument says: "for all $y$ with $x\sim y$, …, therefore $x\sim x$". It assumes such a $y$ exists. If $x$ is related to nothing, the "for all $y$" statement is vacuously true and gives no information, so $x\sim x$ is never derived. What the argument does prove: if every element is related to something, then a symmetric and transitive relation is reflexive.

(b) $S=\{1,2\}$ with $\sim=\{(1,1)\}$ (only $1\sim1$). It is symmetric and transitive (check all cases), but $2\not\sim2$. The empty relation on any nonempty set also works.

Exercise 1.12 (Countability of ℤ)
Solution

Define $f:\N\to\Z$ by $f(n)=n/2$ if $n$ is even and $f(n)=-(n-1)/2$ if $n$ is odd. So $1,2,3,4,5,\ldots\mapsto0,1,-1,2,-2,\ldots$

It is a bijection, with inverse $g(k)=2k$ for $k>0$ and $g(k)=1-2k$ for $k\le0$. Check: for $k>0$, $f(2k)=k$; for $k\le0$, $1-2k$ is odd and $f(1-2k)=-(1-2k-1)/2=k$. Also $g(f(n))=n$ in both parity cases. Hence $\Z$ is countable. ∎

Exercise 1.13 (Polynomials with rational coefficients)
Solution

Let $S_n$ be the polynomials of degree at most $n$ with rational coefficients. The map $\Q^{n+1}\to S_n$, $(a_0,\dots,a_n)\mapsto a_0+a_1x+\dots+a_nx^n$, is a surjection. $\Q^{n+1}$ is countable as a finite product of countable sets, so $S_n$ is countable. Finally $S=\bigcup_{n=0}^\infty S_n$ is a countable union of countable sets, hence countable. ∎

Exercise 1.14 ($\Pow_{00}(\N)$ is countable)
Solution

Let $\Pow^{(N)}(\N)=\{A\subset\N:\#A=N\}$. Then $\Pow^{(0)}=\{\emptyset\}$ is countable. For $N\ge1$, list $A$ increasingly as $a_1<\dots<a_N$ and send $A\mapsto(a_1,\dots,a_N)\in\N^N$. This is injective, because $A$ is recovered as the set of entries. $\N^N$ is countable, so $\Pow^{(N)}(\N)$ is countable. Then $\Pow_{00}(\N)=\bigcup_{N=0}^\infty\Pow^{(N)}(\N)$ is a countable union of countable sets, hence countable. ∎

Contrast: $\Pow(\N)$ itself is uncountable (Cantor).

Exercise 1.15 (Total order ↔ strict total order) 10 marks
Solution

(a) Let $\le$ be a total order and $s<t:\iff s\le t,\ s\ne t$.

Trichotomy. If $s=t$, neither $s<t$ nor $t<s$ holds. If $s\ne t$, comparability gives $s\le t$ or $t\le s$, so $s<t$ or $t<s$. Both cannot hold, since antisymmetry would give $s=t$. So exactly one holds.

Transitivity. If $r<s$ and $s<t$, then $r\le t$. If $r=t$ we would have $r\le s\le r$, so $r=s$, a contradiction. Hence $r<t$.

(b) Let $<$ be a strict total order and $s\le t:\iff s<t$ or $s=t$.

Reflexive: $s=s$. Antisymmetric: if $s\le t$, $t\le s$ and $s\ne t$, then $s<t$ and $t<s$, contradicting trichotomy (exactly one holds). Transitive: if any of the relations is an equality the claim is immediate; otherwise use transitivity of $<$. Comparable: trichotomy gives $s<t$, $s=t$ or $t<s$. ∎

Exercise 1.17 (Relations via functions & partitions) 20 marks

$f:S\to T$, $\mathcal C$ a partition of $S$. $t_1\sim t_2$ iff $\exists A\in\mathcal C:\ f^{-1}(\{t_1,t_2\})\subset A$. (a) Reflexive? If $f$ is injective? (b) Symmetric? If $f$ is bijective? (c) Transitive? If $f$ is surjective?

Solution

(a) Not necessarily reflexive. $t\sim t$ iff the fibre $f^{-1}(\{t\})$ lies inside one block. Counterexample: $S=\{1,2\}$, $\mathcal C=\{\{1\},\{2\}\}$, $T=\{t\}$, $f$ constant. Then $f^{-1}(\{t\})=\{1,2\}$ is in no single block, so $t\not\sim t$.
If $f$ is injective, it is reflexive: $f^{-1}(\{t\})$ has at most one point. If it is empty, it lies in any block ($\mathcal C\ne\emptyset$ since $S\ne\emptyset$). If it is $\{s\}$, then $s$ lies in some block, since the blocks cover $S$.

(b) Always symmetric, with no hypothesis on $f$, since $\{t_1,t_2\}=\{t_2,t_1\}$. In particular it is symmetric when $f$ is bijective.

(c) Not necessarily transitive. $S=\{1,2\}$, $\mathcal C=\{\{1\},\{2\}\}$, $T=\{a,b,c\}$, $f(1)=a$, $f(2)=c$. Then $f^{-1}\{a,b\}=\{1\}$, so $a\sim b$; $f^{-1}\{b,c\}=\{2\}$, so $b\sim c$; but $f^{-1}\{a,c\}=\{1,2\}$, so $a\not\sim c$. The value $b$ is missed by $f$, and that is what breaks transitivity.
If $f$ is surjective, it is transitive: let $t_1\sim t_2$ via $A$ and $t_2\sim t_3$ via $B$. Since $f$ is surjective, $\emptyset\ne f^{-1}(\{t_2\})\subset A\cap B$. Distinct blocks are disjoint, so $A=B$. Then $f^{-1}\{t_1,t_3\}\subset f^{-1}\{t_1,t_2\}\cup f^{-1}\{t_2,t_3\}\subset A$, so $t_1\sim t_3$.

So if $f$ is bijective, $\sim$ is an equivalence relation, and its partition is $\{f(A):A\in\mathcal C\}$.

Exercise 1.18 (Uncountability of ℝ) 10 marks

(a) $\psi:\{0,1\}^\N\to\R$, $a\mapsto\sum_{n\ge1}a_n10^{-n}$ is injective. (b) Deduce that $\R$ is uncountable.

Solution

(a) The series converges by comparison with $\sum10^{-n}$. Let $a\ne b$ and let $m$ be the least index with $a_m\ne b_m$ (well-ordering); WLOG $a_m=1$, $b_m=0$. Then $$\psi(a)-\psi(b)=10^{-m}+\sum_{n>m}(a_n-b_n)10^{-n}\ \ge\ 10^{-m}-\sum_{n>m}10^{-n}=10^{-m}-\tfrac19\,10^{-m}=\tfrac89\,10^{-m}>0.$$ So $\psi(a)\ne\psi(b)$.

(b) Suppose $\R$ were countable, with injection $j:\R\to\N$. Let $\beta:\Pow(\N)\to\F(\N;\{0,1\})\to\{0,1\}^\N$ be the bijection from Exercises 1.6–1.7. Then $j\circ\psi\circ\beta:\Pow(\N)\to\N$ is an injection (a composition of injections), contradicting Cantor's Theorem (no injection $\Pow(S)\to S$). Hence $\R$ is uncountable. ∎

Exercise 1.19 (Characterisation of infiniteness) 10 marks

$S$ is infinite ⟺ there is an injection $\N\to S$.

Solution

(⇐) Suppose $\iota:\N\to S$ is injective but $S$ is finite. If $S=\emptyset$ there is no map from $\N$ at all. Otherwise there is a bijection $\beta:S\to\{1,\dots,K\}$, and $\beta\circ\iota$ restricted to $\{1,\dots,K+1\}$ is an injection of a $(K+1)$-element set into a $K$-element set, contradicting the pigeonhole principle.

(⇒) Let $S$ be infinite. By AC, take a choice function $c$ on $\Pow(S)\setminus\{\emptyset\}$. Define recursively $s_1=c(S)$ and $s_{n+1}=c(S\setminus\{s_1,\dots,s_n\})$. The set $S\setminus\{s_1,\ldots,s_n\}$ is nonempty, since otherwise $S$ would be finite. Then $s_{n+1}\notin\{s_1,\dots,s_n\}$, so $n\mapsto s_n$ is injective. ∎

In-text exercise (Countability remark 2)

For $S\ne\emptyset$: countable ⟺ there is a surjection $\N\to S$.

Solution

An injection $f:S\to\N$ has a left inverse $g:\N\to S$ (here $S\ne\emptyset$ is needed), and $g$ is surjective because $g\circ f=\mathrm{id}_S$ (Exercise 1.4(b)(ii)). Conversely, a surjection $g:\N\to S$ has a right inverse $h$ (by AC; or explicitly, $h(s)=\min g^{-1}(\{s\})$ by well-ordering), and $h$ is injective. ∎
