The big picture for Week 1

The first week is likely about learning how a physical or mathematical process can be represented as a
linear system. The basic language is

                               input u(t) −→ system −→ output y(t) .

A system may also have an internal state x(t), which stores enough information about the system at
time t to determine how it evolves in the future.
The most important progression is likely to be

           physical system −→ block diagram −→ differential equation −→ X ′ = AX + Bu .


Lecture 1 (about 1 hour): What is a linear system?

   Likely learning goals
   By the end of Lecture 1 you should be able to identify the input, output and state of a system, recog-
   nise basic linear operators, read simple block diagrams, and distinguish open-loop from feedback
   systems.


1. Input, output and state

The notes describe a system evolving in time t > 0 using:

• Input u(t): what is supplied to or drives the system.
• Output y(t): what we observe or measure.
• State x(t): the internal variables needed to determine future behaviour.

A key question throughout the module is:

                                      How does y(t) depend on u(t)?

4. Open-loop and feedback systems

An open-loop system processes the input and produces the output without sending the output back into
the system.
A feedback (closed-loop) system sends some of the output back through the system. This is central to
control theory.

Lecture 2 (about 1 hour): From differential equations to state-space
form
   Likely learning goals
   By the end of Lecture 2 you should understand how linear differential equations can be represented
   as systems, why matrix notation is useful, and how a higher-order scalar ODE can be rewritten as
   a first-order vector equation.


1. Matrix amplifiers and vector signals

The course extends scalar block diagrams to vector inputs. A matrix block acts as

                                                     U 7→ BU.

This allows the same diagram language to handle multiple inputs and multiple outputs.


2. Linear differential operators

The notes introduce operators of the form

                                             dn f            dn−1 f
                           Lf (t) = an (t)        + an−1 (t)        + · · · + a0 (t)f (t).
                                             dtn             dtn−1
If the coefficients aj are constants, this is a constant-coefficient linear differential operator.
A typical equation is
                           an y (n) + an−1 y (n−1) + · · · + a0 y = bm u(m) + · · · + b0 u.
The notes show that such an equation can be realised as a feedback system using integrators, differentia-
tors, amplifiers, taps and summing junctions.


3. The damped harmonic oscillator

This is one of the key examples and is likely to reappear throughout the module:

                                                y ′′ + βy ′ + γy = u.

Interpretation:

• y = displacement,

• y ′ = velocity,

• y ′′ = acceleration,

• u(t) = external driving force,

• −βy ′ = damping,

• −γy = restoring force.

The notes use car suspension as the motivating physical example.

What you should know by the end of Week 1

You should be comfortable with the following checklist:

 1. Explain what input, output and state mean.

 2. State the definition of a linear map.

 3. Recognise an amplifier, integrator, differentiator, tap and summing junction.

 4. Translate a simple equation into a block diagram and back again.

 5. Explain the difference between open-loop and feedback systems.

 6. Distinguish positive from negative feedback in simple examples.

Best things to revise before Week 1

You do not need to pre-learn control theory. The most useful background is:

• matrix multiplication and matrix-vector multiplication;

• 2 × 2 matrices;

• basic differentiation and integration;

• first- and second-order ODE notation;

• the definition of a linear map;

• changing a second-order ODE into a pair of first-order equations.


Quick self-test

Try these without looking back:

 1. What is the difference between an input u(t) and a state x(t)?

 2. What does an amplifier labelled a do to a signal u?

 3. What is the difference between a tap and a summing junction?

 4. Why is mv ′ = −kv + u an example of negative feedback?

 5. For y ′′ + 4y ′ + 3y = u, let v = y ′ . Write down the two first-order equations.

 6. For the same equation, write down A and B in X ′ = AX + Bu.
