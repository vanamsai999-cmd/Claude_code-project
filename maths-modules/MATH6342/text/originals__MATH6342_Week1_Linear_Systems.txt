1. The big idea of Week 1

The course starts by thinking of a system as a “machine” that evolves in time. The system receives an
input, has an internal state, and produces an output.


                     u(t)                     linear system                       y(t)
                    input                       state x(t)                       output


The central question is:

                            How does the input u(t) determine the output y(t)?

Examples mentioned in the notes include wind turbines, heating systems, electrical networks, vehicle
suspension, epidemics, predator–prey systems and musical filters.

   Core language

   Input u(t): the signal or forcing applied to the system.
   State x(t): variables that describe the internal condition of the system.
   Output y(t): what the system produces or what we observe.

   Why this matters
   Block diagrams are built by connecting simple linear operations. Instead of seeing a long differential
   equation as one intimidating object, you break it into small pieces: multiply, add, differentiate and

4. Open-loop and feedback systems

Open-loop

An open-loop system processes the input and produces an output, but the output is not fed back into
the system.
Conceptually:
                                             u −→ system −→ y.


Closed-loop / feedback

In a feedback system, part of the output is returned to the input side and influences future behaviour.


                              u         +                    system                  y




                                                          feedback

   Positive feedback
   The returned output reinforces the behaviour of the system. Example from the notes:
                                            dx
                                               = kx + u,         k > 0.
                                            dt
   A larger state x creates further growth.

   Negative feedback
   The returned signal opposes change and can stabilise behaviour. For the cyclist example,
                                                   dv
                                               m      = −kv + u.
                                                   dt
   The faster the cyclist moves, the larger the opposing air-resistance term −kv.



5. Linear differential equations as systems

The course next connects block diagrams with differential equations. A general linear differential operator
has the form
                                         dn f         dn−1 f
                          Lf (t) = an (t) n + an−1 (t) n−1 + · · · + a0 (t)f (t).
                                         dt           dt
For constant coefficients, equations of the form

                                  an y (n) + · · · + a0 y = bm u(m) + · · · + b0 u

can be realised using amplifiers, summing junctions, integrators and differentiators.

   What the lecturer is trying to show
   A differential equation is not just an equation to solve. It can also be interpreted as a network of
   connected linear operations. This point of view becomes important later for control systems.

6. The damped harmonic oscillator

A key example that appears early and returns later is

                                          y ′′ + βy ′ + γy = u.

Interpretation:

    • y = displacement,

    • y ′ = velocity,

    • y ′′ = acceleration,

    • u(t) = external driving force,

    • −γy = restoring force from a spring,

    • −βy ′ = damping from a shock absorber.

The notes use vehicle suspension as a physical example.

8. What you should know by the end of Week 1

You should aim to be able to:

    1. explain the meaning of input, state and output;

    2. recognise examples of linear systems;

    3. state what it means for an operator to be linear;

    4. recognise amplifiers, integrators, differentiators, taps and summing junctions;

    5. translate simple equations into block diagrams and back;

    6. distinguish open-loop and closed-loop/feedback systems;

    7. explain positive versus negative feedback;

    8. understand how a differential equation can be viewed as a feedback system;

    9. rewrite a second-order ODE as a first-order matrix system;

   10. recognise the state-space form X ′ = AX + Bu.

10. Quick self-test

Try these without looking back:

    1. What are the input, state and output of a system?

    2. What does an amplifier block labelled a do to a signal u?

    3. What is the difference between a tap and a summing junction?

    4. What makes a system a feedback system?

    5. Is mv ′ = −kv + u an example of positive or negative feedback?

    6. Rewrite y ′′ + 3y ′ + 2y = u as a system of two first-order equations.

    7. Write that system in the form X ′ = AX + Bu.
