1 Chapter 1: Linear systems and their description (frames 6–30)

 KEY IDEA / DEFINITION

 A system has input u(t), internal state x(t) and output y(t). The state contains sufficient information, together
 with future input, to predict future behaviour. For n states, m inputs and p outputs,

                                              ẋ = Ax + Bu,         y = Cx + Du

 with A ∈ Cn×n , B ∈ Cn×m , C ∈ Cp×n , D ∈ Cp×m . A governs evolution, B input effects, C measurement, D
 instantaneous feedthrough. SISO means one input/one output; MIMO means multiple inputs/outputs.

 FORMULA / THEOREM

 An operator L is linear when L(af +bg) = aLf +bLg for all scalars a, b. Examples: differentiation, integration from
 a fixed endpoint, multiplication by a fixed function and evaluation at a fixed time (with suitable domain/codomain).
 A time-varying coefficient a(t) may still define a linear operator.

 KEY IDEA / DEFINITION

 Reading block diagrams: a gain k sends u 7→ ku; a differentiator sends u 7→ u′ ; an integrator sends u 7→ u; a tap
                                                                                                           R

 copies a signal; a summing junction adds signals with their indicated signs. An open loop has no feedback circuit; in
 a closed loop some downstream signal returns upstream. Kirchhoff’s current law balances currents entering/leaving
 a junction, and voltage law says signed voltages around a closed circuit sum to zero.

 KEY IDEA / DEFINITION

 Realization. A realization of a rational transfer function T (s) is matrices (A, B, C, D) producing it. A scalar
 strictly proper rational b(s)/a(s) with monic denominator can be realised using the companion matrix of a(s),
 B = en and a suitable output row C built from numerator coefficients; a proper function may also require D ̸= 0.
 Equivalent transfer functions can have distinct state-space realizations.

 EXAM TIPS / METHOD
 When asked to realise a rational function: divide polynomials first to identify any D term; construct A from
 denominator; set B = en ; choose C to fit numerator; explicitly verify C(sI −A)−1 B +D. For eigenvalue/eigenvector
 questions, solve (A − λI)v = 0 rather than dividing by a singular matrix.

 COMMON ERROR
 Do not confuse internal eigenvalues of A with poles of a nonminimal transfer function: pole–zero cancellation can
 hide a state mode in T (s).

 FORMULA / THEOREM

 Matrix-valued Laplace transforms: L{eAt }(s) = (sI − A)−1 for sufficiently large ℜs. For ẋ = Ax + Bu,

 EXAM TIPS / METHOD

4 Chapter 4: Frequency response and stability (frames 135–161)

 KEY IDEA / DEFINITION

 A sinusoidal input can be represented using eiωt . If a stable LTI system has transfer function T (s), its steady-
 state sinusoidal response uses T (iω): magnitude |T (iω)| gives gain and argument arg T (iω) gives phase shift. The
 Nyquist plot traces T (iω) in the complex plane; Bode plots show gain (often 20 log10 |T (iω)| decibels) and phase
 versus logarithmic frequency.

 WORKED: frequency response of a first-order filter
 For T (s) = 1/(s + 2),

                                     2 − iω                      1
                          T (iω) =          ,   |T (iω)| = √          ,   arg T (iω) = − arctan(ω/2).
                                     4 + ω2                    4 + ω2
 At ω = 0, gain = 1/2 and phase = 0. At high frequency, gain tends to 0 and phase tends to −π/2. On a decibel
 plot, DC gain = 20 log10 (1/2) ≈ −6.02 dB.

 FORMULA / THEOREM
 Three different stability notions:
 • Asymptotic internal stability: every unforced state tends to zero, equivalently ℜλ < 0 for every eigenvalue
    of A (continuous-time finite-dimensional LTI).
 • Marginally stable free dynamics: bounded trajectories without universal decay can occur when imaginary-
    axis eigenvalues are semisimple and all others lie in the open left half-plane.
 • BIBO stability: every bounded input produces bounded zero-state output. For a proper rational transfer
    function, no uncancelled poles may lie in the closed right half-plane.
 A nonminimal realization can be BIBO stable without being internally asymptotically stable; check the question’s
 exact definition. The lectures present sufficient internal eigenvalue conditions and their relationship to BIBO
 stability.

 WORKED: damping classifications

 For y ′′ + βy ′ + γy = u, the free characteristic equation is λ2 + βλ + γ = 0 and

                                                         −β ± β 2 − 4γ
                                                               p
                                                  λ1,2 =                 .
                                                                 2
 Assuming γ > 0, β > 0: if β 2 > 4γ it is overdamped (two real negative roots); = critically damped (repeated
 negative root); < underdamped (complex conjugates with negative real part). If β = 0, purely imaginary roots
 lead to persistent undamped oscillations; forcing near the natural frequency can produce resonance.

 FORMULA / THEOREM

 Useful bounds: If A is Hurwitz (all eigenvalues have negative real parts), there are M, α > 0 such that ∥eAt ∥ ≤
 M e−αt . For bounded input ∥u(t)∥ ≤ U , the forced state is bounded by M ∥x0 ∥ + M ∥B∥U/α. The original slides
 discuss bounded matrix exponentials, Jordan-block conditions and proofs.

 EXAM TIPS / METHOD

 To classify stability: find eigenvalues/poles, sketch their real parts, check multiplicities/Jordan blocks on the
 imaginary axis, and distinguish state stability from input-output stability. For frequency plots calculate real and
 imaginary parts, magnitude and phase separately. Explain which frequency range a sketch refers to.

 COMMON ERROR
 A pole on s = iω prevents the usual frequency-response value at that frequency. Also, 20 log10 is for amplitude
 gain; power ratios use 10 log10 .

 KEY IDEA / DEFINITION

 Stable rational-function ring (course theme). The slides denote by S a class of rational functions stable
 under addition and multiplication (subject to their specified stability/properness convention). Polynomial Euclidean
 algorithms find greatest common divisors, and Bezout identities take the form a(s)x(s) + b(s)y(s) = d(s). If a, b
 are coprime then d = 1. Related constructions over stable rational functions underpin controller parametrisation.

 WORKED: Euclidean algorithm and Bezout

 Let a(s) = s2 + 3s + 2 = (s + 1)(s + 2) and b(s) = s + 1. Polynomial division gives

                                                a(s) = (s + 2)b(s) + 0.

 So gcd(a, b) = s + 1, not 1. The identity a − (s + 2)b = 0 shows the shared factor; no polynomials x, y satisfy
 ax + by = 1 because both left terms are divisible by s + 1. If b = s + 3 instead, division gives a = s(s + 3) + 2 so
 1 = 21 a − 2s b and they are coprime.

 LYAPUNOV AND SYLVESTER EQUATIONS
 For ẋ = Ax, choose V (x) = x∗ P x with P = P ∗ > 0. Then

                                                V̇ = x∗ (A∗ P + P A)x.

 A standard continuous-time Lyapunov criterion: A is Hurwitz iff for each Q = Q∗ > 0 there is a unique P = P ∗ > 0
 solving
                                               A∗ P + P A = −Q.

 Indeed V̇ = −x∗ Qx < 0 for nonzero x. The Sylvester equation has form AX + XB = C; uniqueness depends on
 the spectra of A and −B being disjoint. Sylvester’s positive-definiteness criterion: a Hermitian matrix is positive
 definite iff all leading principal minors are positive.

 WORKED: one-dimensional Lyapunov proof
 Take A = [−2] and choose Q = [1]. The Lyapunov equation reads (−2)P + P (−2) = −1, i.e. −4P = −1, so
  P = 1/4 > 0 . Let V = x2 /4. Then V̇ = (x/2)(−2x) = −x2 < 0 for x ̸= 0: the origin is asymptotically stable.

 WORKED: Sylvester equation

 Solve AX + XB = C for scalars A = [2], B = [3], C = [10]. Then 2X + 3X = 10 so X = 2 . The relevant spectra
 are {2} and {−3}, disjoint, so this solution is unique.

 EXAM TIPS / METHOD

 For controller questions: (1) label plant/controller and feedback sign; (2) write closed-loop equations and check
 well-posedness; (3) derive the exact characteristic polynomial; (4) determine right-half-plane zeros/eigenvalues; (5)
 check internal stability and cancellations. For Lyapunov: propose Hermitian Q > 0, solve for P , verify Hermitian
 and positive definite, then explicitly compute V̇ .

 COMMON ERROR
 Nyquist counts cannot be used without a defined contour and an accurate number of open-loop unstable poles. A
 stable closed-loop input-output transfer function alone need not guarantee stability of every internal signal.

 simplification. BIBO: bounded input yields bounded output. Hurwitz matrix: every     R t eigenvalue strictly in the

 gcd is a unit, e.g. 1 in polynomial arithmetic. Well posed: feedback equations determine the internal signals
