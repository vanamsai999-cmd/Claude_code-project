144 Gain and Phase

In engineering, the frequency response is relatively easy to measure. The
polar decomposition of the frequency response function gives the gain Γ
and phase ϕ.
• Gain measures how much the device amplifies a signal. If Γ > 1 (so
log Γ > 0), then the device makes the signal bigger.
• The phase describes the relative position of peaks in the output versus
the input.
Definition (Gain and Phase)
Define the frequency response to be T (iω), and make a polar
decomposition T (iω) = Γ(ω)e iϕ(ω) . Then define the gain (or amplitude
gain) of the system to be Γ(ω) = |T (iω)| at angular frequency ω ∈ R;
define the phase (shift) to be ϕ(ω) = arg T (iω). The Nyquist locus is
the curve {T (iω) : −∞ ≤ ω ≤ ∞} in the complex plane.

148 Scales on the Bode plot and phase plot

The Bode plot is the logarithm of the gain log Γ in decibels versus ω in
radians per second, with ω > 0 plotted on a log scale. Going from left to
right on the Bode plot, ω increases from 0 to ∞, and iω goes up the
imaginary axis. Recall that 360◦ is equivalent to 2π radians, and be
careful with the scales on the plots. The phase (or phase shift) ϕ(ω) is
the change in phase of the signal between input and output at a given
input frequency. Phase ϕ in degrees is plotted against ω in radians per
second, with ω > 0 on a log scale.
i) If ϕ(ω) > 0, there is phase gain, so the output runs ahead of the input.
ii) If ϕ(ω) < 0, there is a phase lag, so the output runs behind the input.
iii) If ϕ = 0, then the input and output are said to be in phase.
iv) If ϕ = π (or 180◦ ), then the input and output are in anti-phase so
input peaks emerge as output troughs. Anti-phase signals are used in
noise-cancelling headphones, where a sound is cancelled by a sound in
anti-phase. Anti-phase is also used in optical lens coatings, to reduce
reflections.

152 Stability cases


Consider dX /dt = AX with X (0) = X0 . This has solution
X (t) = exp(tA)X0 , and we distinguish the following cases.
(i) Exponentially stable: there exist M, δ > 0 such that
∥X (t)∥ ≤ Me −δt for all t > 0 and all X0 . This occurs when ℜλj < 0 for
all eigenvalues λj . This is BIBO stable.
(ii) Marginally stable: X (t) is bounded for t > 0 for all X0 , which
occurs when ℜλj < 0, or ℜλj = 0 and the corresponding Jordan blocks
are all of size 1 × 1. Later we will regard this marginal case as BIBO
unstable.
(iii) Unstable: X (t) (t > 0) is unbounded for some X0 , which occurs
when either ℜλj > 0 for some eigenvalue λj of A, or ℜλj = 0 for some λj
that has a Jordan block of size ≥ 2. This is also BIBO unstable.
