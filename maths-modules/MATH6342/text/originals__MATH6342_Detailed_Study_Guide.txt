1.1    A slower explanation: what makes a system linear?

  Superposition is a test, not just a slogan
  A signal is a function of time. To say that an operator L is linear is to say that it respects
  both addition and scalar multiplication:

                                   L(αf + βg) = αLf + βLg.

 You can check this without solving a differential equation. Differentiation passes because
 (αf + βg)′ = αf ′ + βg ′ . Integration from a fixed starting point passes because the
 integral distributes over a sum. Multiplication by a known function h(t) also passes:
 h(αf + βg) = αhf + βhg.
 This last example is useful: linear does not mean constant coefficients. The map f 7→ tf (t)
 is linear, although its coefficient depends on time. It is not time invariant: delaying f
 does not have the same effect as delaying the product tf (t). In contrast, f 7→ f (t)2 is
 nonlinear: (f + g)2 contains 2f g.
 There is also a difference between a linear rule and a rule containing a fixed offset. If
 L(f ) = 3f + 2, then L(0) = 2, whereas every linear map must send zero to zero. Such
 a map is affine. A fixed nonzero initial state has a similar effect on the input-output
 map: the free response is an additional term independent of the input. That is why
 superposition of input responses is normally stated with zero initial conditions.

    Why the field is usually complex
    Physical inputs can be real, but complex numbers make eigenvalues and sinusoidal signals
    easier to handle. For a real-coefficient system, solve using eiωt and take real parts to

    commutes with taking real parts. Complex algebra is a calculation tool; the final physical
    output can still be real.



2      Modelling: states, block diagrams and reduction of
       order
    What the four matrices actually do
    A continuous-time, constant-coefficient linear system is

                                  Ẋ = AX + Bu,                y = CX + Du.

    A describes how states influence their own rates of change; B tells where input enters; C
    selects or combines states into the measured output; D is immediate feedthrough. The
    state stores the information needed to predict future evolution once the input is known.
    For n states, k inputs and m outputs, the dimensions are

                          A : n × n,     B : n × k,          C : m × n,       D : m × k.

    SISO means k = m = 1; MIMO allows several inputs and outputs. Dimensions are a
    useful error detector. Linearity means superposition of zero-initial-state responses; a
    fixed nonzero initial state adds a free response.

2.1    Building a state model one decision at a time

  A state must remember the information that the output alone forgets
  Suppose two masses on springs are at the same position at time zero. One is moving
  to the right, the other to the left. Even with identical future forces, their positions will
  immediately become different. Position alone is therefore not enough to specify the state:
  velocity is also needed.
  For a second-order scalar ODE, two initial values are normally required. The state vector
  simply collects these values into a first-order description. For an nth-order equation,
  the derivative-state construction stores n values. The first-order equation has more
  components, but each component only involves one derivative.
  The output need not reveal every state. In a vehicle suspension model the state may
  contain displacement and velocity, while the sensor reports only displacement. Then
  C = (1, 0) selects the first component. If the sensor reports 2x + 3v, use C = (2, 3). The
  dynamics A, B do not change just because a different quantity is measured.

  Reading an integrator diagram backwards
  Begin at an integrator output x. The signal immediately before that integrator must be
  x′ . Trace every branch entering its summer and add its signed contributions. Repeat for
  every integrator. Finally trace the output summer to get the algebraic output equation.
  For example, if the input to the first integrator is −2x1 + 4x2 + u and the second receives
  3x1 − u, then the rows of A are (−2, 4) and (3, 0), and the entries of B are 1, −1. This
  read-back step is the quickest check of your own diagram.

2.2    The opening feedback examples worked through fully

  Worked example | Positive feedback and Black’s algebraic amplifier
  The lecture example has y = u + θy, where 0 < θ < 1. Rearranging gives (1 − θ)y = u
  and hence y = u/(1 − θ). For θ = 0.9, the gain is 10.
  This particular model is algebraic rather than dynamic: it has no time derivative and no
  stored state. Its solvability requires 1 − θ ̸= 0. At θ = 1, the equation reads y = u + y, so
  a nonzero u gives no solution, while u = 0 gives infinitely many possible outputs. That
  is a simple illustration of failure of well-posedness.
  If noise n is added at the same input junction, the equation becomes y = u + n + θy and
  the noise is multiplied by the same gain. Amplifying the desired input also amplifies that
  noise. The diagram alone does not promise good signal quality.

    denominator.

    General differential operators and the meaning of order
    An operator L = an (t)Dn + · · · + a0 (t) is linear because it combines differentiation and
    multiplication by known coefficients. Its order is the highest derivative with a nonzero
    coefficient. When the leading coefficient is nonzero, divide through before reducing order.
    If the leading coefficient vanishes at a time, the usual first-order reduction may fail there.
    The constant-coefficient state-space tools in this module assume that the resulting A is
    constant; time-varying linearity alone does not justify writing etA .

3.1   The algebra behind the formulas, explained in smaller steps

  Why eigenvectors simplify repeated multiplication
 An eigenvector v points in a direction that A does not mix with other directions: Av = λv.
 Applying A again gives A2 v = λ2 v. After k applications, Ak v = λk v. If a basis consists
 of eigenvectors, every vector can be split into these independent directions, and each
 direction evolves by a scalar factor.
 This explains diagonalisation. With eigenvectors as columns, AS = S∆. Multiplying by
 S −1 yields A = S∆S −1 . The matrix S −1 changes coordinates into the eigenvector basis,
 ∆ acts component by component, and S changes back.

5.1    Understanding forcing, transient motion and steady response
  What the two parts of the solution tell you

  The term etA X0 records what the system would do if the input were switched off. If A is
  stable, this term tends to zero and is called a transient. The convolution term records
  the accumulated effect of the input. The factor e(t−r)A tells you that an input applied



                                                        19
MATH6342 | Linear Systems                                                               Sai Vanam



  long ago is damped more strongly than one applied just now.
  An input can also create a transient. Switching on a constant force at time zero does not
  usually put the system immediately at its new equilibrium. The forced response contains
  an equilibrium part plus a part that corrects the initial mismatch. Thus “forced” does
  not mean “already steady”, and “transient” does not mean “caused only by the initial
  state”.
  For constant input u0 , an equilibrium Xe satisfies AXe + Bu0 = 0. If A is invertible, it is
  Xe = −A−1 Bu0 . Subtracting the equilibrium gives (X − Xe )′ = A(X − Xe ), so

                                  X(t) = Xe + etA (X0 − Xe ).

  If A is stable, X(t) tends to Xe . If A is singular, the equilibrium equation can have no
  solution or many solutions, so do not use A−1 without checking.

8      Transfer functions and realization
    The central formula and its limitations
    With zero initial state,
                                     T (s) = D + C(sI − A)−1 B.
    It is rational and proper; T (∞) = D. For MIMO, T has size m × k. Its finite poles
    can only occur at eigenvalues of A, but some eigenvalue factors may cancel. A transfer
    function records input-output behaviour, not every possible hidden state mode.
    For a scalar ODE a(D)y = b(D)u with suitable zero initial data, T (s) = b(s)/a(s). For
    instance y ′′ + 5y ′ + 4y = u′ − 7u gives T = (s − 7)/(s2 + 5s + 4).

    Method | Calculate T without taking a full inverse
    1. Form sI − A with particular care over signs.
    2. Solve (sI − A)v = B for the vector v using elimination.
    3. Compute T = D + Cv and simplify.
    4. Factor numerator and denominator; cancel common factors before listing poles.
    5. Check the large-s limit: it must equal D.
    The adjugate formula is also valid, but computing every entry of a 3 × 3 inverse is often
    unnecessary.

8.1    Realization as a construction you can reproduce

  Why the denominator determines the internal dynamics
  The equation (sI −A)v = en for a companion matrix produces a chain v2 = sv1 , v3 = s2 v1 ,
  and so on. The last row closes that chain by requiring q(s)v1 = 1. Thus the denominator
  is built into the state dynamics before the output coefficients are chosen.
  The row C then mixes the components (1, s, . . . , sn−1 )/q(s) into any desired strictly proper
  numerator. Feedthrough D supplies the constant part of a proper rational function.
  These are separate jobs: A, B create a basis of dynamic responses; C, D combine them
  into the required input-output map.
  An improper rational function such as s + 1 cannot be realized by finite matrices in
  the standard form D + C(sI − A)−1 B, because the resolvent term tends to zero at high
  frequency, leaving a finite limit D. This provides an immediate impossibility check before
  attempting a construction.

9      Stability: matrices, polynomials and input-output
       behaviour
    Three questions that must be kept distinct
    Stable matrix / asymptotic decay: every eigenvalue of A has ℜλ < 0. Equivalently,
    etA decays exponentially.
    Bounded homogeneous motion: etA is bounded exactly when every eigenvalue has
    ℜλ ≤ 0 and all imaginary-axis Jordan blocks have size one. This includes undamped
    oscillation, which need not be BIBO stable.
    Stable rational function: after cancellation, the function is proper and every finite
    pole lies strictly in ℜs < 0. A constant is stable. s + 1 is not a stable rational function,
    despite having no finite poles, because it is improper.
    In the lecture framework a system is BIBO stable when bounded inputs give bounded
    outputs for the permitted initial states. A stable A is sufficient. Stability of T alone does
    not certify all hidden state behaviour of an arbitrary nonminimal realization. The notes’
    realization theorem asserts that every stable proper T has some BIBO-stable realization.

    A real monic stable polynomial must have strictly positive coefficients. Proof: its real

  axis or supply an equivalent certificate such as a strict Lyapunov inequality. To prove a
  rational transfer stable, establish properness and locate every uncancelled pole. To prove
  BIBO stability, obtain a bound that is uniform in time for every bounded admissible
  input.
  The word “uniform” is crucial. A bound like |y(t)| ≤ t + 1 does not prove bounded
  output on the infinite time interval: the right-hand side itself grows without bound. A
  valid BIBO argument needs a finite constant, possibly depending on the input bound
  and initial state, but not on t.
  To disprove BIBO stability, it is enough to provide one bounded input with an unbounded
  output. You do not have to show that every input is dangerous. The oscillator input cos t
  is an especially useful example because the resulting t sin t term makes growth explicit.

  positive coefficients in degree two.

  is nonnegative and the constant is positive. Complex roots can still have nonnegative
  real part. That is why the corresponding general assertion fails.

  Stable rational functions form a ring
  Adding or multiplying two proper rational functions preserves properness. Their combined
  poles can only come from the original poles, and cancellation can remove poles but cannot
  create new ones elsewhere. Thus sums and products of stable rational functions are stable.
  Differentiation also preserves membership: a derivative has the same pole locations with
  possibly increased multiplicity and remains proper. Taking reciprocals is different: a zero
  in the right half-plane becomes an unstable pole, or the reciprocal may be improper.

11.1    Why the critical Nyquist point is exactly minus one

  The geometry comes directly from the feedback equation
  Closed-loop poles arise when 1+L(s) = 0, where L = GK is the loop transfer. Rearranging
  gives L(s) = −1. Thus the point −1 is not an arbitrary plotting convention: it is the
  image of the values of s that make the feedback equation singular.
  If L(iω0 ) = −1, the dangerous value occurs on the stability boundary. If the loop is
  perturbed, a boundary root can move into either half-plane, so simply saying “the curve
  nearly avoids −1” does not establish strict stability. Evaluate the closed-loop denominator
  if the curve meets the point exactly.
  For a stable plant and no critical-point passage, the argument principle turns geometric
  winding into a root count. The winding includes the complete curve, not just positive
  frequencies. With the convention of this module, clockwise counts positively and N =
  Z − P . When P = 0, each net clockwise winding corresponds to an additional right-half-
  plane closed-loop zero of 1 + L.

  Worked example | A gain parameter and the exact stability threshold
  Let G(s) = 1/(s + 1) and K = k be real. The closed-loop transfer is

                                        G       1

12     PID controllers and internal stability
  The roles of P, I and D
  A PID controller is K(s) = kD s + kP + kI /s. The proportional term reacts to the current
  error, the integral term accumulates it, and the derivative term responds to its rate.
  An ideal derivative is improper, so properness of the closed-loop maps must be checked.
  The papers use different letters for these coefficients: copy their exact convention before
  calculating.
  Internal stability requires all four functions
                   1                   G                  K                    GK
           S=          ,    GS =           ,    KS =          ,    GKS =
                1 + GK              1 + GK             1 + GK                1 + GK
  to belong to S. They describe responses at different loop junctions to independently
  injected disturbances. Since S + GKS = 1, one can sometimes infer one map from
  another, but properness still matters.

  Method | Solve a PID parameter question
  1. Write G = n/d and K = k/ℓ as polynomial quotients.
  2. Form h = dℓ + nk without dropping factors of s.
  3. Determine its actual degree. If the leading coefficient can vanish, handle that case
     separately.
  4. Normalise the leading coefficient to be positive before requiring positive coefficients.
     This gives necessary conditions.
  5. To prove sufficiency, factor the polynomial, calculate roots, or apply a justified complete
     test such as the quadratic or cubic Hurwitz criterion.
  6. For internal stability, write the four numerators over h: dℓ, nℓ, kd, nk. Check poles
     after any cancellations and compare numerator and denominator degrees in every
     map.

13     Coprime factorisation, Bézout identities and con-
       troller design
  Why stable factors can represent an unstable plant
  A fraction G = P/Q can have unstable poles even when P, Q ∈ S: zeros of Q become
  poles of the quotient. Stable rational functions form a commutative ring under addition
  and multiplication (and are closed under differentiation), but they do not form a field:
  1/f need not be proper or stable.
  The pair P, Q ∈ S is coprime in S if there are X, Y ∈ S satisfying

                                         P X + QY = 1.

  This is the required certificate. Merely observing no visible common factors in a repre-
  sentation is not the full stable-ring proof.

  Method | The lecture algorithm, expanded step by step
  1. Cancel common polynomial factors in G = M/N and put m = max(deg M, deg N ).
  2. Introduce λ = 1/(1 + s), equivalently s = (1 − λ)/λ.
  3. Form polynomials P (λ) = λm M ((1 − λ)/λ) and Q(λ) = λm N ((1 − λ)/λ).
  4. Find polynomial X, Y with P X + QY = 1, either by Euclid and back-substitution or
     coefficient matching.
  5. Substitute λ = (1 + s)−1 into all four polynomials. Each becomes proper with its only
     possible pole at s = −1, hence lies in S.
  6. Verify the identity by expansion and the plant ratio G = P/Q.
  The choice of m prevents a spurious shared zero at λ = 0: at least one leading coefficient
  survives there. For two coprime quadratics it is often sufficient to try linear X = x1 λ + x0 ,
  Y = y1 λ + y0 and solve four linear coefficient equations.

13.1    Bézout and Euclid without a black box
  What it means to solve P X + QY = 1
  We are looking for combinations of the two given factors that reproduce the constant
  function 1. If P and Q both vanish at a point, every combination vanishes there and
  cannot equal 1. For ordinary complex polynomials, the converse holds because Euclid’s
  algorithm produces their greatest common divisor as a polynomial combination.
  In the stable-rational setting, the identity must use X, Y from the stable ring as well.
  This additional membership requirement is why changing to λ = (1 + s)−1 is useful: every
  polynomial in λ turns into a proper rational function with poles only possibly at s = −1.
  Once the polynomial identity is found, stable membership follows immediately.

13.2    The change of variable and full feedback equations

  Why the substitution can be reversed
  The map λ = 1/(1 + s) is invertible as a rational change of variable, with inverse
  s = (1 − λ)/λ. Substituting into a rational expression and then substituting back recovers
  the original expression wherever both sides are defined, hence as an identity of rational
  functions.
  More generally, λ = (as + b)/(cs + d) has a rational inverse when ad − bc ̸= 0. Solving
  λ(cs + d) = as + b gives s = (b − dλ)/(cλ − a). This is an algebraic coordinate change; the
  special choice in the notes is valuable because polynomials in 1/(1 + s) are automatically
  proper with possible pole only at −1.
  For example 2 + 3λ − λ2 becomes 2 + 3/(1 + s) − 1/(1 + s)2 . Its numerator has degree at
  most two over denominator (1 + s)2 , so it is proper, regardless of whether its numerator
  has zeros in the right half-plane. Zeros do not prevent stable-ring membership; poles do.

  Method | Derive the entire internal feedback map by elimination
  Start from x = r − z, y = d + Kx, z = n + Gy. Substitute the last two equations into
  the first:

  Hence x = S(r − Gd − n), where S = (1 + GK)−1 . Next,

                       y = d + KS(r − Gd − n) = KSr + Sd − KSn,

        pace

  Why an energy can be useful when the Euclidean norm is awkward
  For X ′ = AX, differentiating ∥X∥2 = X ∗ X gives X ∗ (A∗ + A)X. Even if A is stable,
  this expression need not be negative for every X. The Euclidean distance can increase
  temporarily because states are mixed by off-diagonal entries.
  A weighted energy V = X ∗ KX changes the shape of the level sets from spheres to
  ellipsoids. The goal is to find weights K > 0 for which every nonzero solution moves
  toward lower energy. The identity A∗ K + KA = −L, L > 0, does exactly that. Positive
  definiteness ensures that small energy means small state norm and that energy cannot
  hide a nonzero direction with zero cost.
  A decreasing function alone is not enough to prove state decay unless it also controls the
  state norm. For example, a constant zero “energy” decreases weakly but tells us nothing.
  The lower bound V ≥ λmin (K)∥X∥2 is therefore a necessary part of the argument, not a
  decorative final line.

17     Proof-writing methods and a practical exam routine

  Method | How to write a definition or theorem answer
  Give the mathematical condition, its domain and its strictness. For example: “A rational
  function is stable if it is proper and all its poles lie in the open left half-plane.” Mentioning
  only negative poles misses properness; writing ℜs ≤ 0 changes the definition.
  For a theorem, state assumptions before the conclusion. In a proof, choose the object
  that makes the statement easy: a power series for exponentials, an integration-by-parts
  identity for Laplace derivatives, a quadratic form for positivity, or an exact identity for
  coprimeness.

  Method | Four reusable proof skeletons
  Exponential identity: write the series; justify absolute convergence; manipulate powers
  or coefficients; identify the resulting scalar series.
  Matrix integral identity: bound the integrand to prove convergence; compute its



                                                 67
MATH6342 | Linear Systems                                                              Sai Vanam



  derivative; integrate to obtain an endpoint difference; evaluate both endpoints explicitly.
  Positive-definite integral: insert an arbitrary nonzero vector; move matrices into a
  congruence expression; use strict positivity pointwise; integrate. Do not infer positive
  definiteness just from positive matrix entries.
  Stability by frequency response: identify the loop transfer and its poles; exclude
  critical-point passage; determine winding (or bound the entire curve inside a safe region);
  apply Nyquist with the correct sign convention and conclude about the specified loop.

  Budgeting time using the supplied papers
  Each supplied paper states three hours, 100 marks, and all questions to be answered.
  That suggests roughly 1.8 minutes per mark before allowing time for checking. The
  current MATH6342 format may differ; use the actual examination instructions when
  released.
  Start with work you can complete reliably. In a long calculation, keep a reusable
  denominator symbol q(s) until the end. If stuck on expansion, write the correct setup
  and method clearly, then move on. Return to verify boundary conditions, factorisations
  and properness. A short exact argument is preferable to a long unsupported assertion.

  Exam tips and common mistakes
  1. Re-read the requested object: R, T = R/(1 + R), or another feedback around T ?
  2. Check the sign of every last-row companion entry and feedback denominator.
  3. Check e0A = I and, where useful, E ′ (0) = A.
  4. Check transformed initial terms before setting them to zero.
  5. Check phase quadrants and whether a real-axis crossing is negative.
  6. Check all four internal maps, including high-frequency degree behaviour.
  7. Check a claimed Bézout identity by expansion.
  8. Check every leading principal minor, not just the determinant.

  three independent defects.

  Model answer
  First, positive cubic coefficients are only necessary: s3 + 4s2 + s + 4 = (s + 4)(s2 + 1) is a
  counterexample. A complete pole test is still needed.
  Second, “starts at zero” needs a frequency-range convention. A strictly proper full
  Nyquist curve begins at zero at ω = −∞, but its positive-frequency branch begins at
  G(0); neither endpoint alone determines winding about −1.
  Third, a stable plant can be destabilised by feedback. Internal stability also requires all
  four closed-loop maps to be stable and proper. An ideal derivative controller can make
  K/(1 + GK) improper for a strictly proper plant, even when one external transfer is
  stable.

  Exam tips and common mistakes
  Each part uses a different representation of the same system. State variables are best for
  diagrams, transforms for transfer functions, complex substitution for frequency response,
  polynomial roots for the simple feedback test, and convolution for a direct BIBO bound.
  Choosing the representation before calculating makes a long question manageable.

  Try it first | Final diagnostic: four short decisions
  Decide whether each statement is correct and justify your answer. (i) A real 2 × 2 matrix
  with trace −3 and determinant 2 is stable. (ii) The rational function (s − 1)/(s + 2) is
  unstable because its numerator has a positive zero. (iii) A realization of T (s) = 2+1/(s+1)
  must have zero feedthrough. (iv) If A∗ K + KA = −I and K > 0, the homogeneous
  solutions are bounded but cannot be shown to decay.

  Model answer
 (i) Correct. The characteristic polynomial is s2 − (tr A)s + det A = s2 + 3s + 2 =
 (s + 1)(s + 2). Both eigenvalues are negative. This uses the characteristic polynomial of
 a 2 × 2 matrix, not a general claim that negative trace alone implies stability.
 (ii) Incorrect. The transfer is proper and its only pole is −2, so it is stable as defined
 in the module. The zero at 1 would become an unstable pole in its reciprocal; it does not
 itself make the original transfer unstable. This distinction is essential in stable coprime
 factorisation.
 (iii) Incorrect. The high-frequency limit is 2, so every standard finite-dimensional
 realization has feedthrough D = 2. One choice is A = −1, B = C = 1, D = 2. The
 dynamic term tends to zero at infinity, leaving D.
 (iv) Incorrect. The notes’ boundedness conclusion is valid, but the strict equation gives
 more. For V = X ∗ KX, V ′ = −∥X∥2 ≤ −V /λmax (K). Hence V decays exponentially; the
 lower bound V ≥ λmin (K)∥X∥2 then proves exponential state decay. Both inequalities
 are needed to turn the energy estimate into a norm estimate.
