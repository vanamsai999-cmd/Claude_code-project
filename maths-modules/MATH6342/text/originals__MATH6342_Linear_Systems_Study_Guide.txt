Chapter 1: Linear systems and their description
What is a linear system?
A linear system is a machine or process evolving in time. It has:

• an input u(t): what we apply to the system;

• a state x(t): internal variables needed to predict future behaviour;

• an output y(t): what we observe or measure.

The slides motivate the subject using examples including wind turbines, heating systems, electrical
networks, ECGs, vehicle suspension, epidemics, predator–prey systems, and audio filters.
A map L : V → W is linear when
                                         L(λf + µg) = λLf + µLg.
Basic linear operators in the course include differentiation, integration, scalar amplification, multiplication
by a function, and evaluation.

Open loop versus feedback
An open-loop system sends the input through linear operations to create the output. A feedback system
sends part of the output back into the input path.
Positive feedback reinforces changes. The notes use bird populations
                                               dx
                                                  = kx + u,         k > 0,
                                               dt
and a turbocharger as examples.
Negative feedback opposes changes. For a cyclist with air resistance,
                                                       dv
                                                   m      = −kv + u,
                                                       dt
where −kv is the feedback term resisting motion.

      Watch out
      Feedback is not automatically “good” or “bad”. Positive feedback can cause growth; negative feedback
      is commonly used for regulation and stability, but stability still has to be checked mathematically.

Rational functions and transfer functions
A rational function is f (s) = g(s)/h(s). It is:

• proper if deg g ≤ deg h;

• strictly proper if deg g < deg h.

Uniqueness
Lerch’s uniqueness theorem tells us, under the lecture assumptions, that the Laplace transform determines
the original function. This justifies solving an equation in the s-domain and transforming back.

Solving differential equations with Laplace transforms
For a differential equation, the workflow is:

1. take Laplace transforms of both sides;

2. insert the initial conditions using L{f ′ } = sfˆ − f (0) and its higher-order versions;

3. solve the resulting algebraic equation for ŷ(s);

4. use partial fractions / transform tables to invert.

Chapter 4: Transfer functions, frequency response and stability
Transfer functions as input-output descriptions
A SISO transfer function T (s) is defined by

                                                 Ŷ (s) = T (s)Û (s)

for zero initial conditions. The notes prove that every rational transfer function can be realised by a linear
system assembled from the course’s block-diagram components.

Frequency response
To study sinusoidal inputs, substitute
                                                      s = iω.
The complex number T (iω) gives the system’s frequency response. Write

                                             T (iω) = Γ(ω)eiϕ(ω) ,

where
                              Γ(ω) = |T (iω)|          and       ϕ(ω) = arg T (iω) .
Γ is the gain (amplitude ratio) and ϕ is the phase shift.

Nyquist and Bode plots
• A Nyquist plot traces T (iω) in the complex plane as frequency varies.

• A Bode plot displays gain (usually logarithmically) and phase against frequency.

These plots compress dynamic behaviour into a visual frequency-domain summary.

The damped oscillator revisited
For
                                              y ′′ + βy ′ + γy = u,
the denominator polynomial controls the natural response. Different values of β and γ produce different
damping regimes. The same example is then used to discuss boundedness, marginal stability and resonance.

BIBO stability
A system is BIBO stable if every bounded input produces a bounded output. The lecture notes distinguish
this from weaker notions where the homogeneous response might remain bounded but a resonant bounded
input produces unbounded growth.

   Watch out
   Marginal stability is not BIBO stability. An undamped oscillator can have bounded free
   oscillations but exhibit resonance under a bounded sinusoidal input at its natural frequency, producing
   an unbounded output.


Eigenvalue test for stability
A central theorem states that if all eigenvalues of A satisfy

                                                 Re(λj ) < 0,

then there exist M, δ > 0 such that

                                          ∥etA ∥ ≤ M e−δt ,     t ≥ 0.

For bounded U , the state-space solution then remains bounded, and therefore the output is bounded.
Hence (A, B, C, D) is BIBO stable.

   Intuition
   Eigenvalues in the open left half-plane correspond to decaying exponential factors. The strict
   inequality matters: repeated eigenvalues on the imaginary axis can create polynomial factors such
   as teiωt , which are unbounded.


Chapter 5: Feedback control
Stable polynomials and stable rational functions
A polynomial is called stable if all its zeros lie in the open left half-plane

                                         LHP = {s ∈ C : Re(s) < 0}.

A necessary condition shown in the notes is that a monic real stable polynomial has all positive coefficients.
This condition is not sufficient in general.
A rational function is called stable if it is proper and all of its poles are in the open left half-plane.

Simple feedback loops
Let G represent the plant and −K the controller. For the simple negative-feedback loop, the closed-loop
transfer function is

   Core formula

                                           T = (I + GK)−1 G.

For SISO systems this becomes
                                                        G(s)
                                          T (s) =                .
                                                    1 + G(s)K(s)
The poles of G are the open-loop poles; poles of the closed-loop T are the closed-loop poles.

PID controllers
A proportional-integral-derivative controller has

                                                           b
                                           K(s) = a +        + cs.
                                                           s

The three terms provide proportional, accumulated (integral), and rate-of-change (derivative) action. The
lecture emphasis is that controller choice is a balance between stability and responsiveness.

Nyquist stability criterion
The chapter develops Nyquist’s criterion using the argument principle. The practical purpose is to infer
closed-loop stability from the complex-plane behaviour of the open-loop transfer function rather than
solving the differential equation explicitly.

   Revision / problem-solving cue

   When studying a feedback system, keep the hierarchy clear:
   1. identify G and K;
   2. form 1 + GK;
   3. determine closed-loop poles / stability;
   4. then examine gain, phase and responsiveness.

Well-posedness and internal stability
In the standard feedback loop with reference r, disturbance d, and noise n, the internal variables are
uniquely determined precisely when
                                            1 + GK ̸= 0.
The system is internally stable when every transfer function linking external inputs to internal signals is
stable. In the SISO notation used in the slides, this means
                                    1             G             GK           K
                                        ,             ,              ,
                                 1 + GK        1 + GK         1 + GK      1 + GK
all belong to the stable rational class S.

Youla-style stabilisation result
If
                                         G = P/Q,         P X + QY = 1,
with all four functions in S, then
                                                   K = X/Y
internally stabilises the simple feedback loop. The slides note that this is the simplest case of the broader
Youla theory.

Self-adjoint and positive definite matrices
                                         T
For a matrix A, its adjoint is A′ = A . A self-adjoint matrix satisfies A = A′ and has real eigenvalues; it
can be unitarily diagonalised.
A matrix K is positive definite if K = K ′ and

                                         ⟨Kz, z⟩ > 0      for every z ̸= 0.

For self-adjoint K, this is equivalent to all eigenvalues being positive, and also equivalent to all leading
principal minors being positive.

Lyapunov’s criterion
If there is a positive definite K such that

                                               Q = −(A′ K + KA)

is also positive definite, then all solutions of

                                           V (t) = ⟨KX(t), X(t)⟩,

   A Lyapunov function is an “energy-like” quantity. If it is positive and cannot increase with time,
   the state cannot blow up.

How to revise this module efficiently
1. Master the three representations: ODE, state space and transfer function.

2. Memorise the core Laplace rules, especially derivatives, exponentials and convolution.

3. Practise matrix exponentials: diagonalizable matrices first, then Jordan blocks.

4. Link poles to behaviour: left half-plane ⇒ decay; imaginary-axis structure ⇒ oscillation / possible
   resonance.

5. Practise closed-loop algebra: simplify G/(1 + GK) and identify closed-loop poles.

6. Know the stability vocabulary: BIBO, stable rational function, internal stability, Lyapunov
   criterion.

7. Use MATLAB to check, not replace, reasoning: eigenvalues, poles, Bode/Nyquist plots and
   Lyapunov equations are excellent for verification.

  One-page mental checklist

  When you see a new linear-systems question, ask:
   1. What are the input, state and output?
   2. Can I write X ′ = AX + BU , Y = CX + DU ?
   3. Do I need the time-domain solution, or would a Laplace transform be faster?
   4. What is the transfer function?
   5. Where are the poles / eigenvalues?
   6. Is the system stable, marginal, or unstable?
   7. If feedback is present, what is 1 + GK and where are the closed-loop poles?
   8. If direct solving is awkward, can a Lyapunov / frequency-domain argument answer the question
      instead?
