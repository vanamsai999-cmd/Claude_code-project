  1. States, transfer and dimensions

                      Ẋ = AX + Bu,       y = CX + Du,        T = D + C(sI − A)−1 B.
  Dimensions: A : n × n, B : n × k, C : m × n, D : m × k. Transfer functions use zero initial state.
  Solve (sI − A)v = B, then form D + Cv; no full inverse is needed. Check T (∞) = D.

  3. Integrator-only modelling

  For y ′′ + ay ′ + by = cu′ + du, set x1 = y, x2 = y ′ − cu. Then

                              x′1 = x2 + cu,    x′2 = −bx1 − ax2 + (d − ac)u.

  Use one integrator per state. Initial x2 (0) = y ′ (0) − cu(0). For an ODE without input derivatives,
  ordinary derivative states (y, y ′ , . . .) give the companion matrix directly.

  Exam tips and common mistakes
  Numerator coefficients enter C in ascending powers. A tap copies a signal; it does not divide it.
  An integrator’s input is its output derivative. State variables need not literally be derivatives of y.

  10. Stability distinctions

  Stable matrix: all ℜλ < 0, hence ∥etA ∥ ≤ M e−δt .
  Bounded free motion: all ℜλ ≤ 0, and imaginary-axis Jordan blocks have size one.
  Stable rational: proper and all poles strictly left of the imaginary axis, after cancellation.
  BIBO bound: if ∥u∥∞ ≤ U and A is stable,

                                       ∥X(t)∥ ≤ M ∥X0 ∥ + M ∥B∥U/δ.

  Stable T can conceal unstable hidden states in a nonminimal realization.

  11. Polynomial tests
  Real monic stable polynomials have positive coefficients; converse fails in degree ≥ 3. Example:
  (s + 1)(s2 + 1) has poles on the imaginary axis. A quadratic s2 + as + b is Hurwitz iff a, b > 0.
  Extension: a cubic d3 s3 + d2 s2 + d1 s + d0 , d3 > 0, is Hurwitz iff all coefficients are positive and
  d2 d1 > d3 d0 . Handle leading-coefficient zero separately.

  13. Nyquist: the notes’ convention

  For feedback G/(1 + GK) use loop L = GK. Traverse ω : −∞ → +∞ and count clockwise windings
  N about −1. Then N = Z − P , with P the right-half-plane poles of L and Z the right-half-plane
  zeros of 1 + L. Stability requires N = −P and no imaginary-axis closed-loop poles.
  For stable L, zero winding and no passage through −1 imply stable feedback, assuming 1+L(∞) ̸= 0.
  A strict gain bound |L(iω)| < 1 proves this. Passage through −1 is a boundary case requiring
  separate analysis, not an ordinary winding count.

  14. PID and all four internal maps

  For G = n/d, K = k/ℓ, set h = dℓ + nk. The internal maps are

                                     dℓ/h,   nℓ/h,       kd/h,   nk/h.

  Each must be proper with strictly left-half-plane poles. Proving only the external map stable is
  insufficient.
  For G = (s + 1)/(s2 + s − 6) and K = as + b + c/s,

                            h = (1 + a)s3 + (1 + a + b)s2 + (b + c − 6)s + c.

  The choice a = 0, b = 3, c = 4 gives (s + 4)(s2 + 1): positive coefficients but no strict stability. A
  nonzero ideal derivative term also makes KS improper for this plant in the cubic case.

  Method | 15. Stable coprime factorisation

  1. Cancel common factors in G = M/N ; put m = max(deg M, deg N ).
  2. Set s = (1 − λ)/λ. Form P = λm M (s), Q = λm N (s).
  3. Find polynomial X, Y with P X + QY = 1, by Euclid or coefficient matching.
  4. Substitute λ = 1/(1 + s). Each is proper, with only possible pole −1.
  5. Use K = X/Y ; the four maps are QY, P Y, QX, P X, proving internal stability.
  For coprime quadratics, try linear X, Y and equate four coefficients. Verify the exact identity by
  expansion.

  Worked example | A compact certificate from 2023 Q4

                                 P = 7 − 5λ − λ2 ,       Q = 9 + 4λ + λ2 ,
                                X = (20 + λ)/329,        Y = (21 + λ)/329.
  Expansion gives P X + QY = 1, so K = (20s + 21)/(21s + 22) internally stabilises (7s2 + 9s +
  1)/(9s2 + 22s + 14).

  Exam tips and common mistakes
  The rational lecture framework calls a loop well posed when 1 + GK ̸≡ 0. Internal stability is
  stronger. A stabilising controller need not itself be stable. Do not swap the Bézout labels without
  adjusting the controller ratio.
