COURSE OVERVIEW

What is a linear system?

A linear system is a mathematical model of a machine, process or collection of interacting components. Time is usually denoted by t > 0. A system receives an input u(t), has an internal state x(t), and produces an output y(t). The central question is: how does the output depend on the input and the internal dynamics?

Input
u(t)
→
System / state
x(t)
→
Output
y(t)

The lecture deck uses examples from wind turbines, central heating, electrical networks, ECG signals, lenses, vehicle suspension, epidemics, predator–prey systems, musical filters and amplifiers. The common feature is that many real systems can be represented by combinations of linear operators and then analysed using linear algebra, differential equations and transforms.

Core state-space model

X′(t) = AX(t) + BU(t)
Y(t) = CX(t) + DU(t)

This (A,B,C,D) representation is the main language of the module. Matrix A controls the autonomous evolution of the internal state; B tells us how the input enters the state dynamics; C maps the state to the output; and D describes any direct input-to-output effect.

Linear operators used in block diagrams

Differentiator

f ↦ df/dt

Returns the rate of change of a signal.

Integrator

f ↦ ∫₀ˣ f(t)dt

Accumulates a signal from time 0.

Amplifier

f ↦ af

Multiplies a signal by a scalar. “Amplifier” is used even when 0<a<1.

Summing junction / tap

A summing junction adds incoming signals. A tap copies a signal onto another path; it does not split its magnitude.

Open loop vs feedback

Open loop

The input is processed and produces an output, but the output is not fed back into the system. The deck also calls this “straight through”.

Closed loop / feedback

A transformed version of the output is returned to the input. Positive feedback can reinforce behaviour; negative feedback counteracts deviations and is central to control.

Negative feedback from air resistance. For cyclist velocity v, mass m, pedal force u and drag coefficient k:
m dv/dt = −kv + u
The term −kv resists the motion and therefore acts as negative feedback.
Damped harmonic oscillator. A mass–spring–damper model satisfies
y″ + βy′ + γy = u
with restoring force −γy and damping force −βy′. With v=y′ and X=[y,v]ᵀ,
A = [[0,1], [−γ,−β]],   B = [0,1]ᵀ,   X′=AX+Bu.
CHAPTER 1

Linear systems and their description

The first chapter builds the modelling language. A map L:V→W is linear when L(λf+μg)=λLf+μLg. Block diagrams combine linear operations into larger machines. A circuit in the directed graph corresponds to feedback.

Differential equations as feedback systems

A constant-coefficient linear differential equation can be realised using taps, amplifiers, summing junctions, integrators and differentiators. This is important because it turns a differential equation into a physical/computational block diagram.

Reduction of order

An nth-order scalar differential equation can be rewritten as a first-order vector system. For

y⁽ⁿ⁾ + aₙ₋₁(t)y⁽ⁿ⁻¹⁾ + ··· + a₀(t)y = u(t),

choose

X = [y, y′, …, y⁽ⁿ⁻¹⁾]ᵀ

and obtain X′ = AX + Bu. In the constant-coefficient case, A becomes a fixed matrix and linear algebra becomes available.

Companion matrix

The companion matrix packages the coefficients of a monic polynomial into a matrix. In the convention used in the deck, its last row contains −a₀,…,−aₙ₋₁ and the superdiagonal entries are 1. Its characteristic polynomial is exactly

λⁿ + aₙ₋₁λⁿ⁻¹ + ··· + a₁λ + a₀.
Can you do this? Convert a third-order ODE into first-order state-space form and write down its companion matrix without notes.
CHAPTER 2

Solving linear systems by matrix theory

This chapter develops the matrix tools needed to solve X′=AX+BU. It revisits determinants, cofactors, characteristic polynomials, norms, adjoints and matrix exponentials, then uses these tools to solve state-space equations.

Determinants, cofactors and the resolvent

The characteristic polynomial is defined using the control-theory convention

χA(λ)=det(λI−A).

When det(sI−A)≠0, the inverse exists and

(sI−A)⁻¹ = adj(sI−A) / det(sI−A).

The matrix-valued function (sI−A)⁻¹ is the resolvent. Its singularities occur at eigenvalues of A.

Inner products and norms

For complex column vectors, the standard inner product uses conjugation. The induced Euclidean norm satisfies Cauchy–Schwarz and the triangle inequality. Matrix norms allow estimates such as ||AB||≤||A||||B||, which later control the size of e^{tA}.

Matrix exponential

etA = I + tA + t²A²/2! + t³A³/3! + ···

The matrix exponential is the fundamental solution of the homogeneous system X′=AX. It satisfies the expected exponential law when matrices commute, and in particular

d/dt(etA) = AetA = etAA.

General state-space solution

X(t)=etAX₀ + ∫₀ᵗ e(t−v)A B U(v) dv.

The first term is the response caused by the initial state. The integral is the forced response caused by the input.

Eigenvalues, diagonalisation and Jordan form

If A is diagonalizable, write A=SΛS⁻¹; then e^{tA}=Se^{tΛ}S⁻¹. If A is not diagonalizable, Jordan blocks produce terms involving powers of t multiplied by exponentials. This is why repeated eigenvalues on the imaginary axis can create growth even when the exponential part itself has modulus 1.

Boundedness idea

Eigenvalues with negative real part produce decaying modes. The strict inequality Re λ<0 is especially important for guaranteeing exponential decay of the matrix exponential.

Can you do this? Given A, determine its eigenvalues, decide whether diagonalisation is available, compute or describe etA, and insert it into the variation-of-constants formula.
CHAPTER 3

Laplace transforms

The Laplace transform changes a differential-equation problem in time into an algebraic problem in a complex variable s. The deck works with functions of exponential type: there exist M>0 and β∈ℝ such that |f(x)|≤Me^{βx}.

Definition

ℒ(f)(s)=f̂(s)=∫₀∞ f(x)e−sxdx,   Re(s)>β.

The transform is linear. Differentiation in time becomes multiplication by s together with initial-value terms; integration in time becomes division by s. This is the bridge from ODEs to rational functions.

High-value transform rules

Derivative

ℒ(f′)=s f̂(s)−f(0)

Second derivative

ℒ(f″)=s²f̂−sf(0)−f′(0)

Integral

ℒ(∫₀ᵗ f)=f̂(s)/s

Exponential

ℒ(eat)=1/(s−a)

Convolution

Convolution in time becomes multiplication in the s-domain. This is one of the main reasons transfer functions are so powerful: cascaded systems become products of rational functions or rational matrices.

Matrix Laplace transform

Applying the Laplace transform to X′=AX+BU with initial state X(0) gives

(sI−A)X̂(s)=X(0)+BÛ(s)

so

X̂(s)=(sI−A)⁻¹X(0)+(sI−A)⁻¹BÛ(s).

Frequency viewpoint

Putting s=iω connects Laplace-domain analysis with sinusoidal inputs and frequency response. The magnitude of a complex response is interpreted as gain, while the argument is interpreted as phase.

Can you do this? Transform an ODE with initial conditions, solve algebraically for the transformed unknown, use partial fractions, and invert the transform.
CHAPTER 4

Transfer functions, realization and stability

For a SISO system with zero initial conditions, the transfer function T(s) is defined by

Ŷ(s)=T(s)Û(s).

For a MIMO system, T(s) is a matrix of functions. For the standard state-space model,

T(s)=D+C(sI−A)⁻¹B.

Realization

A realization is a state-space system that produces a desired transfer function. The deck proves that every proper complex rational function can be realized by a SISO (A,B,C,D) system; every rational matrix function can likewise be realized by a MIMO system built from matrix amplifiers, summing junctions, taps, integrators and differentiators.

Proper and strictly proper rational functions

For T=p/q, proper means deg p ≤ deg q. Strictly proper means deg p < deg q. Properness matters because physically meaningful causal transfer functions in this framework should not grow without bound as s→∞.

BIBO stability

BIBO means bounded input → bounded output. The deck links time-domain and transfer-function stability:

Key equivalence. A complex rational function T is stable iff T is the transfer function of some BIBO-stable linear system (A,B,C,D).

Stable polynomials and stable rational functions

A polynomial is stable when every zero lies in the open left half-plane Re(s)<0. A rational function is stable when it is proper and all poles lie in that open left half-plane. The set of stable rational functions is denoted S; it forms a differential ring but not a field.

Eigenvalue criterion

If every eigenvalue λ of A satisfies Re λ<0, then ||e^{tA}|| decays exponentially and bounded inputs produce bounded states and outputs.

Resonance and marginal stability

A bounded sinusoidal input at a system’s natural frequency may cause an unbounded output. The deck calls the situation where complementary solutions stay bounded but suitable bounded forcing creates unbounded response marginal stability; it is not BIBO stability.

Damped harmonic oscillator poles

T(s)=1/(s²+βs+γ),   λ±=(-β±√(β²−4γ))/2.

For β,γ>0, the poles lie in the open left half-plane and the system is stable.

Nyquist criterion used in the deck

For stable R and constant negative feedback −1, the closed-loop transfer function is

T=R/(1+R).

If the Nyquist contour R(iω) neither passes through nor winds around −1, then T remains stable. The argument principle is expressed as N=Z−P, where N is the net clockwise winding number around −1, Z counts zeros of R+1 in the RHP, and P counts its RHP poles.

Can you do this? Starting from (A,B,C,D), derive T(s), identify its poles, decide properness/stability, and relate the result back to the eigenvalues of A.
CHAPTER 5

Feedback control

The purpose of feedback control is not merely to solve a system but to change its behaviour. A controller acts on the measured output and feeds a corrective signal back into the plant.

Simple feedback loop

If G is the plant and −K is the controller, then the simple feedback loop has transfer function

T=(I+GK)⁻¹G.

The poles of G are the open-loop poles; poles of the closed-loop T are the closed-loop poles. Controller design aims to move the closed-loop poles into a region that gives stability and acceptable responsiveness.

PID controllers

K(s)=a+b/s+cs

P — proportional

Responds to the present size of the error.

I — integral

Accumulates past error and can remove persistent offsets.

D — derivative

Responds to rate of change and can react sharply to developing error.

The deck emphasises the trade-off between stability and responsiveness: a controller should keep the system on course without making it unable to respond to intended changes.

Polynomial tools: Euclidean algorithm and Bézout identity

The Euclidean algorithm finds the highest common factor of two polynomials. Working backwards gives a Bézout identity

PM+QN = gcd(P,Q).

If P and Q have no common zero, the gcd can be scaled to 1. This coprime-factor viewpoint feeds directly into controller construction.

Stable coprime factorisation and Youla stabilisation

Write an arbitrary rational plant as G=P/Q with coprime P,Q in the stable ring S. If there are X,Y∈S with

PX+QY=1,

then the controller K=X/Y internally stabilises the simple feedback loop. Internal stability requires all relevant transfer functions at internal junctions—not just the external input-output map—to be stable.

Self-adjoint matrices and Lyapunov theory

The later part of the chapter uses self-adjoint matrices, positive definiteness and Lyapunov equations to study stability. A self-adjoint matrix has real eigenvalues and can be unitarily diagonalised. Positive definite matrices give quadratic “energy-like” quantities.

AL + LA′ + P = 0

For A with all eigenvalues in the open left half-plane and P positive definite, the deck constructs a positive definite solution L to this Lyapunov equation. MATLAB also has direct commands for solving such equations.

Can you do this? For a given G and controller K, form the closed-loop transfer function, determine closed-loop poles, test stability, and explain the difference between external/BIBO stability and internal stability.

6 Chapter 1: Linear systems and their description

In linear systems, we consider a machine made up of several components,
which are connected together. We take t > 0 to be time and consider
the evolution of the system through time. The machine has an input
u = u(t), and output y = y(t) and the internal state of the machine is
described by a state x = x(t), and we take u, x, y to be vector-valued
functions of t. The state of a system is a set of variables whose values,
together with the input and the equations describing the dynamics, will
describe the future state and output of the system. Usually, we want to
know how y(t) depends upon u(t). The component parts of the machine
are represented by various linear operators. We consider a special class of
linear systems that we can analyze by means of linear algebra. We obtain:
• general results which enable us to classify and describe a significant
class of linear systems, called (A, B, C, D);
• specific methods for solving these linear systems;
• results that are in a form that allows effective and explicit computation
of solutions, usually using computers.

11 Block Diagrams

Let V be the space of infinitely differentiable functions f : (0, ∞) → C.
Let u ∈ V be the input, y ∈ V be the output. A diagram is a graph built
up from vertices u, y and others chosen from
                                               ∫︂
                         u, y, δ0 , ⊕, ·, d/dt, , a, h
                       {︂                              }︂


which are connected by directed edges, drawn as arrows.
(1) u is the input and y is the output. The vertices u and y have degree
one; whereas all other vertices have degree two or three with one or two
arrows pointing into the vertex, and one or two pointing out.
(2) The graph is simple, so there are no loops or multiple edges. All

(3) If the diagram contains a circuit, then we say that there is feedback.
(4) If the diagram does not contain a circuit, then the system is ‘open

[See video: V1 feedback block diagram]
Open loop Here the input u is subject to linear operations and produces
an output y. For example

                         y(t) = atu(t) + u ′′ (t).

Some machines are open loop, for instance rockets, or primitive turbines.

23 Damped harmonic oscillator

Damped harmonic oscillators are important, because they (i) arise in
various physical and electrical systems; (ii) exhibit the effects that
describe more general linear systems. So this example will reappear.

Proposition
The transfer function T (s) = D + C(sI − A)−1 B of a SISO system is a
proper rational function, and all the poles are eigenvalues of A.
Proof. The characteristic polynomial det(sI − A) has degree n, and
leading term s n . A cofactor of sI − A is the determinant of a
(n − 1) × (n − 1) submatrix of sI − A and hence is a polynomial of
degree less than or equal to n − 1. Now
                 (sI − A)−1 = det(sI − A)−1 adj(sI − A)
where adj(sI − A) is the transpose of the matrix of cofactors. Hence the
entries of (sI − A)−1 are strictly proper rational functions. The
eigenvalues of A are precisely the zeros of det(sI − A), hence are the only
possible poles of entries of (sI − A)−1 . Since C, B and D are constant
matrices, they do not introduce any more factors involving s, so T (s) is
a proper rational function.

(i) Each eigenvalue λj has algebraic multiplicity nj , where nj is the

blocks that involve λj , so the geometric multiplicity is less than or equal
to the algebraic multiplicity.
(iv) When a Jordan block has shape k × k, where k > 1, it has both
eigenvectors and generalised eigenvectors. A generalised eigenvector is
v ̸= 0 such that (λj I − A)m v = 0 for some m = 2, . . . , k.

Scales on the Bode plot and phase plot

Show complete slide content 
148 Scales on the Bode plot and phase plot

The Bode plot is the logarithm of the gain log Γ in decibels versus ω in
radians per second, with ω > 0 plotted on a log scale. Going from left to
right on the Bode plot, ω increases from 0 to ∞, and iω goes up the
imaginary axis. Recall that 360◦ is equivalent to 2π radians, and be
careful with the scales on the plots. The phase (or phase shift) ϕ(ω) is
the change in phase of the signal between input and output at a given
input frequency. Phase ϕ in degrees is plotted against ω in radians per
second, with ω > 0 on a log scale.
i) If ϕ(ω) > 0, there is phase gain, so the output runs ahead of the input.
ii) If ϕ(ω) < 0, there is a phase lag, so the output runs behind the input.
iii) If ϕ = 0, then the input and output are said to be in phase.
iv) If ϕ = π (or 180◦ ), then the input and output are in anti-phase so
input peaks emerge as output troughs. Anti-phase signals are used in
noise-cancelling headphones, where a sound is cancelled by a sound in
anti-phase. Anti-phase is also used in optical lens coatings, to reduce
reflections.
