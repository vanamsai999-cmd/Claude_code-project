MATH6321 Mathematical Cryptography - Sai Vanam

Files:
  main.tex        32-page detailed notes and worked-answer workbook
  cheatsheet.tex 7-page revision reference sheet

Overleaf:
1. New Project -> Upload Project -> choose this ZIP.
2. Set main.tex as the main document and use pdfLaTeX.
3. Recompile twice if the contents or page references need updating.
4. To compile the shorter sheet, set cheatsheet.tex as the main document.

Local compilation:
  pdflatex main.tex
  pdflatex main.tex
  pdflatex cheatsheet.tex
  pdflatex cheatsheet.tex

No external images or bibliography files are needed. All boxes and the
picture solution use LaTeX/TikZ. Packages are standard on Overleaf.

Based on all four supplied sources: MATH6321 Notes(1).pdf;
MATH6321 Exam Information.pdf; MATH6321 Coursework 1(1).pdf;
MATH320_Mathematical_Cryptography_Main_Exam_24-25 (1).pdf.
The current guidance says 2 hours and no examinable proofs. The older
2025 paper was 3 hours. Exclusions are clearly labelled in the guide.

Model solutions are independently derived, not an official marking scheme.
