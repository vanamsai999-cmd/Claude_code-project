                                                           Definition. (Minima and maxima for subsets of R)
                                                           Let A ⊂ R. We say that A has a minimum if there is x ∈ A
                                                           such that a ≥ x for all a ∈ A:
                                                                               ∃x∈A ∀a∈A a ≥ x;
                                                           and A has a maximum if there is x ∈ A such that a ≤ x
                                                           for all a ∈ A:
                                                                            ∃x∈A ∀a∈A a ≤ x.
                                                           When they exist minima and maxima are unique; we denote
                                                           them as follows: min A and max A.

2.1    Subsets of R                                        Remark. Let A ⊂ R. Then
                                                                 A has a maximum ⇐⇒ −A has a minimum,
                                                           where −A := {−a : a ∈ A}; in this case
                                                                             max A = − min(−A).

                                                           Examples.
                                                               If A ⊂ R is nonempty and finite then A has a minumum
                                                                and a maximum.
                                                               The bounded half-open interval [a, b[, in which
                                                                a, b ∈ R with a < b, has a minimum but does not have
                                                                a maximum. The latter obvious looking fact actually
                                                                depends on the Archimidean Property of R (see below).

Theorem. (Archimidean Property for R)              Proof.
The Archimedean Property holds for R.              We show that N is unbounded in R (i.e. version (iv) of the
                                                   Archimidean Property holds for R).
                                                       Suppose, for a contradiction, that N is bounded above.
                                                   Then, by the LUB Principle, it has a least upper bound. Set
                                                   s = sup N. Then s − 1 < s, so s − 1 is not an upper bound
                                                   for N, and therefore there is N ∈ N such that s − 1 < N .
                                                   But then
                                                                           N + 1 > s.
                                                   Since N + 1 ∈ N this contradicts s being an upper bound for
                                                   N. Therefore N is not bounded above, and so is unbounded.

Corollary. Let f and J be as in the IVT. Then the range of
f is a closed and bounded interval.

Proof. By the Uniform Continuity Theorem, there are
p, q ∈ R and s, t ∈ J such that p = f (s) ≤ f (x) ≤ f (t) = q
for all x ∈ J; in particular Ran f ⊂ [p, q].
    Let α ∈ [p, q] and denote the interval with endpoints s
and t by J ′. Then J ′ ⊂ J (why?), and so, by the IVT
applied to f |J ′ , there is z ∈ J ′ such that f (z) = α. Hence
Ran f ⊃ [p, q].
    Therefore Ran f equals the closed and bounded interval
[p, q].
