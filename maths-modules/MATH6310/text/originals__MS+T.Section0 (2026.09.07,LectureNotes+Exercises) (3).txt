Example. (Counting metric on P(S), for a finite set S)            Solution.
Here P(S) denotes the power set of S (= collection of all
subsets of S). For a finite set S, the counting metric is given
by
                      d(A, B) := #A∆B
where A∆B is the symmetric difference of A and B, de-
fined by either of two formulae

         (A \ B) ∪ (B \ A) = (A ∪ B) \ (A ∩ B),

Axiom (MS1) holds since

    #(A∆B) = 0 ⇐⇒ A∆B = ∅
               ⇐⇒ A ∪ B = A ∩ B ⇐⇒ A = B.

Axiom (MS2) follows from the symmetry of ∆:

                       B∆A = A∆B.
