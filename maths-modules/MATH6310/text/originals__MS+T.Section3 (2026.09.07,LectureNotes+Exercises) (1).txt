Definition.
A metric on a set S is a function
                     d : S × S → [0, ∞[
satisfying
(MS1) ∀x,y∈S d(x, y) = 0 ⇔ x = y                             .
(MS2) ∀x,y∈S d(y, x) = d(x, y)                   (Symmetry)
(MS3) ∀x,y,z∈S d(x, z) ≤ d(x, y) + d(y, z)       (Triangle ≤)
A metric space E is a set S together with a specified metric
d on it; we write E = (S, d).
