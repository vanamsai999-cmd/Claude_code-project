Exercise 3.3: Associated bounded metric

Let E = (S, d) be a metric space. The function in Example 2 of the lecture notes is
                                                                          t
                               α : [0, ∞[−→ [0, ∞[,        α(t) =            .
                                                                         1+t
We use the lecture proposition New metric via an increasing subadditive function. It is enough to
show that α vanishes exactly at zero, is increasing, and is subadditive.

Proof
(a) Show that α(t) = 0 exactly when t = 0. For every t ≥ 0, the denominator 1 + t is positive,
so
                          0 ≤ α(t) < 1,   α(t) = 0 ⇐⇒ t = 0.
Hence α takes finite, non-negative values and vanishes exactly at zero.
(b) Show that α is increasing. We show that s ≤ t implies α(s) ≤ α(t). Indeed, if 0 ≤ s ≤ t,
then
                                t(1 + s) − s(1 + t)       t−s
                  α(t) − α(s) =                     =                ≥ 0.
                                   (1 + t)(1 + s)     (1 + t)(1 + s)
(c) Show that α is subadditive. For any s, t ≥ 0,
                         s+t      s     t      s   t
           α(s + t) =         =      +      ≤    +    = α(s) + α(t).
                        1+s+t   1+s+t 1+s+t   1+s 1+t
(d) Apply the proposition and conclude.
Thus the proposition applies and d′ = α ◦ d is a metric on E. Explicitly, this agrees with the metric
axioms (MS1)–(MS3) in the notes: for all x, y, z ∈ S,

                                                       d(x, y)
                                   0 ≤ d′ (x, y) =               < 1,
                                                     1 + d(x, y)

so d′ is finite and non-negative. For (MS1),

                             d′ (x, y) = 0 ⇐⇒ d(x, y) = 0 ⇐⇒ x = y,

For (MS2), symmetry of d gives d′ (x, y) = d′ (y, x). For (MS3), the triangle inequality for d, followed
by monotonicity and subadditivity of α, gives

                                  d′ (x, z) = α(d(x, z))
                                                                     
                                          ≤ α d(x, y) + d(y, z)
                                          ≤ α(d(x, y)) + α(d(y, z))
                                          = d′ (x, y) + d′ (y, z).

Conclusion. Therefore d′ is a metric on S. It is bounded, since every distance is less than 1. □

Equations and shapes
(i) p = 1. The equation is |x1 | + |x2 | = 1. In the first quadrant this is x2 = 1 − x1 , for 0 ≤ x1 ≤ 1.
Reflecting this line segment in the coordinate axes gives a diamond with vertices

                                  (1, 0),    (0, 1),   (−1, 0),    (0, −1).

(ii) p = 2. The equation is x21 + x22 = 1, which is the usual Euclidean unit circle.
(iii) p = ∞. The equation max{|x1 |, |x2 |} = 1 means both coordinates have absolute value at most
1, with at least one having absolute value exactly 1. Thus the sphere is the boundary of the square
[−1, 1]2 , with vertices (±1, ±1).
(iv) p = 3/2. The equation is
                                            |x1 |3/2 + |x2 |3/2 = 1.
