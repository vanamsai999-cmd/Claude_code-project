Section 0: what is a metric?

  Method: Time window: 00:00–00:06; 6 minutes
  Use elapsed time from the start of the session. Read the explanation, try the question with its
  answer covered, then check and correct your work.

  A metric is an abstract distance rule
  A metric on a set S is a function d : S × S → [0, ∞) with finite values satisfying, for all x, y, z ∈ S,

               d(x, y) = 0 ⇐⇒ x = y                         (zero exactly at equal points),
                   d(x, y) = d(y, x)                        (symmetry),
                    d(x, z) ≤ d(x, y) + d(y, z)             (triangle inequality).

  A metric space is the pair (S, d): both the set and the distance rule matter. The triangle inequality
  says going via another point cannot make the total route shorter than the direct distance.
  In R, d(x, y) = |x − y|. In Rn , Euclidean distance is d2 (x, y) =
                                                                     pP
                                                                                     2
                                                                         i |xi − yi | . Different metrics
  on the same set can give different convergence and geometric shapes.

  Method: The metric-verification checklist
  First check the rule is defined and finite for every pair. Check nonnegativity, zero iff equality,
  and symmetry. Then prove the triangle inequality for arbitrary x, y, z. For piecewise definitions,
  separate cases. To disprove a candidate, one failed axiom is enough.

  Exam question: Quick check: attempt for 1 minute

  Is d(x, y) = |x − y|2 a metric on R? Give a decisive reason.

  Worked model answer
  No. With x = 0, y = 1, z = 2, d(0, 2) = 4 but d(0, 1) + d(1, 2) = 1 + 1 = 2. This violates triangle
  inequality. Symmetry and definiteness alone do not make a rule a metric.

  A useful alternate construction
  If ϕ : A → E is injective and dE is a metric, then dA (x, y) = dE (ϕ(x), ϕ(y)) is a metric. All axioms
  transfer from E; injectivity is needed because zero distance between images must imply equality of
  the original points. Example: | arctan x − arctan y| defines a metric on R.

Section 0: discrete and counting metrics

  Method: Time window: 00:06–00:12; 6 minutes
  Use elapsed time from the start of the session. Read the explanation, try the question with its
  answer covered, then check and correct your work.

  The discrete metric
  For any set S, let d(x, y) = 0 when x = y, and 1 otherwise. It ignores numerical size: all different
  points are one unit apart. Its values are finite/nonnegative, its zero condition is built in, and
  equality is symmetric.
  For triangle inequality, if x = z, the left side is zero. If x ̸= z, at least one of x ̸= y and y ̸= z must
  hold, since otherwise x = y = z. Hence the right side is at least 1, which is the left side.

  Exam question: Exercise 0.4 method: attempt for 2 minutes

  For finite sets, define d(A, B) = #(A△B), where A△B consists of points in exactly one of A, B.
  Prove triangle inequality by a set inclusion.

  Worked model answer
  The key inclusion is
                                        A△C ⊆ (A△B) ∪ (B△C).
  If a point has different membership in A and C, its membership in B must differ from at least one
  of those two. Thus it belongs to the union on the right. Taking finite cardinalities gives

                       #(A△C) ≤ #((A△B) ∪ (B△C)) ≤ #(A△B) + #(B△C).

  This is d(A, C) ≤ d(A, B) + d(B, C).

  Check the interpretation with a small example

  For A = {1, 2}, B = {2, 3} and C = {3, 4}, the distances are d(A, B) = 2, d(B, C) = 2 and
  d(A, C) = 4. Here triangle inequality is equality. A numerical example checks the formula but does
  not replace the general proof.

  Exam tips and common mistakes
  For counting arguments, find an inclusion before counting. Do not assume all three points or all
  three sets are distinct when proving a metric axiom.

  The first measures total area of disagreement; the second measures worst error. Since d1 ≤ dsup ,
  small sup error gives small integral error. The converse fails: a height-one triangular spike of width

Section 0 practice: 1a. Metric space axioms I

  Concept and method

  A metric is a finite, non-negative distance with d(x, y) = 0 ⇐⇒ x = y, symmetry and the triangle
  inequality. First test d(x, x), then test distinct points with zero distance. If these pass, prove the
  triangle inequality. A single counterexample disproves an axiom; examples alone cannot prove it
  for every input.

  Exam question: 1a: select every metric on R

   a. d(x, y) = min{1, |x − y|}.
   b. d(x, y) = |x − y| + 1.
   c. d(x, y) = | arctan x − arctan y|, where arctan is the inverse of tan : (−π/2, π/2) → R.
   d. d(x, y) = max{|x|, |y|}.
   e. d(x, y) = |x − y|.

  Worked model answer
  Select a, c and e.
  a: Yes. This caps ordinary distance at 1. Non-negativity and symmetry are immediate, and the
  minimum is zero exactly when x = y. For the triangle inequality, if either |x − y| ≥ 1 or |y − z| ≥ 1,
  then d(x, y) + d(y, z) ≥ 1 ≥ d(x, z). Otherwise both distances are less than 1, and

                        d(x, z) ≤ |x − z| ≤ |x − y| + |y − z| = d(x, y) + d(y, z).

  b: No. d(x, x) = 1, whereas a point must have zero distance from itself.
  c: Yes. It is non-negative and symmetric. Injectivity of arctan gives d(x, y) = 0 ⇐⇒ x = y.
  Also,
                | arctan x − arctan z| ≤ | arctan x − arctan y| + | arctan y − arctan z|.
  d: No. d(1, 1) = 1 ̸= 0.
  e: Yes. Absolute value gives non-negativity, identity and symmetry; the inequality |x − z| ≤
  |x − y| + |y − z| gives the last axiom.

  Exam tips and common mistakes

  For an injective map f : X → R, the formula |f (x) − f (y)| is a metric on X. Injectivity matters:
  without it, distinct inputs could have distance zero. Here tan−1 means inverse tangent, not 1/ tan.

  The language used in proofs
  A ⊆ B means every element of A lies in B. To prove equality, prove both inclusions. The power
  set P(S) is the set of all subsets of S. A union means “at least one”; an intersection means “every”.
  De Morgan’s laws switch union/intersection when taking complements.
    i∈I Si consists of coordinate families with xi ∈ Si . Equality means coordinatewise equality. For
  Q

  I = N, the objects are sequences. The axiom of choice says a product of nonempty sets is nonempty,
  or equivalently one may select an element from each set of an arbitrary nonempty-set family.

  A function includes its domain and codomain
  For f : S → T , injective means f (x) = f (y) ⇒ x = y; surjective means every point of T is attained;
  bijective means both. The range f [S] can be smaller than T .
  A restriction reduces the domain. A co-restriction reduces the codomain to a set still containing
  the range. An extension enlarges the domain while preserving the old values. Composition acts
  from right to left: (g ◦ f )(x) = g(f (x)).
  Images and preimages are

                       f [A] = {f (a) : a ∈ A},      f −1 [B] = {s ∈ S : f (s) ∈ B}.

  An inverse image exists for every function; it does not require an inverse function.

  Exam question: Attempt for 1 minute

  Worked model answer
  The image is {1} and the preimage is {−1, 1}. The map is not injective because the two inputs
  have equal output, and not surjective onto R because no negative value is attained. Changing the
  domain and codomain to [0, ∞) would make the same squaring rule bijective.

Section 1: building bijections and inverses

  Method: Time window: 00:26–00:33; 7 minutes
  Use elapsed time from the start of the session. Read the explanation, try the question with its
  answer covered, then check and correct your work.

  Method: The safest bijection proof
  Either prove injective and surjective separately, or define an inverse and check both compositions.
  For maps involving equivalence classes or functions, check well-definedness first. Do not merely
  state “obvious inverse” when the domain or codomain matters.

  Exam question: Exercise 1.7: attempt for 3 minutes

  Let χ : P(S) → F(S; {0, 1}) send A to its indicator 1A . Prove it is bijective by constructing the
  inverse.

  Worked model answer
  For a binary-valued function f define σ(f ) = {s ∈ S : f (s) = 1}. Then σ(1A ) = A, because an
  indicator is one exactly on A. Conversely, for every s, if f (s) = 1, the point lies in σ(f ) and
  1σ(f ) (s) = 1; if f (s) = 0, the point is outside and the indicator is zero. Thus 1σ(f ) = f . Both
  compositions are identities, so χ is bijective.

  Left versus right inverse
  g ◦ f = idS is a left inverse relation and implies f injective. f ◦ h = idT is a right inverse relation
  and implies f surjective. If both hold, associativity gives

                                    g = g ◦ (f ◦ h) = (g ◦ f ) ◦ h = h.

  Thus a two-sided inverse is unique. A left inverse can be constructed for an injection with nonempty
  domain by inverting on the range and choosing any one fixed output elsewhere. Right inverses of
  arbitrary surjections use choice to pick one point in each fibre.

  Image identities worth retaining

                               A ⊆ f −1 [f [A]],    f [f −1 [B]] = B ∩ f [S].
  Preimages preserve unions, intersections and complements. Images preserve unions, but only
  f [A ∩ B] ⊆ f [A] ∩ f [B] generally. Equality can fail for a constant map and two disjoint nonempty
  sets.

Section 1: relations, partitions and countability

  Method: Time window: 00:33–00:40; 7 minutes
  Use elapsed time from the start of the session. Read the explanation, try the question with its
  answer covered, then check and correct your work.

  Equivalence relation means three properties
  Reflexive: x ∼ x. Symmetric: x ∼ y ⇒ y ∼ x. Transitive: x ∼ y and y ∼ z ⇒ x ∼ z. The class
  [x] = {y : y ∼ x} groups equivalent points. Classes are nonempty, cover the set, and are disjoint
  unless equal; hence they form a partition.
  Conversely a partition gives an equivalence relation by “in the same block”. For any function f , the
  rule x ∼ y ⇐⇒ f (x) = f (y) is an equivalence relation. The induced map [x] 7→ f (x) is a bijection
  from classes to the range. Equal representatives have equal outputs, so the formula is well-defined.

  Exam question: Attempt for 1 minute
  Why do symmetry and transitivity alone not force reflexivity?

  Worked model answer
  They do not guarantee that a point is related to anything. The empty relation on a nonempty set
  is symmetric and transitive vacuously, but no point is related to itself. A proof starting “choose y
  with x ∼ y” would assume an unjustified existence statement.

  Countable does not mean finite
  Countable means there is an injection into N; finite sets are included. Integers are countable via
  the list 0, 1, −1, 2, −2, . . .. Finite products and countable unions of countable sets are countable.
  Rationals are countable because countable Z × N maps onto them via (m, n) 7→ m/n.
  Rational-coefficient polynomials are countable: degree-at-most-k polynomials correspond to tuples
  in Qk+1 ; then take a countable union over k. Finite subsets of N are countable by listing each set’s
  elements increasingly and sorting by its finite size.

  Exam tips and common mistakes
  A countable infinite product can be uncountable. The finite-product rule does not prove that binary
  sequence space {0, 1}N is countable.

Section 2: supremum, infimum and approximation

  Method: Time window: 00:45–00:51; 6 minutes
  Use elapsed time from the start of the session. Read the explanation, try the question with its
  answer covered, then check and correct your work.

  Least upper bound versus maximum
  s = sup A means a ≤ s for every a ∈ A, and no smaller number is an upper bound. A maximum
  must also belong to A. For (0, 1), supremum is 1 but there is no maximum; infimum is 0 but no
  minimum.
  The least upper bound principle guarantees a real supremum for every nonempty upper-bounded
  real set. The corresponding infimum is inf A = − sup(−A). The Archimedean property lets you
  choose n with 1/n < ε. Rationals and irrationals both lie between any two distinct reals.

  Method: The approximation lemma
  For any ε > 0, there is a ∈ A with s − ε < a ≤ s. Otherwise s − ε would itself be an upper bound
  smaller than s. Choosing ε = 1/n gives a sequence an ∈ A converging to s.
  For an infimum l, choose an with l ≤ an < l + 1/n. This is how to choose approximately closest
  points when an actual minimiser may not exist.

  Exam question: Exercise 2.6: attempt for 2 minutes

  Show sup(Q ∩ [0, 2π]) = 2π and decide whether this is a maximum.

  Worked model answer
  2π is an upper bound and the set is nonempty because it contains zero. For any ε > 0, rational
  density gives a rational q with max{0, 2π − ε} < q < 2π. Thus q belongs to the set and lies above
  2π − ε. No smaller number can be an upper bound, proving the supremum is 2π. It is not a
  maximum, since 2π is irrational and is absent from the set.

  Exam tips and common mistakes

  Never assume a supremum or infimum is attained. Approximate it with an error such as 1/n or ε
  unless you have a theorem guaranteeing attainment.

  The three definitions

                           xn → a ⇐⇒ ∀ε > 0 ∃N ∀n ≥ N : |xn − a| < ε.
                      (xn ) Cauchy ⇐⇒ ∀ε > 0 ∃N ∀n, m ≥ N : |xn − xm | < ε.
  Bounded means |xn | ≤ M for every n and one finite M . Convergent implies Cauchy implies
  bounded. In R, Cauchy also implies convergent. Bounded alone does not: (−1)n oscillates forever.
  A subsequence xnk has strictly increasing indices. Bolzano–Weierstrass says every bounded real
  sequence has a convergent subsequence. A bounded increasing sequence converges to its supremum;
  the decreasing version uses its infimum.

  Limsup and liminf are limits of tail bounds

  For bounded (xn ) put un = supk≥n xk and ln = inf k≥n xk . Then un decreases, ln increases, and

                              lim sup xn = lim un ,        lim inf xn = lim ln .
                                            n                             n

  The sequence converges iff these two values agree. For xn = (−1)n + 1/n, even terms tend to 1 and
  odd terms to −1, so limsup is 1 and liminf is −1.

  Exam question: Attempt for 2 minutes
  Prove uniqueness of limits. Start from xn → a and xn → b.

  Worked model answer
  For every n, |a − b| ≤ |a − xn | + |xn − b|. Both terms tend to zero, so |a − b| = 0 and a = b. In an
  explicit contradiction proof, if a ̸= b, choose ε = |a − b|/3 and a common large cutoff making both
  distances below ε; then |a − b| < 2|a − b|/3, impossible.

  Exam tips and common mistakes
  For two convergent sequences, combine their cutoffs by taking the maximum. For two error terms,
  begin with tolerance ε/2. These are choices you can reuse throughout the module.

  Minimal linear algebra revision

Section 2 practice: 2e. Subsequences and increasing sequences

  Concept and method
  A subsequence is xnk with strictly increasing indices n1 < n2 < · · · . It preserves the original order.
  Increasing means xn+1 ≥ xn ; decreasing means xn+1 ≤ xn . An “if and only if” statement requires
  both implications. Test constants and oscillating sequences when looking for counterexamples.

  Exam question: 2e: select all true statements

  Let (xn ) be a real sequence.
   a. (xn ) is increasing if and only if yn = xn+1 − xn takes only non-negative values.
  b. (xn ) is not increasing if and only if it is decreasing.
   c. (xn ) cannot be both increasing and decreasing.
  d. (xn ) is increasing if and only if (−xn ) is decreasing.
   e. (xn ) is increasing if and only if it does not have a decreasing subsequence.

  Worked model answer
  Select a and d.
  a: True. xn+1 ≥ xn ⇐⇒ xn+1 − xn ≥ 0 for every n. This is exactly the definition.
  b: False. xn = (−1)n is neither increasing nor decreasing. “Not increasing” only requires at least
  one downward step, not that every step is downward. A constant sequence also disproves the
  reverse implication: it is decreasing but is increasing too.
  c: False. xn = 3 is both. Indeed, a sequence is both increasing and decreasing exactly when it is
  constant, since the two inequalities force xn+1 = xn .
  d: True. xn+1 ≥ xn ⇐⇒ −xn+1 ≤ −xn .
  e: False. A constant sequence is increasing and has constant, hence decreasing, subsequences.
  The converse fails too: xn = n + 2(−1)n begins −1, 4, 1, 6, 3, 8, . . ., so it is not increasing. Yet
  xn ≥ n − 2 → +∞; every subsequence therefore tends to +∞. No subsequence can be decreasing,
  because it would then be bounded above by its first term.

  Exam tips and common mistakes
  Do not confuse “decreasing” with “strictly decreasing”. Constant sequences often decide multiple-
  choice questions about monotonicity. The negation of “every step is upwards or level” is “at least
  one step goes down”.

Section 2 practice: 2f. Uniform continuity

  Concept and method

                   ∀ε > 0 ∃δ > 0 ∀x, y ∈ D :    |x − y| < δ =⇒ |f (x) − f (y)| < ε.

  The most reusable distance estimate
  From triangle inequality, d(x, p) ≤ d(x, y) + d(y, p), so d(x, p) − d(y, p) ≤ d(x, y). Swap x, y to
  bound the opposite difference. Together,

                                        |d(x, p) − d(y, p)| ≤ d(x, y).

  Consequently xn → a implies d(xn , p) → d(a, p). More generally,

                                    |d(a, b) − d(c, e)| ≤ d(a, c) + d(b, e),

  by routing one distance through the other pair, subtracting and swapping.

  Diameter and distance to a set
  diam A = supx,y∈A d(x, y). Bounded means finite diameter. Containment in BR [p] implies diameter
  at most 2R. Conversely, for nonempty bounded A, choose a ∈ A: d(p, x) ≤ d(p, a) + diam A for
  every x ∈ A, placing the set in a finite-radius ball about any fixed p.
  For nonempty A, define distA (x) = inf a∈A d(x, a). It is 1-Lipschitz. Zero distance means a point
  can be approximated arbitrarily closely from A, not necessarily that it lies in A.

  The definitions that start most topology questions

  U is open in E if every p ∈ U admits some r > 0 with Br (p) ⊆ U . Your radius may depend on
  the point. A set F is closed in E if every sequence of its points converging in E has its limit in F .
  Equivalently its complement is open.
  The empty set and whole space are both open and closed. A set may be open, closed, both, or
  neither. In usual R, (0, 1) is open, [0, 1] closed, and [0, 1) neither. In a discrete space every subset
  is both open and closed.
  Arbitrary unions and finite intersections of open sets are open. For an intersection, choose the
                                                                                         T
  minimum of finitely many available positive radii. Infinite intersections may fail: n (−1/n, 1/n) =
  {0} is not open in R. Dually, arbitrary intersections and finite unions of closed sets are closed.

  Three ways to describe a set locally
  Int A consists of points with some ball contained in A. It is the largest open subset of A.
  The closure A consists of points whose every ball meets A. Equivalently, p ∈ A iff some an ∈ A
  tends to p. Choose an ∈ A ∩ B1/n (p) to construct such a sequence. Closure is the smallest closed
  superset. For nonempty A, p ∈ A iff dist(p, A) = 0.
  Boundary is ∂A = A \ Int A = A ∩ E \ A. Every ball about a boundary point meets both the set
  and its complement. In R, Int Q = ∅ but Q = ∂Q = R.

  Relative topology changes which points matter
  For V ⊆ A ⊆ E, V is open in A iff V = A ∩ U for ambient open U . It is closed in A iff V = A ∩ F
  for ambient closed F . The metric ball identity is BrA (a) = A ∩ BrE (a).
  Thus [0, 1) is both open and closed in itself, even though neither in usual R. Never omit the
  ambient space when its identity is unclear.

  Exam question: Attempt for 2 minutes

  For V = [0, 1), find interior, closure and boundary in (a) R and (b) the subspace A = [0, 2].

  Worked model answer
  In R, interior is (0, 1), closure is [0, 1], boundary is {0, 1}. In A, V = A ∩ (−1, 1) is open, so relative
  interior is [0, 1). Relative closure is A ∩ [0, 1] = [0, 1], hence relative boundary is {1}. Zero becomes
  an interior point because negative points no longer belong to the space.

Section 4: continuity through open preimages

  Method: Time window: 02:01–02:08; 7 minutes
  Use elapsed time from the start of the session. Read the explanation, try the question with its
  answer covered, then check and correct your work.

  Choose among equivalent continuity tests
  For f : E → F , metric continuity means small input distance from p gives small output distance
  from f (p), for each p. It is equivalent to preserving limits of sequences. Globally it is equivalent
  to every open target set having open preimage, and also to every closed target set having closed
  preimage.
  For sequential continuity implying continuity, negate continuity: obtain one fixed ε0 > 0 and points
  xn with d(xn , p) < 1/n but d(f (xn ), f (p)) ≥ ε0 . These contradict preservation of sequence limits.

  Exam question: 2023 Q2(c) / 2025 Q3(f) method: attempt for 2 minutes

  Prove continuity iff open sets have open preimages.

  Worked model answer
  If f is continuous and p ∈ f −1 [V ] for open V , choose ε > 0 with Bε (f (p)) ⊆ V . Continuity gives
  δ > 0 with f [Bδ (p)] ⊆ Bε (f (p)). Thus Bδ (p) ⊆ f −1 [V ], proving openness.
  Conversely suppose all open preimages are open. For p and ε > 0, W = f −1 [Bε (f (p))] is open
  and contains p. Some δ > 0 satisfies Bδ (p) ⊆ W . Hence d(x, p) < δ implies d(f (x), f (p)) < ε,
  establishing continuity.

  Exam tips and common mistakes
  Continuity controls inverse images, not direct images. A constant continuous f : R → R sends
  any nonempty open interval to a singleton, which is not open in R. A homeomorphism needs a
  continuous inverse as well as continuity and bijectivity.

Section 4: density and separability

  Method: Time window: 02:08–02:14; 6 minutes
  Use elapsed time from the start of the session. Read the explanation, try the question with its
  answer covered, then check and correct your work.

  A dense set gets arbitrarily close to every point

  D dense in E means D = E, equivalently every nonempty open ball meets D, equivalently each
  point is a limit of a sequence from D. Separable means there is a countable dense subset.
  Qn is countable dense in Rn . In C([0, 1]) with sup metric, use continuous piecewise-linear functions
  on dyadic meshes with rational vertex values. For each fixed mesh the finite tuple of rationals makes
  the family countable. Taking all meshes keeps it countable. Uniform continuity lets a sufficiently
  fine mesh approximate a continuous function, and rationally approximating vertex values then
  interpolating makes the sup error small.
  Every open subset of R is a countable union of open intervals with rational endpoints: around each
  point select one contained in the set; there are only countably many candidate endpoint pairs.

  Exam question: 2023 Q3(a) / 2024 Q2(d) method: attempt for 2 minutes

  If D dense and U open dense, prove D ∩ U dense. Why is openness needed?

  Worked model answer
  Take any ball Br (p). Density of U gives u ∈ Br (p) ∩ U . This intersection is open, so contains a ball
  Bs (u). Density of D supplies a point in Bs (u) ∩ D, hence in Br (p) ∩ U ∩ D. Every ball therefore
  meets U ∩ D, proving density.
  Without openness take rationals and irrationals in R: both are dense but their intersection is
  empty.

Section 4: equivalent metrics and homeomorphisms

  Method: Time window: 02:14–02:20; 6 minutes
  Use elapsed time from the start of the session. Read the explanation, try the question with its
  answer covered, then check and correct your work.

  What each kind of equivalence preserves
  Topological equivalence means the identity map in both directions is continuous, equivalently the
  metrics have the same open sets or the same convergent sequences with the same limits.
  Lipschitz equivalence requires constants c, C > 0 with c d ≤ d′ ≤ C d. This preserves boundedness
  and Cauchyness as well as topology. All finite-dimensional ℓp metrics are Lipschitz equivalent by
  the norm-comparison inequalities.
  Cauchy equivalence means exactly the same Cauchy sequences. The transformed metrics min{1, d}
  and d/(1 + d) preserve Cauchy sequences and topology; if d is unbounded they cannot be Lips-
  chitz equivalent to it. A homeomorphism is a bijection with both it and its inverse continuous;
  completeness need not be preserved by an arbitrary homeomorphism.

  Exam question: 2024 Q3 method: attempt for 2 minutes

  Explain why dN S (x, y) = | arctan x − arctan y| on R has the usual topology but different Cauchy
  sequences.

  Worked model answer
  The map arctan is a homeomorphism from the usual real line to (−π/2, π/2), so its pullback
  metric gives the usual topology. But xn = n is Cauchy for dN S because arctan n → π/2. It is not
  Cauchy in the usual metric, since adjacent terms stay distance one apart. Thus these topologically
  equivalent metrics are not Cauchy equivalent.

  Exam tips and common mistakes

  Do not confuse | arctan x − arctan y| with arctan(d(x, y)). The first changes Cauchy behaviour on
  R; the second is a distance transform that preserves it. For countable products, the weighted-tail
  argument connects coordinatewise convergence to product convergence.

  Exam question: Five-minute recall test: cover all earlier pages
  Write short answers without looking. Allow about one minute for each item.
  1. State all metric axioms. Give one reason |x − y|2 is not a metric on R.
  2. Define the inverse of the indicator-function bijection A 7→ 1A . State why both compositions are
     identities.
  3. Let s = sup A for nonempty upper-bounded A. Explain how to choose an ∈ A with an → s.
  4. Derive |d(x, p) − d(y, p)| ≤ d(x, y).
  5. State the open-preimage test for continuity and prove that continuous maps have open preimages
     of open sets.

  Worked model answer
  1. Finite nonnegative distances; zero iff equality; symmetry; triangle inequality. Squared distance
  fails at 0, 1, 2, since 4 > 1 + 1.
  2. Send f : S → {0, 1} to {s : f (s) = 1}. An indicator’s one-set is exactly the original subset, and
  the indicator of a binary function’s one-set agrees with the function at every input.
  3. Choose s − 1/n < an ≤ s. Such a point exists because otherwise s − 1/n is an upper bound
  smaller than s. Then 0 ≤ s − an < 1/n → 0.
  4. Triangle inequality gives d(x, p) − d(y, p) ≤ d(x, y); swap x, y to bound the negative of this
  difference by the same quantity. The absolute-value bound follows.
  5. Continuity is equivalent to every open target set having open preimage. If p ∈ f −1 [V ], openness
  of V gives Bε (f (p)) ⊆ V . Continuity gives δ > 0 with f [Bδ (p)] ⊆ Bε (f (p)), so Bδ (p) ⊆ f −1 [V ].
  Thus the preimage is open.
