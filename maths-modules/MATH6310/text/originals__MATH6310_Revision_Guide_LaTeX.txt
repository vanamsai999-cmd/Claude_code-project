1 Section 0: What is a Metric Space?

  Key idea
  A metric space is simply a set together with a rule for measuring distance. The power of the idea is
  that once a distance satisfies three basic axioms, we can study convergence, continuity and topology
  in many settings using the same language.


1.1 The definition you must know

  Definition
  A metric on a set S is a function
                                               d : S × S → [0, ∞)
  such that for all x, y, z ∈ S:

                                    (MS1)      d(x, y) = 0 ⇐⇒ x = y,
                                    (MS2)      d(x, y) = d(y, x),
                                    (MS3)      d(x, z) ≤ d(x, y) + d(y, z).

  The pair (S, d) is called a metric space.

  Exam focus
  When asked to prove that a proposed formula defines a metric, structure your answer as:
   1. non-negativity / finiteness if needed;
   2. d(x, y) = 0 ⇐⇒ x = y;
   3. symmetry;
   4. triangle inequality.
  The triangle inequality is usually the only genuinely difficult part.


1.2 The standard metric on R

                                               d(x, y) = |y − x|.
This works because absolute value satisfies:

                        |a| = 0 ⇐⇒ a = 0,          | − a| = |a|,                |a + b| ≤ |a| + |b|.

  Key idea
  The same underlying set can carry very different metrics. For example, R with the usual metric and
  R with the discrete metric are different metric spaces.

  Exam focus
  To prove the triangle inequality for the discrete metric, the only nontrivial case is s ̸= t. Then
  d(s, t) = 1, while d(s, u) + d(u, t) ≥ 1 because at least one of s ̸= u or u ̸= t must hold.


1.5 Counting metric on finite subsets

For a finite set S and A, B ⊆ S,

where

is the symmetric difference.

  Key idea

  Interpretation: d(A, B) counts how many elements you must “toggle” to turn A into B.

2.5 Axiom of Choice

  Theorem / Proposition

                                                  Y

  Key idea

3 Functions

3.1 What a function actually contains

A function f : S → T has three ingredients:
1. a domain S;
2. a codomain T ;
3. a rule assigning exactly one value f (s) ∈ T to every s ∈ S.

  Common trap
  A function is not determined only by its formula. Changing the domain or codomain can change
  whether it is injective, surjective or bijective.


3.2 Important examples

• Identity: idS (s) = s.
• Inclusion: ιA→S : A → S, a 7→ a.
• Indicator:                                             (

• Constant function: f (s) = t0 for all s.
• Coordinate projection from a product: (sj )j∈J 7→ sk .

4 Injective, Surjective and Bijective Maps

  Definition
  For f : S → T :
  • Injective: f (s1 ) = f (s2 ) ⇒ s1 = s2 .
  • Surjective: Ran f = T .
  • Bijective: both injective and surjective.

  Key idea
  Injection: no two inputs collide.
  Surjection: no target is missed.
  Bijection: perfect one-to-one matching.


4.1 Composition facts

For f : S → T and g : T → U :
• if f and g are injective, then g ◦ f is injective;
• if g ◦ f is injective, then f is injective;
• if f and g are surjective, then g ◦ f is surjective;
• if g ◦ f is surjective, then g is surjective;
• if f and g are bijective, then g ◦ f is bijective.


4.2 Left and right inverses

  Theorem / Proposition

  Ignoring the special empty-set edge case noted in the lectures:

                                f injective ⇐⇒ ∃g : T → S with g ◦ f = idS ,
                               f surjective ⇐⇒ ∃h : T → S with f ◦ h = idT ,
                                f bijective ⇐⇒ f has a two-sided inverse.

  Exam focus
  A standard way to prove injectivity is to start with

                                                    f (x) = f (y)

  and algebraically deduce x = y. To prove surjectivity, start with an arbitrary target t ∈ T and solve
  f (s) = t for an input s ∈ S.

5.1 Direct image

6 Schröder–Bernstein

  Theorem / Proposition

  If there is an injection S → T and an injection T → S, then there is a bijection S → T .

  Exam focus

7 Equivalence Relations and Partitions

  Definition
  A relation ∼ on a nonempty set S is an equivalence relation if it is:
  • reflexive: s ∼ s;
  • symmetric: s ∼ t ⇒ t ∼ s;
  • transitive: r ∼ s and s ∼ t ⇒ r ∼ t.

For a ∈ S, the equivalence class is
                                            [a] = {s ∈ S : s ∼ a}.
The quotient set is
                                            S/ ∼= {[a] : a ∈ S}.


7.1 Example: congruence modulo p

For prime p,
                                          n ≡p m ⇐⇒ p | (m − n).
The equivalence classes are the residue classes
                                            [0]p , [1]p , . . . , [p − 1]p ,
and these split Z into disjoint pieces.


7.2 Partitions

  Definition
  A collection C of subsets of S is a partition if:
            C = S;
        S
   1.
   2. every C ∈ C is nonempty;
   3. distinct members of C are disjoint.

  Theorem / Proposition

  Equivalence relations and partitions are two ways of describing the same structure:
  • equivalence classes of an equivalence relation form a partition;
  • a partition defines an equivalence relation by saying two elements are related exactly when they lie
    in the same block.

  Key idea
  Every function can be viewed as: first collapse together inputs with the same output, then make a
  perfect bijection with the range, then include the range inside the codomain.



8 Countability

  Definition
  A set S is countable if there exists an injection

                                                f : S → N.

  Thus finite sets are countable, and an infinite countable set can be listed in a sequence.


8.1 Useful tests

If S ̸= ∅, then S is countable iff there is a surjection N → S.
If T is countable, then S is countable whenever either:
• there is an injection S → T , or
• there is a surjection T → S.


8.2 Standard examples

• N is countable.
• Z is countable.
• NN is countable for each fixed finite N .
• finite Cartesian products of countable sets are countable.
• Q is countable because Z × N → Q, (n, m) 7→ n/m, is surjective.
• a countable union of countable sets is countable.

  Exam focus
  For countability questions, try one of three standard moves:
   1. build an injection into a known countable set;

   2. build a surjection from a known countable set;
   3. write the target as a countable union of countable pieces.


8.3 Classic applications

The lecture notes use the countable-union principle to show that:
• polynomials with rational coefficients form a countable set;
• the set of all finite subsets of N is countable.


9 Cantor’s Theorem and Uncountability

  Theorem / Proposition

  For every set S, there is no surjection
                                                  S → P(S).
  Equivalently, the power set P(S) is strictly “larger” than S in cardinality.


9.1 The diagonal idea

Assume for contradiction that ϕ : S → P(S) is surjective. Define

                                            D = {s ∈ S : s ∈
                                                           / ϕ(s)}.

Since D ⊆ S, surjectivity says D = ϕ(x) for some x ∈ S.
Now ask whether x ∈ D:
• If x ∈ D, then by definition x ∈
                                 / ϕ(x) = D.
• If x ∈
       / D, then by definition x ∈ ϕ(x) = D.
Either way gives a contradiction.

  Key idea
  The diagonal construction creates an object deliberately designed to differ from the sth listed object
  at position s. Therefore no proposed list can contain everything.


9.2 Binary sequences are uncountable

The notes identify

                                                    = {0, 1}N .
By Cantor’s theorem, these sets are uncountable.

11 Proof Templates You Should Be Able to Reproduce

1. Set equality: take an arbitrary element and prove membership both ways.
2. Injectivity: assume f (x) = f (y) and derive x = y.
3. Surjectivity: let t be arbitrary in the codomain and find s with f (s) = t.
4. Equivalence relation: verify reflexive, symmetric, transitive separately.
5. Metric: verify zero-distance criterion, symmetry and triangle inequality.
6. Countability: construct an injection/surjection or decompose into countable pieces.
7. Cantor diagonal argument: assume a complete listing exists, construct an object that differs from
   every listed object on its diagonal position.
