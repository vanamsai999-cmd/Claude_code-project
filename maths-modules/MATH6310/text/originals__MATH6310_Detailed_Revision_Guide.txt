  Exam tips and common mistakes
  A proof is a chain of justified statements, not a list of theorem names. State where each
  assumption enters. For an “if and only if”, prove both directions. For limits and compactness,

  compactness and products. Revisit real analysis whenever a proof uses a supremum, an
  infimum or a subsequence. After each topic, attempt its question before reading the answer;
  then reproduce the proof with the answer hidden.

0.2    Metric axioms and core examples

  What a metric means
  A metric is a function d : S × S → [0, ∞) satisfying, for all x, y, z ∈ S,

         d(x, y) = 0 ⇐⇒ x = y,           d(x, y) = d(y, x),      d(x, z) ≤ d(x, y) + d(y, z).

  Distances must be finite. A metric space is the pair (S, d): the same set with a different
  metric may have different convergence, boundedness or completeness properties.
  Intuition: distance distinguishes points, is independent of direction, and a detour cannot
  beat the direct distance. Most metric proofs reduce to the triangle inequality.

  Method: Metric verification
  Check the candidate is defined and finite on every pair. Prove definiteness in both directions.
  Prove symmetry. For the triangle inequality, either apply a known norm inequality, work
  pointwise then sum/supremise, or split cases for piecewise formulas. To disprove a candidate
  it suffices to exhibit one failed axiom. For example d(x, y) = |x − y|2 fails with x = 0, y =
  1, z = 2, since 4 > 1 + 1.

  Discrete metric and counting metric
  The discrete metric is d(x, y) = 0 for x = y and 1 otherwise. It works on any set. If x ̸= z,
  at least one of x ̸= y and y ̸= z holds, so the right side of the triangle inequality is at least 1.
  For finite subsets A, B of a set,

                      d(A, B) = #(A△B),           A△B = (A \ B) ∪ (B \ A).

  This counts the membership changes needed to transform A into B. Since

                                     A△C ⊆ (A△B) ∪ (B△C),

  cardinality gives the triangle inequality. If the underlying set is infinite, restrict to finite
  subsets to ensure the formula stays finite.

  Exam question: Section 0 Exercises 0.1 and 0.4: model metric proofs
 (a) Prove the discrete metric is a metric. (b) Prove the counting metric satisfies the triangle
 inequality.

  Worked model answer
 (a) Its values are 0 and 1, hence finite and nonnegative. By definition d(x, y) = 0 exactly
 when x = y. Equality/inequality of points is symmetric, so d(x, y) = d(y, x). Let x, y, z ∈ S.
 If x = z, the left side is zero, so the triangle inequality holds. If x ̸= z, x = y = z is
 impossible, so d(x, y) + d(y, z) ≥ 1 = d(x, z). This proves all axioms.
 (b) Let s ∈ A△C. Its membership in A and C differs. If its membership in B agrees with A,
 it differs from C, so s ∈ B△C. Otherwise s ∈ A△B. Hence the displayed inclusion holds.

0.3        Function metrics, Hausdorff distance and unusual metrics

  Integral and sup metrics on functions
  For continuous real functions on I = [0, 1],
                                               Z
                                 d1 (f, g) =       |f − g|,   dsup (f, g) = sup |f (t) − g(t)|.
                                               I                            t∈I

  The first measures total discrepancy; the second measures worst-case discrepancy. Integral
  definiteness uses continuity, as proved earlier. For the sup metric, definiteness follows because
  if the supremum is zero, every pointwise difference is zero. The pointwise inequality

                           |f (t) − h(t)| ≤ |f (t) − g(t)| + |g(t) − h(t)| ≤ dsup (f, g) + dsup (g, h)

  gives the triangle inequality upon taking a supremum.
  Since d1 ≤ dsup , uniform convergence implies integral convergence. The converse fails:
  continuous triangular spikes of height 1 and support [0, 1/n] have integral 1/(2n) but sup
  norm 1.

  The general sup-metric space ℓ∞ (S; E)
  This is the set Fb (S; E) of functions with bounded image, with metric

                                 dsup (f, g) = sup dE (f (s), g(s)).
                                                    s∈S

  For nonempty S, fix s0 ∈ S. Then

                    d(f (s), g(s)) ≤ diam f (S) + d(f (s0 ), g(s0 )) + diam g(S),

  so the supremum is finite. Metric axioms follow pointwise and then by taking the supremum.
  For empty S there is a single function; give that singleton its zero metric. No vector-space
  structure of E is required.

  Hausdorff distance: distance between whole sets
  For nonempty closed bounded subsets of Rn , put
                                          (                                  )
                       dH (A, B) = max sup dist(a, B), sup dist(b, A) .
                                              a∈A               b∈B

  Equivalently, it is the infimum of δ ≥ 0 such that each set lies in the other’s δ-fattening.
  Nonemptiness makes the distance-to-set expression meaningful; boundedness ensures finite-
  ness; closedness ensures zero distance means equality.
  If A ⊆ B, then Aδ ⊆ Bδ . If x ∈ (Aγ )δ , choose y ∈ Aγ with d(x, y) ≤ δ and a ∈ A with
  d(y, a) ≤ γ. Then d(x, a) ≤ γ + δ, so (Aγ )δ ⊆ Aγ+δ (for the fattenings defined by existence
  in the supplied notes).

  Exam question: Section 0 Exercise 0.6: Hausdorff triangle inequality
  Deduce dH (A, C) ≤ dH (A, B) + dH (B, C) from the fattening properties.

  Worked model answer
  Let a = dH (A, B) and b = dH (B, C), and fix ε > 0. By the definition of infimum and
  monotonicity of fattening, choose admissible radii r < a + ε and s < b + ε such that A ⊆ Br ,
  B ⊆ Ar , B ⊆ Cs , C ⊆ Bs . Then

                     A ⊆ Br ⊆ (Cs )r ⊆ Cr+s ,             C ⊆ Bs ⊆ (Ar )s ⊆ Ar+s .

  Thus dH (A, C) ≤ r + s < a + b + 2ε. Let ε ↓ 0 to obtain the triangle inequality. The small
  error terms avoid assuming an infimum is attained.

  TGV metrics and pullbacks
  On R2 , the TGV metric is dT (x, y) = ∥x∥2 + ∥y∥2 for distinct points and zero on the diagonal.
  The radial variant uses ∥x − y∥2 when x, y are linearly dependent, and the sum of norms
  otherwise.
  For dT , if the intermediate point equals an endpoint the triangle inequality is equality;
  otherwise the right side includes the norms of both endpoints and an additional 2 ∥y∥. For

  the radial variant, distances are lengths of shortest permitted paths along lines through the
  origin. Algebraically: if the endpoints are dependent, each leg dominates Euclidean distance.
  If the endpoints are independent and both legs are independent, the result is immediate.
  If exactly one leg is dependent, use ∥x∥ ≤ ∥x − y∥ + ∥y∥ (or the analogous inequality for
  the other endpoint). Both legs cannot be dependent with y ̸= 0 unless the endpoints are
  dependent. With y = 0, both legs sum to ∥x∥ + ∥z∥.
  An injective map ϕ : A → (E, d) defines a pullback metric dA (x, y) = d(ϕ(x), ϕ(y)). Injectiv-
  ity is needed for definiteness. Example:

                          dN S (x, y) = | arctan x − arctan y| (x, y ∈ R).

  This is bounded by π and is isometric to the usual interval (−π/2, π/2). It is not induced
  by a norm on R, because a norm would make d(0, n) = n ∥1∥ unbounded.

  Exam question: Additional practice: why continuity depends on the metric
  For the TGV metric on R, show that the identity from TGV to the usual metric is Lipschitz,
  but the reverse identity is continuous only at zero.

  Worked model answer
  For distinct x, y, |x − y| ≤ |x| + |y| = dT (x, y); on the diagonal both distances are zero. Thus
  the identity to the usual metric is 1-Lipschitz. At zero dT (x, 0) = |x|, so the reverse identity
  is continuous there. If a =  ̸ 0, take xn = a + 1/n. Then xn → a in the usual metric but
  dT (xn , a) = |a + 1/n| + |a| → 2|a| > 0. Therefore the reverse identity is not continuous at a
  and the metrics are not topologically equivalent.



0.4    Proof clinic: Quantifiers: what the examiner is asking you to
       construct

  Read a definition as a conversation
  For openness, someone gives you a point p ∈ U . You must answer with a positive radius r,
  and then prove that every point inside that ball stays in U . Your radius may depend on p.
  This is why an interval such as (0, 1) is open even though points near its endpoints need
  very small radii.
  For convergence, someone gives you an accuracy ε > 0. You must answer with a cutoff N ,
  after which every term is close enough. A finite number of failures before N does not matter.
  The cutoff may depend on ε, but not on the later index n.
  For Cauchyness, after your cutoff all pairs of terms must be close. You do not choose a
  separate cutoff for each later pair. That is why showing d(xn , xn+1 ) → 0 does not suffice: it
  controls adjacent terms, rather than arbitrary pairs.
  For sequential compactness, you are given any sequence and must extract a suitable subse-
  quence. You do not need the original sequence itself to converge. For example (−1)n lies in
  the compact interval [−1, 1] but does not converge; its even subsequence is constantly 1.

  Exam question: Additional practice: spot the quantifier error
  A student argues: “For each n, choose N = n + 1. Then all terms after N are late, so the
  sequence converges.” What is missing?

  Worked model answer
  There is no proposed limit and no bound on the distance to it. More fundamentally, the
  required cutoff must be chosen after the tolerance but before the universally quantified later
  index. Writing N = n + 1 makes the cutoff depend on the very index it is supposed to
  control. A valid proof must name a point a and, for each ε, choose one N (ε) such that
  d(xn , a) < ε holds for every n ≥ N (ε).



0.5    Proof clinic: A manageable routine for each topic

  Use the expanded notes actively
  First pass: read the intuitive explanation and one example. Say the idea aloud in ordinary
  words. For instance, complete means that sequences whose terms become mutually close do
  not run into missing points.
  Second pass: write the formal definition from memory. Check every quantifier and where
  the metric is evaluated. Then reconstruct the proof’s main estimate before reading the
  intermediate steps.
  Third pass: attempt a numbered lecture exercise. Read only the method box if stuck.
  After checking the solution, close the notes and write the argument again in your own words.
  Fourth pass: attempt a past-paper question on the same topic. Give reasons for each
  implication and verify every theorem hypothesis. Collect an example and a counterexample
  beside the definition.
  The objective is to recognise the structure of a new question: local-radius construction,
  sequence-limit argument, infimum approximation, uniform-error estimate, subsequence
  extraction, or fixed-point verification. Those structures recur across the whole supplied
  module material.

0.6.1   Exercise 0.1: The discrete metric

  Exam question: Lecture exercise
  For any set S, put d(x, y) = 0 if x = y and d(x, y) = 1 otherwise. Prove d is a metric.

  Method: Use the two possible values
  The first axioms follow directly from the definition. The triangle inequality only needs
  thought when its left side is 1. Ask whether both terms on the right could then be zero.

  Worked model answer
  The function is defined for every pair and takes finite nonnegative values. By construction,
  d(x, y) = 0 exactly when x = y. Since x = y iff y = x, the definition gives d(x, y) = d(y, x).
  Fix x, y, z ∈ S. If x = z, then d(x, z) = 0 and the right side of the triangle inequality is
  nonnegative. If x ̸= z, then at least one of x = ̸ y, y = ̸ z holds: otherwise x = y = z, a
  contradiction. Therefore at least one of d(x, y), d(y, z) is 1, giving

                                  d(x, z) = 1 ≤ d(x, y) + d(y, z).

  Thus the triangle inequality holds for every triple, and d is a metric.

  Exam tips and common mistakes
  Do not assume the three points are distinct. A metric axiom must hold for repeated points
  too. Separating the case x = z handles this safely.


0.6.2   Exercise 0.2: Why integral distance distinguishes continuous functions

  Exam question: Lecture exercise
                                          R1
  For continuous h : [0, 1] → R, prove    0 |h(t)| dt = 0 ⇒ h = 0.


  Method: Prove the contrapositive
  If h is nonzero somewhere, continuity prevents its absolute value from dropping immediately
  to zero. It stays above a positive height on an interval of positive length; that creates positive

0.6.3   Exercise 0.3: The sup metric

  Exam question: Lecture exercise
  For f, g ∈ C([0, 1]; R), let dsup (f, g) = supt |f (t) − g(t)|. Prove definiteness and triangle

  Worked model answer
  Continuous functions on the compact interval are bounded, so the supremum is finite. If

                                0 ≤ |f (t) − g(t)| ≤ dsup (f, g) = 0.

1.2      Functions, restrictions, inverses and images

  A function has three ingredients
  Specify a domain, codomain, and one output in the codomain for each input. The range is the
  outputs actually attained, so it need not equal the codomain. Identity maps, inclusion maps,
  constant maps, coordinate projections and indicator functions are fundamental examples.
  An indicator 1A : S → {0, 1} is one on A and zero elsewhere in S.
  For f : S → T and g : T → U , (g ◦ f )(s) = g(f (s)). Composition is associative but generally
  not commutative. Restricting f to A ⊆ S reduces its domain. Extending it reverses that
  operation. Co-restricting its codomain to B is permitted when the entire range lies in B.

  There is exactly one function from ∅ to any T , and no function from a nonempty set to ∅.
  If finite sets have n domain points and m codomain points, there are mn functions.

  Injectivity, surjectivity and inverses
  Injective means f (x) = f (y) ⇒ x = y. Surjective means every target value is attained.
  Bijective means both. The same squaring rule is not injective on R, but is injective on
  [0, ∞); changing the codomain also changes surjectivity.
  A left inverse satisfies g ◦ f = idS , which forces f injective. Conversely an injection with
  nonempty domain has a left inverse: invert on the range and send all other target points to
  one fixed domain point. The empty-domain exception is important.
  A right inverse satisfies f ◦ h = idT , which forces surjectivity. Conversely choose one point
  in each fibre f −1 [{t}] to obtain a right inverse of a surjection, using choice. A bijection has
  a two-sided inverse. If g is a left inverse and h a right inverse, associativity gives

  Hence a two-sided inverse is unique.

1.3    Equivalence relations, partitions and canonical factorisation

  Equivalence classes group indistinguishable elements
  An equivalence relation is reflexive, symmetric and transitive. Its class [a] = {x : x ∼ a}
  contains a, and two classes are either identical or disjoint. The set of classes is S/∼, and
  q(s) = [s] is the surjective quotient map.
  A partition is a family of nonempty disjoint subsets whose union is S. Equivalence classes form
  a partition: reflexivity covers every point, and symmetry/transitivity show that intersecting
  classes coincide. Conversely a partition defines x ∼ y when they lie in the same block.
  Coverage gives reflexivity; sharing a block gives symmetry; the uniqueness of the block
  containing an intermediate point gives transitivity. These constructions undo one another.
  Congruence modulo an integer p ≥ 2 groups integers into residue classes. Equality gives
  singleton classes; the full relation gives one class. The empty relation on a nonempty set is
  symmetric and transitive but not reflexive.

  Every function factors through its fibres
  For f : S → T , define x ∼f y iff f (x) = f (y). This is an equivalence relation. The
  formula fe([x]) = f (x) defines a bijection from S/∼f to f [S]: equivalent representatives have
  equal outputs, equal outputs give equal classes, and every range value is attained. With
  i : f [S] ,→ T ,
                                            f = i ◦ fe ◦ q.
  Thus every map is a surjection onto its classes, followed by a bijection onto its range, followed
  by an inclusion into the codomain. This pattern later explains quotient metrics and algebraic
  isomorphism theorems.



1.4    Countability, diagonalisation and comparing sizes

  Countability rules and how they are proved
  Countable means admitting an injection into N and includes finite sets. A nonempty set is
  countable iff it admits a surjection from N. A countably infinite set admits a bijection with
  N: inject it into N, then enumerate its infinite image in increasing order using well-ordering.
  Finite products of countable sets are countable. For example (n1 , . . . , nk ) 7→ pn1 1 · · · pnk k injects
  Nk into N by unique prime factorisation. The rationals are countable because (m, n) 7→ m/n
  maps countable Z × N onto Q.
  A countable union of countable sets is countable: after ignoring empty sets, enumerate each
  set, and use a two-index list to cover the union. Since N2 is countable, the combined list is
  countable. This does not apply to infinite products: {0, 1}N is uncountable.

  Exam question: Cantor’s theorem: model proof

1.5     Partial orders and Zorn’s lemma: optional self-study

  Order terminology and the maximal-element principle
  A partial order is reflexive, antisymmetric and transitive. Antisymmetry means x ≤ y and
  y ≤ x imply x = y; this differs from symmetry. A total order additionally makes every pair
  comparable. A strict order is asymmetric and transitive; a strict total order has trichotomy.
  A chain is a subset of mutually comparable elements. An upper bound dominates every
  element of a subset. A maximal element has no strictly larger element, but need not dominate
  all elements of the whole set. For example distinct singleton sets are both maximal in the
  collection of singleton subsets ordered by inclusion.
  Zorn’s lemma says that a partially ordered set in which every chain has an upper bound has
  a maximal element. It is equivalent to the axiom of choice. For linearly independent subsets
  of a vector space ordered by inclusion, the union of a chain is independent because any finite
  proposed dependence lies in one chain member. Zorn then gives a maximal independent
  set, which spans and hence is a basis. Partial functions ordered by extension give another
  important example: a chain has a union function because its members agree wherever their
  domains overlap. This explains the extension argument in Appendix II. The source labels
  this order-theory subsection non-examinable.

1.6.15   Exercise 1.15: Strict and non-strict total orders

  Exam question: Lecture exercise; optional order-theory material
  Show the conversions x < y ⇐⇒ x ≤ y and x ̸= y and x ≤ y ⇐⇒ x < y or x = y take
  total orders to strict total orders and back.



                                                  23
MATH6310 | Metric Spaces & Topology                                                          Sai Vanam


  Worked model answer
  Given a total order, comparable distinct points satisfy precisely one direction of strict
  inequality, because antisymmetry prevents both. Equal points satisfy neither, proving
  trichotomy. If x < y < z, transitivity gives x ≤ z; equality x = z would force x = y by
  antisymmetry, impossible. Thus x < z.
  Conversely, the converted non-strict relation is reflexive by its equality clause. If x ≤ y
  and y ≤ x with distinct points, then x < y and y < x, contradicting trichotomy, so it is
  antisymmetric. Transitivity follows from strict transitivity when both steps are strict, while
  an equality step leaves the other comparison unchanged. Trichotomy ensures comparability.
  Thus the relation is a total order.

Section 2         Real Analysis and Linear Algebra: revision

2.1   Real analysis tools

  Supremum, maximum, infimum and minimum
  An upper bound u satisfies a ≤ u for every a ∈ A. The supremum s = sup A is the least
  upper bound. It need not belong to A. A maximum is an element of A which is an upper
  bound. Similarly, an infimum is a greatest lower bound, while a minimum must lie in A.
  For A = (0, 1), sup A = 1, inf A = 0, and there is neither a maximum nor a minimum.
  For [0, 1), only the minimum is attained. The least upper bound principle says that every
  nonempty subset of R bounded above has a real supremum. For lower bounds use

                                      inf A = − sup(−A).

  Method: Prove a proposed value is a supremum
  First prove a ≤ s for every a ∈ A. Then prove that for every ε > 0 there is a ∈ A with
  s − ε < a. Otherwise s − ε would be a smaller upper bound. To approximate a supremum
  by a sequence, choose an ∈ A with s − 1/n < an ≤ s; if monotonicity is required replace an
  by max{a1 , . . . , an }.
  For an infimum t, choose an with t ≤ an < t + 1/n. The infimum need not be attained, so
  never simply write “choose a ∈ A attaining inf A” without justification.

  Archimedean property and order density
  N is unbounded above in R; equivalently, for every ε > 0 there exists n with 1/n < ε. Both
  rationals and irrationals occur between any two distinct reals.
                                                                   √              √
  A short proof of irrational density: choose rational q with a − 2 < q < b − 2. Then
      √
  q + 2 is irrational and lies in (a, b).
  To obtain a minimum in a nonempty integer set A bounded below by p ∈ Z, apply well-
  ordering to {a − p + 1 : a ∈ A} ⊆ N. Apply this to −A for maxima of integer sets bounded
  above.

  Exam question: Section 2 practice: Exercise 2.6

  q > 2π − ε. Consequently no smaller number is an upper bound, and sup A = 2π. Since 2π
  is irrational it does not lie in A; therefore A has no maximum.

  Sequence definitions and limit rules
  A real sequence is a function N → R. A subsequence has the form (xnk ) with strictly
  increasing indices n1 < n2 < · · · . The set of terms forgets order and repetitions.

                        xn → a ⇐⇒ ∀ε > 0 ∃N ∀n ≥ N : |xn − a| < ε.

                   (xn ) Cauchy ⇐⇒ ∀ε > 0 ∃N ∀n, m ≥ N : |xn − xm | < ε.
  Bounded means |xn | ≤ M for a single finite M and every n. A convergent sequence is
  Cauchy and bounded. In R, every Cauchy sequence converges. A bounded sequence need
  not converge: (−1)n is a counterexample.
  Limits respect finite linear combinations, products, modulus and reciprocals when the
  limiting denominator is nonzero. If xn ≤ yn and both converge, then lim xn ≤ lim yn . Strict
  inequalities may become equality at the limit. The sandwich principle says that an ≤ xn ≤ bn
  and an , bn → L imply xn → L.

  Monotonicity, subsequences and Bolzano–Weierstrass
  A bounded increasing sequence converges to the supremum of its terms. Indeed, choose N
  with xN > s − ε, where s = supn xn . For all n ≥ N , s − ε < xN ≤ xn ≤ s. The decreasing
  version uses the infimum.
  Every real sequence has a monotone subsequence: call n a peak if xn ≥ xm for all m >
  n. Infinitely many peaks produce a decreasing subsequence. If there are finitely many,
  each sufficiently late term has a larger later term, giving a recursively chosen increasing
  subsequence.
  Bolzano–Weierstrass: every bounded real sequence has a convergent subsequence. Apply
  the preceding fact and monotone convergence. If all terms are in a closed interval, the
  subsequential limit stays in that interval.

  Limsup and liminf: the eventual upper and lower levels
  For a bounded real sequence define

                                  un = sup xk ,         ln = inf xk .
                                        k≥n                  k≥n


  Then (un ) decreases, (ln ) increases, and

                           lim sup xn = lim un ,        lim inf xn = lim ln .

  These are respectively the largest and smallest subsequential limits. Each is a subsequential
  limit, obtained by choosing increasingly late terms close to the corresponding tail supremum
  or infimum. Since ln ≤ xn ≤ un , a bounded sequence converges iff liminf equals limsup.
  A Cauchy sequence is bounded. Also uN − lN ≤ ε once all distances between terms in the
  N th tail are below ε. Thus limsup equals liminf, proving completeness of R.

2.2    Linear algebra, continuity and integration

  Vector spaces and their maps
  A vector space over R or C allows addition and scalar multiplication: addition is associative
  and commutative with zero and additive inverses; scalar multiplication has identity 1, is
  associative with scalar multiplication, and distributes over vector and scalar addition.
  A linear subspace U ⊆ V satisfies 0 ∈ U and u + λv ∈ U for u, v ∈ U . A linear map satisfies
  T (u + λv) = T u + λT v. Its kernel and range are subspaces. A bijective linear map has a
  linear inverse. A linear functional is a linear map to the scalar field; on Rn it has the form
  x 7→ ai xi , with ai = T (ei ).

2.3    Detailed proof: The intermediate value theorem through an
       infimum

  Exam question: Additional practice based on Section 2
  Let f : [a, b] → R be continuous and f (a) < c < f (b). Prove f (t) = c for some t ∈ (a, b)
  using an infimum.

  Worked model answer
  Set A = {x ∈ [a, b] : f (x) ≥ c}. Since b ∈ A, this set is nonempty; it is bounded below by
  a. Let t = inf A. By infimum approximation choose xn ∈ A with t ≤ xn < t + 1/n. Thus
  xn → t, and since all xn ∈ [a, b], the weak inequalities pass to the limit to give t ∈ [a, b].
  Continuity gives f (xn ) → f (t). Since every f (xn ) ≥ c, we obtain f (t) ≥ c. In particular
  t ̸= a, because f (a) < c.
  Suppose f (t) > c. Continuity then gives δ > 0 with f (x) > c whenever x ∈ [a, b] and
  |x − t| < δ. Because t > a, choose h > 0 with h < min{δ, t − a}. Then x = t − h ∈ [a, b]
  and f (x) > c, so x ∈ A. But x < t = inf A, contradicting that t is a lower bound. Therefore
  f (t) = c. Since f (b) > c, also t ̸= b, so t ∈ (a, b).
  For the decreasing endpoint case apply this result to −f and −c. If c equals an endpoint
  value, that endpoint already supplies the required point.

  What each assumption does
  The ordered real target lets us define the set where values are above c. Completeness of the
  real order supplies its infimum. The interval domain allows moving a little to the left of t.
  Continuity prevents a jump over the target value. This is a different use of completeness from
  Cauchy completeness of a general metric space, although the properties of R are related.



2.4    Proof clinic: Discovering an epsilon–delta proof

  Method: Work backwards, then write forwards
  Suppose you need |f (x) − f (p)| < ε. First manipulate the expression until you can bound
  it by something involving |x − p|. If another factor depends on x, impose a rough local
  restriction such as |x − p| < 1 to bound that factor. Then choose the smaller of the rough
  restriction and the accuracy restriction.

  Exam question: Additional practice: continuity of x2 at an arbitrary point
  Prove f (x) = x2 is continuous on R directly, explaining how you find δ.

  Worked model answer
  Fix p ∈ R. The target difference factors as

                                    |x2 − p2 | = |x − p| |x + p|.

  The first factor is controlled by δ, but the second initially is not. Require |x − p| < 1. Then

                               |x + p| ≤ |x − p| + 2|p| < 1 + 2|p|.

  Now it will suffice to have |x − p| < ε/(1 + 2|p|). Combine both requirements by choosing

                                  δ = min{1, ε/(1 + 2|p|)} > 0.

  If |x − p| < δ, then both restrictions hold and

                                   |x2 − p2 | < δ(1 + 2|p|) ≤ ε.

  This proves continuity at arbitrary p. Dependence of δ on p is permitted for continuity.

  Why the same proof does not show uniform continuity on R
  Uniform continuity would require a single δ for all p. The chosen denominator grows with
  |p|, so the proof does not provide that. To show actual failure, take xn = n, yn = n + 1/n.
  Their separation is 1/n → 0 while
                                    yn2 − x2n = 2 + 1/n2 ≥ 2.
  For target tolerance 1, arbitrarily close inputs have image separation above 1, contradicting
  uniform continuity.

2.5.1   Exercise 2.1: Extrema of integer sets

  Exam question: Lecture exercise
  A nonempty subset of Z is bounded below. Show it has a minimum. Deduce the corresponding
  maximum result for upper-bounded integer sets.

  Worked model answer
  Suppose a ≥ p for every a ∈ A, with p ∈ Z. Define B = {a − p + 1 : a ∈ A}. This
  is a nonempty subset of N, since every transformed element is an integer at least 1. By
  well-ordering, B has a least element b0 . Since b0 ∈ B, there is a0 ∈ A with b0 = a0 − p + 1.
  For every a ∈ A, a − p + 1 ≥ b0 = a0 − p + 1, so a ≥ a0 . Therefore a0 = min A.
  If A is bounded above, −A = {−a : a ∈ A} is bounded below and nonempty. By the
  preceding result it has minimum b0 . Then −b0 ∈ A, and −a ≥ b0 for every a ∈ A, so
  a ≤ −b0 . Thus max A = − min(−A).

  Method: Move to a setting where a theorem applies
  An integer set may contain negative numbers, so well-ordering of N cannot be applied to it
  directly. Translating it into N is the missing bridge.

2.5.3   Exercise 2.3: Approximating a supremum

  Exam question: Lecture exercise
  For nonempty upper-bounded A ⊆ R and s = sup A, prove that every ε > 0 admits a ∈ A
  with s − ε < a ≤ s.

  Worked model answer
  The inequality a ≤ s holds for every a ∈ A because s is an upper bound. Suppose, for a
  fixed ε > 0, there were no a ∈ A with a > s − ε. Then every a ∈ A would satisfy a ≤ s − ε,
  so s − ε would be an upper bound smaller than s. This contradicts leastness of the upper
  bound s. Therefore the required a exists.
  Choosing such an an for ε = 1/n gives 0 ≤ s − an < 1/n, hence an → s. Membership of s in
  A is not required.

  When this construction appears again
  Use it to produce points nearly maximising a continuous function, pairs nearly realising a
  diameter, and points nearly realising an infimum. Compactness can then turn approximate
  attainment into actual attainment.


2.5.4   Exercise 2.4: Infima from suprema

  Exam question: Lecture exercise

2.5.9   Exercise 2.9: Continuity is equivalent to sequential continuity

  For f : A → R, A ⊆ R, and p ∈ A, prove continuity at p iff xn → p in A implies
  f (xn ) → f (p).

  Worked model answer
  First assume f continuous at p. Let xn → p and fix ε > 0. Continuity provides δ > 0
  such that x ∈ A and |x − p| < δ imply |f (x) − f (p)| < ε. Convergence provides N such
  that |xn − p| < δ for n ≥ N . Therefore |f (xn ) − f (p)| < ε for all n ≥ N , proving image
  convergence.
  For the reverse direction, use the contrapositive. If f is not continuous at p, then there is
  one ε0 > 0 such that for every δ > 0 there is x ∈ A with |x − p| < δ but |f (x) − f (p)| ≥ ε0 .
  Set δ = 1/n and choose such a point xn . Then |xn − p| < 1/n → 0, so xn → p, but the
  image distances are all at least ε0 , preventing f (xn ) → f (p). Thus sequential continuity
  would fail. The contrapositive proves the converse.

  Exam tips and common mistakes
  In the negation, ε0 is fixed before choosing xn . If the lower bound shrank with n, it would
  not necessarily prevent image convergence.

Section 3            Metric space fundamentals

3.1    Triangle estimates, distance functions and boundedness

  Two estimates to memorise
  The triangle inequality gives d(x, p) − d(y, p) ≤ d(x, y). Swap x, y to get

                                         |d(x, p) − d(y, p)| ≤ d(x, y).

  More generally, taking a route from a through c, d to b and then reversing the roles gives

                                     |d(a, b) − d(c, d)| ≤ d(a, c) + d(b, d).

  Consequently the metric itself is 1-Lipschitz on E × E with the sum metric. In particular, if
  xn → x and yn → y, then d(xn , yn ) → d(x, y).

  Distance to a nonempty set
  Define dist(x, A) = inf a∈A d(x, a). For every a ∈ A,

                                 dist(x, A) ≤ d(x, a) ≤ d(x, y) + d(y, a).

  Taking the infimum over a gives dist(x, A) ≤ d(x, y) + dist(y, A). Swapping x, y proves

                                     | dist(x, A) − dist(y, A)| ≤ d(x, y).

  Thus this function is 1-Lipschitz. Also dist(x, A) = 0 iff a sequence in A converges to
  x: choose an with d(x, an ) < 1/n, or use 0 ≤ dist(x, A) ≤ d(x, an ). Zero distance means
  membership of the closure, not necessarily of A.

  Diameter and boundedness
  diam A = sup{d(x, y) : x, y ∈ A}; take diam ∅ = 0. Bounded means finite diameter. For
  any fixed p ∈ E, boundedness is equivalent to containment in some closed ball BR [p]. If
  A ̸= ∅ choose a ∈ A and use d(p, x) ≤ d(p, a) + diam A. Conversely, containment in BR [p]
  gives d(x, y) ≤ 2R.
  For nonempty bounded sets A, B,

             max{diam A, diam B} ≤ diam(A ∪ B) ≤ diam A + dist(A, B) + diam B,

  where dist(A, B) = inf a∈A,b∈B d(a, b). For the upper bound choose a, b with d(a, b) <
  dist(A, B) + ε; route any cross pair through a, b and let ε ↓ 0.

  Exam question: 2025 Q1: the four-point estimate
  For a1 , a2 , b1 , b2 ∈ E, prove

                              |d(a1 , b1 ) − d(a2 , b2 )| ≤ d(a1 , a2 ) + d(b1 , b2 ).



                                                        37
MATH6310 | Metric Spaces & Topology                                                                 Sai Vanam


  Worked model answer
  Apply the triangle inequality twice:

                              d(a1 , b1 ) ≤ d(a1 , a2 ) + d(a2 , b2 ) + d(b2 , b1 ).

  Subtracting d(a2 , b2 ) gives an upper bound for d(a1 , b1 ) − d(a2 , b2 ). Interchanging indices 1
  and 2 gives the same upper bound for its negative. Therefore the absolute value is at most
  d(a1 , a2 ) + d(b1 , b2 ). Taking a1 = x, a2 = y, b1 = b2 = p yields the reverse triangle inequality
  for distance to p.

  Exam tips and common mistakes
  To bound a difference of distances, create a triangle route and then swap the two pairs. To
  handle an infimum or supremum, first obtain a bound valid for every point; only then take
  the infimum or supremum. Do not assume the closest point exists unless compactness or
  another attainment result is available.

  Isometries and Lipschitz maps
  An isometry satisfies dF (f (x), f (y)) = dE (x, y) for every pair. It is injective: equal images
  force zero original distance. It need not be surjective. A bijective isometry has an isometric
  inverse. “The spaces are isometric” means there is a bijective isometry.
  Lipschitz means dF (f (x), f (y)) ≤ LdE (x, y) with a finite L ≥ 0. The optimal constant is
  the supremum of the distance ratios over distinct pairs. A constant map has constant zero.
  A strict contraction has an admissible constant q < 1. A bi-Lipschitz map is a bijection for
  which both directions are Lipschitz.

3.3    Sequences in general metric spaces

  Definitions and the basic hierarchy
  Replace absolute value in the real definitions by the metric:

                        xn → a ⇐⇒ ∀ε > 0 ∃N ∀n ≥ N : d(xn , a) < ε,

                   (xn ) Cauchy ⇐⇒ ∀ε > 0 ∃N ∀n, m ≥ N : d(xn , xm ) < ε.
  Convergent ⇒ Cauchy ⇒ bounded in every metric space. The first converse holds only in
  complete spaces; the second generally fails even in R.


                                                 39
MATH6310 | Metric Spaces & Topology                                                       Sai Vanam



  If xn → a, choose N so d(xn , a) < ε/2 for n ≥ N ; then d(xn , xm ) < ε. If (xn ) is Cauchy,
  choose a tail with pairwise distances below 1 and use a ball around its first point to contain
  that tail and the finitely many earlier terms.

  Uniqueness and the convergent-subsequence lemma
  If xn → a and xn → b, then

                                 d(a, b) ≤ d(a, xn ) + d(xn , b) → 0,

  so a = b. Every subsequence of a convergent sequence has the same limit.
  If a Cauchy sequence has a subsequence xnk → a, then the whole sequence converges to
  a. Given ε > 0, choose N with tail distances below ε/2, and fix k such that nk ≥ N and
  d(xnk , a) < ε/2. Then for every n ≥ N ,

                               d(xn , a) ≤ d(xn , xnk ) + d(xnk , a) < ε.

  This lemma is the bridge from sequential compactness to completeness.

  Method: Negate a quantified definition correctly
  Not Cauchy means
                            ∃ε0 > 0 ∀N ∃n, m ≥ N : d(xn , xm ) ≥ ε0 .
  Not converging to a means ∃ε0 > 0 such that arbitrarily late terms satisfy d(xn , a) ≥ ε0 . Not
  complete means there exists a Cauchy sequence with no limit in the space. Not sequentially
  compact means there exists a sequence with no subsequence converging to a point of the set.

  Exam question: 2024 Q1(c): convergence in the discrete metric
  Prove that a sequence converges in a discrete metric space iff it is eventually constant.

  Worked model answer
  Suppose xn → p. Use ε = 1/2: for some N , d(xn , p) < 1/2 for every n ≥ N . The only
  possible distance below 1/2 is zero, hence xn = p for every n ≥ N . Conversely, if xn = p for
  all n ≥ N , then for any ε > 0, d(xn , p) = 0 < ε for those n, so xn → p.
  The same 1/2 argument for pairs proves that every discrete-metric Cauchy sequence is
  eventually constant. Thus every discrete metric space is complete.

  Exam question: Section 3 Exercise 3.12: convergence of distance values
  If (xn ) is Cauchy and p ∈ E, show d(xn , p) converges in R. If xn → a, identify its limit.

  Worked model answer
  The reverse triangle inequality gives |d(xn , p) − d(xm , p)| ≤ d(xn , xm ). Hence (d(xn , p)) is
  Cauchy in R, so converges by completeness of R. If xn → a, then |d(xn , p) − d(a, p)| ≤
  d(xn , a) → 0, so its limit is d(a, p). Without convergence of xn in E, there need not be a
  point a ∈ E representing that limit as a limit point of the original sequence.

  The limit is required to lie in the metric space. For example 1/n has no limit in (0, 1) even

  Exam question: Lecture exercise
  Prove d(x, y) = ∥y − x∥ is a metric on a normed vector space.

  Worked model answer

                             d(x, y) = 0 ⇐⇒ y − x = 0 ⇐⇒ x = y.

  Thus all metric axioms hold.

  Exam tips and common mistakes
  The vector identity is the bridge between the norm triangle inequality and the metric triangle
  inequality. Writing it makes the proof transparent.

3.5.2   Exercise 3.2: A metric from an injection

  Exam question: Lecture exercise
  Let ϕ : A → (E, dE ) be injective. Show dA (x, y) = dE (ϕ(x), ϕ(y)) is a metric.

  Worked model answer
  Finiteness, nonnegativity and symmetry follow immediately from those properties of dE .
  For definiteness,
                         dA (x, y) = 0 ⇐⇒ ϕ(x) = ϕ(y) ⇐⇒ x = y,
  where the second equivalence uses injectivity. For triangle inequality,

                             dA (x, z) = dE (ϕ(x), ϕ(z))
                                      ≤ dE (ϕ(x), ϕ(y)) + dE (ϕ(y), ϕ(z))

  Therefore dA is a metric. If injectivity were omitted, the formula could give zero between
  different points. For example a constant ϕ gives dA ≡ 0, which fails definiteness if A has
  more than one point.

3.5.6   Exercise 3.6: Inverse of a bijective isometry

  Exam question: Lecture exercise

  Therefore g is an isometry.

  Exam question: Lecture exercise
  Prove both implications in a general metric space.

3.5.14    Exercise 3.14: Finiteness of a sup distance

4.1    Open sets and interior

  Openness and interior

  U is open in E if ∀p ∈ U ∃r > 0 : BrE (p) ⊆ U . Its points have room around them within the
  specified metric space. Empty and whole sets are open. Every set in a discrete metric space
  is open, since B1/2 (p) = {p}.
  A point is in Int A iff it has a ball contained in A. The interior is the largest open subset of
  A:
                                           [
                                  Int A = {U : U ⊆ A, U open}.
  Thus Int A is open; A is open iff A = Int A; and Int(Int A) = Int A.

  Unions and intersections
  Arbitrary unions of open sets are open: a point in a union lies in one member, which supplies
  a ball. Finite intersections are open: use the minimum of finitely many positive radii. Infinite
  intersections need not be open:
                                      \
                                          (−1/n, 1/n) = {0}.
                                      n≥1


  Every open set is a union of open balls: choose rx > 0 with Brx (x) ⊆ U for each x ∈ U ,
              S
  then U = x∈U Brx (x).
  Every open U is also a union of closed balls. Choose Rx > 0 with BRx (x) ⊆ U and use
  BRx /2 [x] ⊆ U . A union of closed sets need not be closed, so there is no contradiction.

  Method: Prove open or disprove open
  For a positive proof, fix an arbitrary point inside and construct a positive radius, often a
  minimum of distances to excluded points or endpoints. For a negative proof, find one point
  in the set for which every positive-radius ball contains an excluded point. Merely observing
  that the set has a missing endpoint is insufficient in an arbitrary metric space.

4.2    Closed sets, closure and boundary

  Three descriptions of closure

  For A ⊆ E, a point p is in A iff every ball about p meets A, iff there is an ∈ A with an → p.
  For nonempty A, this is equivalent to dist(p, A) = 0. To produce the sequence, choose
  an ∈ B1/n (p) ∩ A.
  A set is closed iff A = A, equivalently it contains the limits of every sequence of its points
  which converges in E. Closure is the smallest closed superset:
                                \
                           A=      {F : A ⊆ F, F closed},        A = A.

  To prove closure is idempotent directly, approximate a point of A by a point of A within
  r/2, then that point by a point of A within r/2.

  Closed/open duality and boundary
  A is closed iff E \ A is open. Consequently arbitrary intersections of closed sets are closed;
  finite unions of closed sets are closed. Closed balls are closed because distance to their centre
  is continuous, or because a limit of distances ≤ r is still ≤ r.

                           E \ A = Int(E \ A),        E \ Int A = E \ A.

  The boundary is
                                  ∂A = A \ Int A = A ∩ E \ A.
  Every ball about a boundary point meets both A and its complement. Boundary is closed.
  The three disjoint regions Int A, ∂A, Int(E \ A) partition E.

  In R: for A = [0, 1), interior is (0, 1), closure is [0, 1], boundary is {0, 1}. For A = Q, interior
  is empty and both closure and boundary are R. For discrete spaces every set is both open
  and closed, and every boundary is empty.

4.4    Continuity in metric spaces

  The three equivalent tests
  For f : E → F , continuity at p is

                  ∀ε > 0 ∃δ > 0 ∀x ∈ E : dE (x, p) < δ ⇒ dF (f (x), f (p)) < ε.

  It is equivalent to sequential continuity: xn → p ⇒ f (xn ) → f (p). Globally, it is equivalent
  to preimages of all open sets being open, and to preimages of all closed sets being closed.
  Lipschitz functions are continuous: for L > 0 take δ = ε/L; for L = 0 the map is constant
  and any positive δ works. Compositions of continuous maps are continuous: if xn → x, then
  f (xn ) → f (x) and g(f (xn )) → g(f (x)).




                                                53
MATH6310 | Metric Spaces & Topology                                                     Sai Vanam


  Method: Choose the shortest continuity proof
  Use a Lipschitz bound if an algebraic estimate is available. Use sequences when limits are
  easy or you want to disprove continuity. Use open preimages when the question concerns
  topology. To disprove continuity at p, produce xn → p whose images fail to tend to f (p).
  To prove sequential continuity implies continuity, negate continuity. This provides a fixed
  ε0 > 0 and points xn with d(xn , p) < 1/n but d(f (xn ), f (p)) ≥ ε0 , contradicting sequential
  continuity.

  Exam question: 2023 Q2(c)(ii) and 2025 Q3(f): the open-preimage theorem

  Prove that f is continuous iff f −1 [V ] is open for every open V ⊆ F .

  Worked model answer
  Suppose f is continuous and take p ∈ f −1 [V ]. Since f (p) ∈ V and V is open, choose ε > 0
  with BεF (f (p)) ⊆ V . Continuity gives δ > 0 such that f [BδE (p)] ⊆ BεF (f (p)). Therefore
  BδE (p) ⊆ f −1 [V ], proving openness.
  Conversely suppose all open preimages are open. Fix p ∈ E and ε > 0. The set W =
  f −1 [BεF (f (p))] is open and contains p. Hence some δ > 0 satisfies BδE (p) ⊆ W . Thus
  dE (x, p) < δ implies dF (f (x), f (p)) < ε. So f is continuous at every p.

  Exam question: 2023 Q2(c)(iii): images do not behave like preimages
  Give a continuous map and an open set whose image is not open.

  Worked model answer
  Let f : R → R be the constant map f (x) = 0, and let U = (−1, 1). The function is
  continuous, indeed 0-Lipschitz. But f [U ] = {0} is not open in R, since no positive-radius
  ball about 0 lies in that singleton. Thus continuity controls inverse images of open sets, not
  arbitrary direct images.

  Identity theorem for continuous functions
  If f, g : E → F are continuous, the set H = {x : f (x) = g(x)} is closed: for xn ∈ H with
  xn → x, continuity gives f (x) = lim f (xn ) = lim g(xn ) = g(x). If H contains a dense subset,
  E = H = H, so f = g. This proves uniqueness of continuous extensions from dense domains.

4.6    Homeomorphisms and equivalence of metrics

  Homeomorphisms preserve topology
  A homeomorphism is a continuous bijection whose inverse is continuous. A continuous
  bijection alone is insufficient: the identity (R, ddiscrete ) → (R, | · |) is continuous and bijective
  but its inverse is not continuous.
  For a continuous bijection, being a homeomorphism is equivalent to sending every open set to
  an open set, or every closed set to a closed set. Bi-Lipschitz bijections are homeomorphisms.
  Homeomorphisms preserve sequential compactness, but need not preserve metric boundedness
  or completeness.

  Three notions of equivalent metrics on the same set
  Topological equivalence: the identity is a homeomorphism. Equivalently, the metrics
  have the same open sets, the same closed sets, or the same convergent sequences with the
  same limits.
  Cauchy equivalence: the metrics have exactly the same Cauchy sequences. This notion
  appears explicitly in the 2024 paper. It implies topological equivalence: if xn → p for one
  metric, interleave x1 , p, x2 , p, . . .; it is Cauchy for both metrics, forcing convergence to p for
  the second. Thus Cauchy equivalence also preserves completeness.
  Lipschitz equivalence: there exist c, C > 0 with

                          c d(x, y) ≤ d′ (x, y) ≤ C d(x, y) for every pair.

  It preserves bounded sets and Cauchy sequences, hence completeness and topology. These
  equivalence relations are reflexive, symmetric and transitive: use identity, inverse and
  composition of the relevant identity maps; for Lipschitz bounds multiply constants.

  Method: Prove or disprove equivalence
  Try two-sided linear bounds for Lipschitz equivalence. For topological equivalence, compare
  small balls at each point or compare convergent sequences. To disprove it, find a sequence
  converging to a point in one metric but not the other. To disprove Cauchy equivalence, find
  a sequence Cauchy for one but not the other. To disprove Lipschitz equivalence, show a
  ratio of distances tends to zero or infinity.

                   α(d(x, z)) ≤ α(d(x, y) + d(y, z)) ≤ α(d(x, y)) + α(d(y, z)).

4.7    Detailed proof: Why closure of a norm ball is its closed ball

  Exam question: Additional practice based on Sections 3 and 4

  In a normed vector space, prove Br (a) = Br [a] for r > 0. Explain why the argument is not

  First Br [a] is closed and contains Br (a). By the smallest-closed-superset description of
  closure, Br (a) ⊆ Br [a].
  For the reverse inclusion, take x ∈ Br [a]. If ∥x − a∥ < r, it is already in the open ball and
  hence in its closure. If ∥x − a∥ = r, define

                            xn = a + (1 − 1/n)(x − a)       (n ≥ 2).

  By norm homogeneity,

                     ∥xn − a∥ = (1 − 1/n)r < r,       ∥xn − x∥ = r/n → 0.

  Thus xn ∈ Br (a) and xn → x, so the sequential description of closure puts x ∈ Br (a). This
  proves the other inclusion and hence equality.
  The construction uses vector addition and scalar multiplication to move along a line segment
  toward a. A general metric space need not have such points. In a discrete space with at
  least two points, B1 (a) = {a} is already closed, but B1 [a] = E. Therefore equality can fail
  without the normed vector-space structure.

  Exam tips and common mistakes
  A geometric intuition such as “approach radially from inside” becomes a proof only after
  you specify the sequence and compute both its membership and its limit. Those are the two
  separate checks in the displayed formulas.



4.8    Proof clinic: Open-set arguments: choose the available margin

  Exam question: Additional practice: a strict distance inequality defines an open
  set
  For fixed a, b ∈ E, prove U = {x : d(x, a) < d(x, b)} is open without citing a preimage
  theorem.

  Worked model answer
  Fix p ∈ U . Its positive margin is h = d(p, b) − d(p, a) > 0. Moving from p to x can increase
  distance to a by at most d(x, p) and decrease distance to b by at most d(x, p). Thus budget
  less than half the margin in total by taking r = h/3.




                                               58
MATH6310 | Metric Spaces & Topology                                                     Sai Vanam



  If d(x, p) < r, triangle and reverse triangle inequalities give

                             d(x, a) ≤ d(p, a) + d(x, p) < d(p, a) + r,
                             d(x, b) ≥ d(p, b) − d(x, p) > d(p, b) − r.

  Since 2r = 2h/3 < h, d(p, a) + r < d(p, b) − r. Therefore d(x, a) < d(x, b), so x ∈ U . We
  have Br (p) ⊆ U , proving openness.

  Method: The continuity shortcut after you understand the estimate
  The function h(x) = d(x, a)−d(x, b) is continuous, since both distance functions are Lipschitz.
  Thus U = h−1 [(−∞, 0)] is open. This is shorter, but the direct proof explains how the
  positive margin produces a radius.



4.9    Proof clinic: Closed-set arguments: retain weak inequalities at
       limits

  Exam question: Additional practice: an equidistance locus is closed
  Show F = {x ∈ E : d(x, a) = d(x, b)} is closed.

  Worked model answer
  Take a sequence xn ∈ F with xn → x in E. By continuity of distance values, d(xn , a) →
  d(x, a) and d(xn , b) → d(x, b). Each pair of values is equal, so their limits are equal:
  d(x, a) = d(x, b). Hence x ∈ F . The sequential characterisation proves F closed.
  An alternative is F = h−1 [{0}] for the continuous function h from the previous lesson. Since
  {0} is closed in R, its preimage is closed.

  Why closed inequalities survive and strict ones may not
  If tn ≤ c and tn → t, then t ≤ c. But tn < c does not force t < c: c − 1/n → c. Thus sets
  defined by continuous weak inequalities are naturally closed, while strict inequalities are
  naturally open. In an arbitrary metric setting, use continuity to make this reasoning precise
  rather than relying on the appearance of the inequality alone.



4.10    Proof clinic: Finding closure, interior and boundary in stages

  Exam question: Additional practice: an interval with an isolated point
  In usual R, let A = (0, 1) ∪ {2}. Find its interior, closure and boundary, with justification.




                                                 59
MATH6310 | Metric Spaces & Topology                                                    Sai Vanam


  Worked model answer
 Every point of (0, 1) has a small interval around it contained in (0, 1), hence in A. The point
 2 is not interior because every ball around it contains points different from 2 and outside
 (0, 1). Thus Int A = (0, 1).
 Every point of A lies in its closure. The endpoint 0 is approached by 1/n for n ≥ 2, and 1 by
 1 − 1/n for n ≥ 2, so both belong to the closure. The set [0, 1] ∪ {2} is closed and contains
 A, so the closure cannot be larger than it. Therefore A = [0, 1] ∪ {2}.
 Subtracting the interior gives ∂A = {0, 1, 2}. In particular a boundary point may itself
 belong to the set (2), or fail to belong (0, 1).

  Exam tips and common mistakes
  Identify closure and interior separately, then use the boundary formula. Boundary is not
  merely “endpoints of an interval”; isolated points and dense subsets require the general
  definition.

4.13     Proof clinic: A proof-writing checklist applied to a theorem

  Exam question: Additional practice: a closed ball is closed
  Prove Br [a] is closed, stating exactly how convergence is used.

  Worked model answer
  Let (xn ) be a sequence in Br [a] converging in E to a point x. Membership gives d(xn , a) ≤ r
  for every n. Reverse triangle inequality gives |d(xn , a) − d(x, a)| ≤ d(xn , x) → 0, so
  d(xn , a) → d(x, a). Taking the limit in the weak inequality yields d(x, a) ≤ r. Therefore
  x ∈ Br [a]. Since every convergent sequence from the ball has its ambient limit in the ball,
  the ball is closed.

  What this answer does well
  It begins with an arbitrary sequence of the required type; distinguishes membership from
  convergence; names the estimate giving convergence of scalar distances; keeps the non-strict
  inequality when passing to a limit; concludes membership; and invokes the correct closed-set
  characterisation. You can use the same structure whenever a set is defined by a continuous
  weak inequality.

4.14.6   Exercise 4.6: Equivalence relations on metrics

  Exam question: Lecture exercise
  Prove topological equivalence and Lipschitz equivalence are equivalence relations on the
  metrics on a fixed set S.

  Worked model answer
  For topological equivalence, reflexivity holds because a metric has the same open sets as itself.
  Symmetry holds because “d and d′ have the same open sets” is symmetric. For transitivity,
  if d, d′ have the same open sets and d′ , d′′ have the same open sets, then d, d′′ have the same
  open sets. Thus it is an equivalence relation.
  For Lipschitz equivalence, d is equivalent to itself using both comparison constants equal to
  1. If c d ≤ d′ ≤ C d with c, C > 0, then

                                        C −1 d′ ≤ d ≤ c−1 d′ ,

  so symmetry holds. If also a d′ ≤ d′′ ≤ b d′ with a, b > 0, combine to get

                                         ac d ≤ d′′ ≤ bC d.

  These positive constants prove transitivity. Hence Lipschitz equivalence is also an equivalence
  relation.

Section 5         Complete metric spaces

5.1    Completeness and closed subspaces

  Completeness is a property of the metric
  A metric space is complete if every Cauchy sequence has a limit in the space. A subset is
  complete when equipped with the inherited metric.
  R, C, finite-dimensional ℓp spaces, and every discrete space are complete. (0, 1) and [0, 1)
  with the usual metric are incomplete: a sequence can approach an excluded endpoint. Q is
                                          √
  incomplete: rational approximations to 2 are Cauchy but have no rational limit.
  Completeness is preserved under bi-Lipschitz maps and Cauchy-equivalent metrics. It is
  not preserved by arbitrary homeomorphisms: (R, dN S ) is homeomorphic to usual R but
  incomplete because n is Cauchy and cannot converge to a finite real in dN S .

  Method: The closed-subset shortcut
  A complete subset of any metric space is closed. A closed subset of a complete metric space
  is complete. Thus, when the ambient space is complete, subset completeness is equivalent to
  closedness. In particular a subset of usual Rn is complete iff it is closed, without needing
  boundedness.
  To prove incompleteness construct a Cauchy sequence with a missing limit. It is usually
  easiest to find its limit in a larger known complete space and use uniqueness to exclude any
  alternative limit in your space.

  Exam question: 2025 Q4(a): complete iff closed in a complete ambient space
  Let E be complete and A ⊆ E. Prove that A is complete iff it is closed in E.

  Worked model answer
  Suppose A is complete. Let an ∈ A with an → p in E. Then (an ) is Cauchy in E and hence
  in the subspace A. By completeness of A, an → a for some a ∈ A. This is also convergence
  in E, so uniqueness gives p = a ∈ A. Hence A is closed.
  Conversely, suppose A is closed and let (an ) be Cauchy in A. It is Cauchy in E, so by
  completeness of E there is p ∈ E with an → p. Since A is closed, p ∈ A. Thus the sequence
  converges in A, proving completeness.

  Exam question: 2022 Q3(b): uniform continuity and completeness
  Let f : E → E ′ be a homeomorphism, with f uniformly continuous and E ′ complete. Prove
  that E is complete.

  Worked model answer
 Let (xn ) be Cauchy in E. Uniform continuity sends Cauchy sequences to Cauchy sequences:
 for any target tolerance choose one δ valid for all pairs, then apply Cauchyness in E. Thus
 (f (xn )) is Cauchy in E ′ , and completeness gives f (xn ) → y ∈ E ′ . Since f −1 is continuous,


                                                69
MATH6310 | Metric Spaces & Topology                                                        Sai Vanam



  xn = f −1 (f (xn )) → f −1 (y) ∈ E. Therefore E is complete.
  Notice the direction: uniform continuity is needed for f to send the original Cauchy sequence
  forward, and continuity of f −1 brings its limit back.



5.2     Completeness of function spaces and uniform limits

  Why the sup metric is uniform convergence
  dsup (fn , f ) → 0 iff

                           ∀ε > 0 ∃N ∀n ≥ N ∀s ∈ S : dE (fn (s), f (s)) < ε.

  The index N works for every input. Pointwise convergence allows N to depend on the input
  and is weaker. For instance fn (t) = tn on [0, 1] converges pointwise to a function which is 0
  below 1 and 1 at 1, but this limit is discontinuous, so the convergence cannot be uniform.

  Method: Prove ℓ∞ (S; E) complete
  Assume E complete. Start with an arbitrary sup-Cauchy sequence (fn ). For each s,
  dE (fn (s), fm (s)) ≤ dsup (fn , fm ), so define f (s) = limn fn (s) using completeness of E. Next
  pass m → ∞ in a uniform Cauchy bound; this gives uniform convergence. Finally prove f
  bounded by comparing it to a fixed bounded fN . Both membership and convergence must
  be checked.

  Exam question: 2023 Q3(b), 2024 Q3(d): completeness of the sup space
  Let E be complete. Prove ℓ∞ (S; E) is complete.

  Worked model answer
  Let (fn ) be Cauchy in the sup metric. For every s ∈ S, (fn (s)) is Cauchy in E, so define
  f (s) = limn fn (s). Given ε > 0, choose N such that dsup (fn , fm ) < ε/2 for n, m ≥ N . For
  any s and n ≥ N , let m → ∞ to obtain

  For membership, use the preceding estimate with tolerance 2 to choose a fixed N0 for which

  Thus f is bounded. It lies in ℓ∞ (S; E) and fn → f there, proving completeness. For

  Let fn : E → F be continuous and fn → f uniformly. Fix p and ε > 0. Choose one N

  Exam question: 2025 Q4(b): completeness of continuous-function space

  Embedding any metric space into a complete normed space
  For nonempty E fix ω ∈ E and define

                             jω (x)(p) = d(x, p) − d(ω, p),      p ∈ E.

  The reverse triangle inequality gives |jω (x)(p)| ≤ d(x, ω), so each function is bounded. Also

                       |jω (x)(p) − jω (y)(p)| = |d(x, p) − d(y, p)| ≤ d(x, y).

  At p = y equality holds. Hence ∥jω (x) − jω (y)∥∞ = d(x, y). This is an isometric embedding
  into the complete real normed space ℓ∞ (E; R).

  essential for unbounded E. The supplied notes say the embedding proof is not expected
  from memory, but the guided construction is useful practice.

  Extending Lipschitz maps from a dense set
  Let A be dense in E, F complete, and f0 : A → F be L-Lipschitz. Define f (x) = limn f0 (an )
  for any an ∈ A tending to x.
  Existence: (an ) is Cauchy, so (f0 (an )) is Cauchy and has a limit in F . Independence: if
  bn → x, then
                       dF (f0 (an ), f0 (bn )) ≤ L[dE (an , x) + dE (x, bn )] → 0.
  Thus the definition is independent of the approximating sequence. Constant sequences
  show extension. For an → x, bn → y, passing to limits in the Lipschitz inequality proves
  dF (f (x), f (y)) ≤ LdE (x, y). The optimal constant is unchanged because restricting to A
  gives the reverse bound.

  uniqueness. If f0 is isometric the equality also passes to limits. Uniformly continuous maps
  extend similarly: use preservation of Cauchy sequences and choose a uniform δ, with ε/2
  margins, before taking limits.

  Completion: definition and examples

  A completion is a complete space Eb with an isometry ι : E → Eb whose image is dense. The
  density condition rules out adding unrelated extra points. Examples: the completion of
  usual Q is R; of (0, 1) is [0, 1]; of (R, dN S ) is [−π/2, π/2] with embedding arctan.
  Every metric space has a completion: embed into a complete normed space and take the
  closure of the image. Two completions are uniquely related by an isometry respecting their
  embeddings. To see surjectivity, the extended isometry has a complete, hence closed, image
  containing the dense embedded copy of E, so its image is all of the target completion.
  Uniqueness follows by equality on that dense copy.
  Status: the existence/uniqueness proof is marked non-examinable in the supplied notes.
  The optional L1 completion of (C(I), d1 ) uses integrable functions modulo equality almost
  everywhere; ordinary pointwise functions must be quotiented because integral distance can
  be zero between distinct functions.

5.6    Cantor intersection and Baire category

  Cantor’s intersection theorem
  Let E be complete and F1 ⊇ F2 ⊇ · · · be nonempty closed subsets with diam Fn → 0. Then
  T
    n Fn is a singleton.
  Choose xn ∈ Fn . For m ≥ n, both xm , xn ∈ Fn , so d(xm , xn ) ≤ diam Fn . Thus (xn ) is
  Cauchy and has a limit p ∈ E. For every fixed n, the tail lies in the closed set Fn , so p ∈ Fn .
  Therefore p is in the intersection. If p, q are in it, then d(p, q) ≤ diam Fn for all n, so p = q.

  Exam question: Section 5 Exercise 5.6: why the assumptions matter
  Give counterexamples if (a) shrinking diameters or (b) closedness is omitted. Also explain
  the role of completeness.

  Worked model answer
 (a) In complete R, the sets Fn = [n, ∞) are nonempty, closed and decreasing, but their
 intersection is empty. Their diameters do not tend to zero. Even Fn = [0, 1] shows that
 without shrinking diameters the intersection need not be a singleton.
 (b) In complete R, let Fn = (0, 1/n). They are nonempty and decreasing with diameter
 1/n → 0, but are not closed and their intersection is empty.
 For completeness, take E = (0, 1) with its usual metric and Fn = (0, 1/(n + 1)]. Each
 is closed relative to E, nonempty, decreasing and has diameter 1/(n + 1) → 0, but the



                                                      76
MATH6310 | Metric Spaces & Topology                                                       Sai Vanam



  intersection is empty. The missing limit is zero, outside E.

  Baire category: included for completeness, marked non-examinable

  A subset A is nowhere dense if Int(A) = ∅. It is meagre if it is a countable union of nowhere
  dense subsets. Empty interior alone does not imply nowhere density: Q has empty interior
  but closure R.
  Baire’s theorem says that a countable intersection of open dense subsets of a complete metric
  space is dense. Equivalently, a countable union of closed nowhere dense sets has dense
  complement. A nonempty complete metric space is not meagre in itself.
  Proof idea: inside any starting open ball, recursively choose nested closed balls of positive
  radii tending to zero, each contained in the previous open ball and the next dense open set.
  Cantor’s intersection theorem gives a point in all of them. Thus every initial ball meets the
  full intersection.
  In R, each singleton is closed nowhere dense, so Q is meagre. In R2 , each line is closed
  nowhere dense; hence countably many lines cannot cover the plane. The supplied notes also
  mention the meagreness, in the sup space C([0, 1]), of functions differentiable somewhere; its
  deeper proof is beyond this guide’s core examination methods.

  Exam question: Additional conceptual practice: meagre does not mean nowhere
  dense
  Show Q is meagre in R but not nowhere dense in R.

  Worked model answer
  Enumerate Q = {q1 , q2 , . . .}. Every singleton {qn } is closed with empty interior in R, hence
  nowhere dense. Therefore their countable union Q is meagre. But Q = R, so Int(Q) = R ̸= ∅.
  Thus Q is not nowhere dense.

  1 for t < 1. Thus pointwise convergence is not uniform.

5.8                Proof clinic: Why completeness of the function space is not
                   pointwise completeness alone

  The three obligations in the proof
  A Cauchy sequence (fn ) in a function space is a sequence of whole functions. To prove it
  converges in that space you need three separate facts:
  1. A candidate function f is defined at every input, usually using completeness of the target
     at each input.
  2. The candidate belongs to the original space: if boundedness or continuity is part of
     membership, verify it.
  3. The distance between fn and f tends to zero in the specified metric, not merely at each
     input.



                                                              78
MATH6310 | Metric Spaces & Topology                                                    Sai Vanam



  In the sup metric, the uniform Cauchy hypothesis gives one cutoff valid for every input,
  which is strong enough for the third obligation. The ε/3 continuity proof handles the second
  obligation for continuous functions. A pointwise limit alone need not satisfy either.

  Exam question: Additional practice: diagnose an incomplete argument
  A student writes: “For each t, fn (t) converges to f (t). Therefore C([0, 1]) is complete.”
  Explain what must be added.

  Worked model answer
  One must begin with an arbitrary sequence Cauchy in the sup metric. The scalar limits
  define f , but it is still necessary to prove f continuous and ∥fn − f ∥∞ → 0. Pass to the
  limit in the uniform Cauchy bound to obtain uniform convergence. Compare the limit with
  one bounded term to prove boundedness. Then use uniform convergence and continuity of
  the approximating functions to show f continuous. Without these steps, the limit might be
  discontinuous or the convergence might only be pointwise.



5.9    Proof clinic: Constructing a useful fixed-point domain

  Exam question: Additional practice: the domain makes the theorem usable
  Show x = (x2 + 1)/3 has exactly one solution in [0, 1], but explain why applying the same
  contraction estimate on all of R fails.

  Worked model answer
  Let T (x) = (x2 + 1)/3. On [0, 1], 1/3 ≤ T (x) ≤ 2/3, so T is a self-map. The interval is
  nonempty and complete. For x, y ∈ [0, 1],

                          |T (x) − T (y)| = 13 |x − y||x + y| ≤ 32 |x − y|.

  The constant 2/3 < 1 gives a unique fixed point in that interval by Banach. Solving the
                                                                   √
  quadratic gives x2 − 3x + 1 = 0, so the interval solution is (3 − 5)/2; the other root exceeds
  1.
  On all of R, the ratio |T (x) − T (y)|/|x − y| = |x + y|/3 for distinct points is unbounded,
  so this map is not globally Lipschitz, much less a strict contraction. The theorem on [0, 1]
  proves uniqueness in that chosen domain, not uniqueness among all real solutions.

  Exam tips and common mistakes
  Always phrase the conclusion with its domain. A contraction can have only one fixed point
  in the space to which the theorem is applied; it says nothing about solutions outside that

5.10.6   Exercise 5.6: Necessary hypotheses in Cantor intersection

  Exam question: Lecture exercise
  Find counterexamples when shrinking diameters or closedness is removed from Cantor’s
  intersection theorem.

  Worked model answer
  Without shrinking diameters: in complete R, set Fn = [n, ∞). Each set is nonempty and
  closed; Fn+1 ⊆ Fn . No real number lies in all of them, so the intersection is empty. Their
  diameters are infinite rather than tending to zero. For failure of uniqueness alone, the
  constant sequence Fn = [0, 1] has non-singleton intersection.
  Without closedness: again in complete R, take Fn = (0, 1/n). These sets are nonempty and
  nested with diam Fn = 1/n → 0. Their intersection is empty because any positive point is
  eventually excluded and zero never belongs. They are not closed.
  For comparison, if completeness is omitted, take the subspace E = (0, 1) and Fn = (0, 1/(n +
  1)]. These are closed relative to E, nested and shrinking, but have empty intersection. The
  natural limit zero is missing from E.

  Exam tips and common mistakes
  When a hypothesis is removed, your counterexample must still satisfy all the others. The
  second example uses a complete ambient space so it isolates closedness as the failing
  hypothesis.

Section 6          Sequential compactness

6.1    Sequential compactness

  Definition and first consequences
  K ⊆ E is sequentially compact if every sequence in K has a subsequence converging to
  a point of K. The subsequence may depend on the starting sequence. The limit-in-K
  condition is essential.
  Sequential compactness is intrinsic: inherited distances are the same, and the required limits
  belong to K, so passing to a larger ambient space does not change it. It implies closedness,
  boundedness and completeness.
  For closedness: if xn ∈ K converges to x in E, a compactness subsequence converges to p ∈ K,
  and uniqueness gives x = p. For boundedness: if unbounded, choose points with distances
  from a fixed point increasing to infinity; no subsequence can converge. For completeness: a
  Cauchy sequence has a convergent subsequence, and the Cauchy-subsequence lemma makes
  the whole sequence converge.

  Closed subsets, unions and intersections
  A closed subset F of a sequentially compact K is sequentially compact: take a subsequence
  converging in K; closedness puts the limit in F . Conversely every sequentially compact subset
  is closed. Hence within a sequentially compact ambient space, “closed” and “sequentially
  compact” are equivalent for subsets.
  Finite sets are sequentially compact by the infinite pigeonhole principle. Finite unions
  of sequentially compact sets are sequentially compact: infinitely many terms lie in one
  constituent. Intersections of two sequentially compact sets are sequentially compact because
  one is closed and the intersection is a closed subset of the other. For an arbitrary nonempty
  family of such sets, the same closed-subset argument works using one member to bound the
  intersection.

  Exam question: 2022 Q4(a): compact subsets of a compact space
  Let K be sequentially compact and A ⊆ K. Prove A is sequentially compact iff A is closed
  in K.

  Worked model answer
  Suppose A is sequentially compact. If an ∈ A and an → x in K, there is a subsequence
  anj → a ∈ A. Since the original sequence tends to x, that subsequence also tends to x.
  Uniqueness gives x = a ∈ A, proving A closed in K.
  Conversely suppose A closed in K. Any sequence in A is also a sequence in K, so has a
  subsequence converging to some x ∈ K. Since every term of the subsequence lies in A and
  A is closed in K, x ∈ A. Thus A is sequentially compact.

6.2    Continuous images, extrema and inverse continuity

  The image theorem and how to prove it
  If f : E → F is continuous and K ⊆ E sequentially compact, then f [K] is sequentially
  compact. Given yn ∈ f [K], choose xn ∈ K with f (xn ) = yn . Extract xnj → p ∈ K.
  Continuity gives ynj = f (xnj ) → f (p) ∈ f [K].
  Therefore continuous images of sequentially compact sets are closed and bounded in any
  metric codomain. A continuous real-valued function on nonempty sequentially compact K
  attains its bounds: choose xn whose values approach the supremum, extract a convergent
  subsequence, then use continuity. Use −f for the minimum.

  Diameter and distance are attained on compact sets
  For nonempty sequentially compact K, the product K × K is sequentially compact and d is
  continuous. Thus diam K is attained at some pair a, b ∈ K. For fixed p ∈ E, x 7→ d(x, p) is
  continuous, so its infimum on K is attained: there is c ∈ K with d(c, p) = dist(p, K).
  One can instead choose approximate minimisers cn with d(cn , p) < dist(p, K) + 1/n, extract
  cnj → c ∈ K, and pass to the limit.

  A continuous bijection from compact is a homeomorphism
  Let f : K → F be a continuous bijection with K sequentially compact. For every closed
  A ⊆ K, A is sequentially compact, so f [A] is sequentially compact and hence closed in F .
  Therefore f is a closed map. If g = f −1 , then g −1 [A] = f [A] is closed for every closed A in
  K, proving g continuous. This is a powerful shortcut to inverse continuity.

  Exam question: 2022 Q4(c): isometry from a compact space into itself

6.3    Product compactness and Heine–Borel

  The diagonal-subsequence construction

  For a sequence x(n) in a countable product of sequentially compact factors, first take a
  subsequence whose first coordinate converges. From that take a subsequence whose second
  coordinate converges. Continue, obtaining nested rows of subsequences. Select the jth term
  of row j.
  For each fixed coordinate i, the diagonal tail after i is a subsequence of row i, so that
  coordinate converges. The product metric’s coordinatewise-convergence theorem then gives
  convergence of the diagonal subsequence to the tuple of coordinate limits, which belongs to
  the product. This proves sequential compactness for the weighted countable product metrics
  in the notes. Finite products need finitely many successive extractions.


                                                  88
MATH6310 | Metric Spaces & Topology                                                      Sai Vanam


  Heine–Borel in finite-dimensional norm metrics
  For A ⊆ Rn and any ℓp metric,

                     A sequentially compact ⇐⇒ A closed and bounded.

  For the difficult direction, boundedness puts A inside a box [−L, L]n . Bolzano–Weierstrass
  and finite product compactness show the box sequentially compact. Since A is closed, it is a
  compact subset of the box. Norm equivalence makes the statement independent of p.
  In particular closed balls and spheres in Rn are sequentially compact. The theorem does not
  extend to arbitrary metric or infinite-dimensional normed spaces by simply retaining “closed
  and bounded”.

  Method: Classify a subset of Rn
  For boundedness, estimate each coordinate, or bound the norm. For closedness, use con-
  tinuity of defining functions and closed preimages: e.g. A = {x : g(x) ≤ c} is closed for
  continuous g. Strict inequalities often describe open sets, but intersect with other constraints
  carefully. If both closed and bounded, conclude sequential compactness by Heine–Borel. For
  nonclosedness exhibit a sequence leaving through a missing boundary point.

6.4    Total boundedness: the 2025 synthesis question

  Definition and distinction from boundedness
  A is totally bounded if for each r > 0 it can be covered by finitely many open balls of radius
  r. The centres may lie in the ambient space, as in the 2025 paper. Boundedness gives one
  large ball; total boundedness requires a finite cover at every scale.
  Total boundedness implies boundedness. Fix a finite radius-1 cover with centres p1 , . . . , pk .
  For x, y ∈ A choose covering centres pi , pj . Then

                                 d(x, y) < 2 + max d(pi , pj ) < ∞.
                                                i,j


  An infinite discrete space is bounded but not totally bounded, since radius-1/2 balls are
  singletons.

  Method: Turn finite covers into a Cauchy subsequence
  Given a sequence and a finite cover, one ball contains infinitely many terms, so select those
  indices. Repeat inside that subsequence with smaller radii 1/2, 1/3, . . .. Extract the diagonal.
  For each fixed stage its diagonal tail lies in a common radius-1/j ball, so pairwise distances
  are below 2/j. Therefore the diagonal is Cauchy. If A is complete, it converges to a point of
  A.

6.6    Further exercise methods from the supplied notes

  A convergent sequence together with its limit is closed (Exercise 6.5)
  Let C = {a} ∪ {xn : n ∈ N} with xn → a. For p ∈     / C, let r = d(p, a)/3 > 0. A tail lies in
  Br (a), so is at distance at least 2r from p. The finitely many earlier terms have a positive
  minimum distance from p. Choose a radius below both r and this finite minimum; its ball
  about p avoids C. Thus E \ C is open and C is closed. It is also sequentially compact: either
  one value occurs infinitely often, or a subsequence of the chosen sequence runs to arbitrarily
  late indices and hence tends to a.

  Cauchy tails and separated consecutive subsequence terms
  For Xn = {xk : k ≥ n}, Cauchyness is equivalent to diam Xn → 0 (Exercise 6.8): each
  direction follows by translating “all pairwise tail distances are small” into the definition of
  diameter.
  For Exercise 5.7, Cauchyness is equivalent to ∀ε > 0 ∃N ∀n ≥ N : d(xN , xn ) < ε. The
  reverse implication uses the triangle inequality through xN and starts with ε/2.
  If a sequence is not Cauchy, fix η > 0 witnessing this. Given a selected term xnk and any
  later cutoff, there are two terms beyond that cutoff at distance at least η. At least one has
  distance at least η/2 from xnk ; otherwise their mutual distance would be below η. Select
  it as xnk+1 . This gives a subsequence with consecutive distances bounded below by η/2.
  Conversely, such a subsequence prevents Cauchyness.

  Pseudo-metrics and quotient spaces (Exercise 6.9)
  A pseudo-metric satisfies the metric axioms except that distinct points may have zero
  distance. Define x ∼ y iff ρ(x, y) = 0. Reflexivity and symmetry are immediate; transitivity
  follows from ρ(x, z) ≤ ρ(x, y) + ρ(y, z) = 0.
  Define d([x], [y]) = ρ(x, y). To check well-definedness, if x ∼ x′ and y ∼ y ′ , then

                        ρ(x, y) ≤ ρ(x, x′ ) + ρ(x′ , y ′ ) + ρ(y ′ , y) = ρ(x′ , y ′ ),

  and the reversed inequality gives equality. Definiteness now holds for equivalence classes;
  other axioms descend from ρ.
  For Riemann-integrable functions with ρ(f, g) = ab |f − g|, functions differing at one point
                                                    R

  can have distance zero. The quotient identifies all pairs with zero integral discrepancy, and
  the displayed integral defines a true metric on these classes.

6.7    Detailed proof: Compact domain makes continuity uniform

  Exam question: Additional practice based on Section 2
  Let K be a sequentially compact metric space and f : K → F continuous into a metric
  space. Prove f uniformly continuous.

  Method: Negate the global claim to obtain two close-input sequences
  Failure of uniform continuity gives one output tolerance that cannot be achieved by any
  single input tolerance. Choosing input tolerance 1/n produces pairs of inputs which are
  increasingly close but whose outputs remain a fixed distance apart.

  Worked model answer
  Suppose f is not uniformly continuous. Then there is ε0 > 0 such that, for every δ > 0,
  some x, y ∈ K satisfy dK (x, y) < δ but dF (f (x), f (y)) ≥ ε0 . For each n choose such xn , yn
  with
                         dK (xn , yn ) < 1/n,    dF (f (xn ), f (yn )) ≥ ε0 .
  Sequential compactness gives a subsequence xnj → p ∈ K. Then

                            dK (ynj , p) ≤ dK (ynj , xnj ) + dK (xnj , p) → 0,

  so ynj → p too. Continuity at p implies f (xnj ) → f (p) and f (ynj ) → f (p). Consequently

                 dF (f (xnj ), f (ynj )) ≤ dF (f (xnj ), f (p)) + dF (f (p), f (ynj )) → 0.

  But these distances are all at least ε0 > 0, a contradiction. Thus f is uniformly continuous.

  Exam tips and common mistakes
  Compactness is applied only to the first sequence. The closeness of each input pair then forces
  the corresponding second subsequence to have the same limit. Independently extracting two
  subsequences could lose the required pairing.

6.8    Proof clinic: Completeness and compactness: keep the logical
       arrows separate

  A complete space need not keep every sequence under control
  Completeness only promises limits for Cauchy sequences. In R, the sequence n has no
  convergent subsequence, but this does not contradict completeness because it is not Cauchy.
  Sequential compactness demands a convergent subsequence from any sequence, so it is
  stronger.
  In Rn , boundedness is strong enough, via Bolzano–Weierstrass, to obtain a convergent
  subsequence in the ambient space. Closedness then retains the limit inside the subset. In
  general metric spaces, boundedness alone does not give that subsequence; total boundedness
  is what provides successively finer finite covers.
  Thus two routes to sequential compactness are available: in finite-dimensional norm metrics,
  closed and bounded; in general metric spaces, complete and totally bounded. Do not silently
  use the finite-dimensional route outside its hypotheses.

  Exam question: Additional practice: classification table
  Classify R, (0, 1), [0, 1] and an infinite discrete space for completeness, boundedness and
  sequential compactness.

  Worked model answer
   Usual     metric      unless   Complete      Bounded      Seq. compact
   stated
   R                                  Yes           No             No
   (0, 1)                              No          Yes             No
   [0, 1]                             Yes          Yes             Yes
   Infinite discrete space            Yes           Yes            No
  For R, use its completeness theorem and the sequence n to disprove compactness. For (0, 1),
  1/n (starting at n = 2) is Cauchy but its only ambient limit is missing. For [0, 1], use
  closedness and completeness, then Heine–Borel. For the discrete example, Cauchy sequences
  are eventually constant but a sequence of distinct points has no convergent subsequence.



6.9    Proof clinic: Recognising when an infimum becomes an attained
       minimum

  Exam question: Additional practice: when a distance infimum is attained
  In the metric space E = (0, ∞) with usual metric, let A = (0, 1] and p = 2. Find the nearest
  point. Then in E = R, give a nonclosed set with a finite unattained point-distance infimum.

  Worked model answer
  For the first case, d(2, a) = 2 − a ≥ 1 for 0 < a ≤ 1, with equality at a = 1. Thus
  dist(2, A) = 1 and it is attained. This shows compactness is sufficient for attainment, not
  necessary in every particular example.
  For the requested unattained infimum in R, let B = (0, 1) and p = 2. Then d(2, b) = 2−b > 1
  for every b ∈ B. Taking bn = 1 − 1/n for n ≥ 2 gives distances 1 + 1/n → 1. Hence
  dist(2, B) = 1 and no point attains it. The missing endpoint prevents attainment.

  A stronger warning in a general metric space
  Even closedness alone need not guarantee a nearest point. On E = {p, a1 , a2 , . . .} define
  d(p, an ) = 1 + 1/n, d(an , am ) = 2 for distinct n, m, and zero on the diagonal. This is a
  metric: the only potentially smaller two-leg route between distinct an , am through p has
  length 2 + 1/n + 1/m > 2; routes from p via another am are longer than its direct distances.
  The subset A = {an : n ≥ 1} is closed because B1 (p) avoids it. Yet dist(p, A) = 1 is not
  attained. The set is not sequentially compact, since its points are uniformly separated. This
  is why the compact attainment theorem carries more information than closedness alone.



6.10     Proof clinic: Two different diagonal arguments

  Do not confuse construction with extraction
  Cantor’s uncountability diagonal changes the nth coordinate of the nth listed object to
  produce a new object absent from a proposed list. The purpose is to show no enumeration
  can be exhaustive.
  The compact-product diagonal extracts the nth term of the nth nested subsequence. It
  produces a subsequence whose tail inherits convergence in every fixed coordinate. The
  purpose is to make infinitely many coordinate requirements hold simultaneously.
  Both inspect a diagonal array, but their logical jobs differ. In the second argument, the
  rows must be nested subsequences. Taking a diagonal from unrelated convergent coordinate
  sequences does not necessarily produce a subsequence of the original product sequence.

6.11.1   Exercise 6.1: Finite sets, unions and intersections

  Exam question: Lecture exercise
  Show finite sets are sequentially compact and the union and intersection of two sequentially
  compact sets are sequentially compact.

  Worked model answer
  If A is finite and (xn ) a sequence in A, some point a ∈ A occurs infinitely often by the infinite
  pigeonhole principle. Select its indices in increasing order to get a constant subsequence,
  which converges to a ∈ A. Thus finite sets are sequentially compact. The empty case is
  vacuous.
  Let A, B sequentially compact and (xn ) a sequence in A ∪ B. Either infinitely many terms lie
  in A, or only finitely many do, in which case infinitely many lie in B. Select a subsequence
  lying entirely in one constituent. Its sequential compactness gives a further subsequence
  converging to a point of that constituent, hence of A ∪ B. Therefore the union is sequentially
  compact.
  For the intersection, start with a sequence in A ∩ B. Since it lies in A, choose a subsequence
  converging to a ∈ A. Sequentially compact B is closed in the ambient metric space. All
  selected terms lie in B, so their limit a lies in B too. Hence a ∈ A ∩ B, proving sequential
  compactness of the intersection.

  Exam tips and common mistakes
  The intersection argument uses closedness of one compact set. It is unnecessary to extract a
  second subsequence, although that alternative also works with uniqueness of limits.


6.11.2   Exercise 6.2: A closest point in a compact set

  Exam question: Lecture exercise
  For nonempty sequentially compact K and p ∈ E, prove there exists c ∈ K with d(c, p) =
  dist(p, K).

  Worked model answer
  Let r = dist(p, K) = inf x∈K d(p, x). It is a finite nonnegative real because K is nonempty
  and distances are finite. By infimum approximation choose xn ∈ K such that

                                      r ≤ d(p, xn ) < r + 1/n.

  Then d(p, xn ) → r. Sequential compactness gives a subsequence xnj → c ∈ K. Reverse
  triangle inequality shows |d(p, xnj ) − d(p, c)| ≤ d(xnj , c) → 0, so this subsequence of distance
  values tends to d(p, c). It also tends to r, since the whole distance sequence does. Uniqueness
  of real limits gives d(p, c) = r, as required.


                                                 97
MATH6310 | Metric Spaces & Topology                                                  Sai Vanam


  Method: Approximate, extract, pass to the limit
  This three-step pattern proves many attainment theorems. The infimum first gives approxi-
  mate minimisers; compactness gives a convergent subsequence; continuity turns its limiting
  value into an actual minimiser.


6.11.3   Exercise 6.3: Continuous functions attain extrema

  Exam question: Lecture exercise
  For continuous f : E → R and nonempty sequentially compact K ⊆ E, prove f attains its
  maximum and minimum on K.

  Worked model answer
  First f [K] is sequentially compact by the continuous-image theorem, and hence bounded.
  Therefore s = sup f [K] and l = inf f [K] are finite reals.
  By supremum approximation choose xn ∈ K with s − 1/n < f (xn ) ≤ s. Thus f (xn ) → s.
  Sequential compactness supplies xnj → q ∈ K. Continuity gives f (xnj ) → f (q). Since the
  same subsequence of values tends to s, uniqueness yields f (q) = s. Thus the supremum is
  attained.
  Apply the same argument to −f , which is continuous. It has a maximiser p ∈ K. Then
  −f (x) ≤ −f (p) for all x ∈ K, which means f (p) ≤ f (x). Therefore

                              f (p) ≤ f (x) ≤ f (q) for all x ∈ K.

  Exam tips and common mistakes
  Nonemptiness is needed for attaining points. The empty set is sequentially compact but
  supplies neither a maximiser nor a minimiser.



6.11.4   Exercise 6.4: Bounded means fitting inside a box

  Exam question: Lecture exercise

  For A ⊆ RN , prove boundedness in d∞ iff A ⊆ [−L, L]N for some finite L ≥ 0.

  Worked model answer
  If A = ∅, choose L = 0. Assume A ̸= ∅ and diam∞ A = D < ∞. Choose a ∈ A. For each
  x ∈ A,
                          ∥x∥∞ ≤ ∥x − a∥∞ + ∥a∥∞ ≤ D + ∥a∥∞ .

  coordinate difference satisfies |xi − yi | ≤ 2L. Taking the maximum gives d∞ (x, y) ≤ 2L, so
  diam∞ A ≤ 2L < ∞. Thus A is bounded.

6.11.5   Exercise 6.5: A convergent sequence with its limit is closed

  Exam question: Lecture exercise
  If xn → a in E, prove C = {a} ∪ {xn : n ∈ N} is closed.

  Method: Separate the tail from the finite beginning
  For a point p ∈
                / C, the limit a is at positive distance from p. Late terms cluster near a,
  leaving room around p. Only finitely many early terms remain to avoid.

  Worked model answer
  Fix p ∈ E \ C. Since p ̸= a, let r = d(p, a)/3 > 0. Choose N such that d(xn , a) < r for all
  n ≥ N . Reverse triangle inequality gives

                      d(p, xn ) ≥ d(p, a) − d(a, xn ) > 3r − r = 2r       (n ≥ N ).

  Every early term is distinct from p, so all distances d(p, xi ) for i < N are positive. Define
                                                                     
                          s = min {r} ∪ {d(p, xi )/2 : 1 ≤ i < N } > 0.

  A point within distance s of p cannot equal a, since d(p, a) = 3r > s; cannot equal a tail
  term, since those have distance above 2r ≥ 2s; and cannot equal an early term, since its
  distance is at least 2s. Hence Bs (p) ∩ C = ∅. Thus every point outside C has a ball outside
  C, so the complement is open and C is closed.



6.11.6   Exercise 6.6: Composition of continuous maps

  Exam question: Lecture exercise
  For continuous f : E → F and g : F → G, prove g ◦ f continuous.

  Worked model answer
  Fix p ∈ E and ε > 0. By continuity of g at f (p) there is η > 0 such that dF (y, f (p)) < η
  implies dG (g(y), g(f (p))) < ε. By continuity of f at p there is δ > 0 such that dE (x, p) < δ
  implies dF (f (x), f (p)) < η. Combining the two implications gives

                             dE (x, p) < δ ⇒ dG (g(f (x)), g(f (p))) < ε.

  Thus the composition is continuous at arbitrary p.
  Equivalently, for open U ⊆ G, (g ◦ f )−1 [U ] = f −1 [g −1 [U ]] is open because each inverse-image
  step preserves openness.

  Exam tips and common mistakes
  Choose tolerances in reverse order: first what g needs in its input, then what f needs to
  achieve that tolerance. This is why η is selected before δ.

6.11.7   Exercise 6.7: The identity theorem

  Exam question: Lecture exercise
  For continuous f, g : E → F , prove their agreement set is closed. Deduce that agreement on
  a dense subset implies agreement everywhere.

  Worked model answer
  Let H = {x ∈ E : f (x) = g(x)}. Take a sequence xn ∈ H converging in E to x. Then
  continuity gives f (xn ) → f (x) and g(xn ) → g(x). Since f (xn ) = g(xn ) for every n, these are
  the same sequence; uniqueness of limits in F gives f (x) = g(x). Therefore x ∈ H, proving
  H closed.
  Now suppose D is dense in E and f = g on D. Then D ⊆ H, so closure monotonicity gives
  E = D ⊆ H = H. Since H ⊆ E already, H = E. Thus f = g on all of E.

  Where you use this result
  It supplies uniqueness of continuous extensions from dense sets, including the extension
  theorem and uniqueness of completion maps. The values on a dense set determine a
  continuous function everywhere.



6.11.8   Exercise 6.8: Diameters of tails

  Exam question: Lecture exercise
  For Xn = {xk : k ≥ n}, prove (xn ) is Cauchy iff diam Xn → 0.

  Worked model answer
  Assume Cauchy and fix ε > 0. Choose N such that d(xj , xk ) < ε/2 for j, k ≥ N . Every
  pair in XN satisfies this, so taking a supremum gives diam XN ≤ ε/2. Since Xn ⊆ XN for
  n ≥ N , diameter monotonicity gives diam Xn ≤ ε/2 < ε for n ≥ N . Thus the tail diameters
  tend to zero.
  Conversely, suppose diam Xn → 0. Given ε > 0, choose N with diam XN < ε. For j, k ≥ N ,
  both xj , xk ∈ XN , so d(xj , xk ) ≤ diam XN < ε. This is exactly Cauchyness.

  Exam tips and common mistakes
  An infinite supremum of numbers strictly below ε may equal ε. Starting with ε/2 makes the
  first implication’s strict final bound safe.

6.11.9   Exercise 6.9: Turning a pseudo-metric into a metric

  Exam question: Lecture exercise
  Let ρ satisfy all metric axioms except that zero need not force equality. Prove x ∼ y
  iff ρ(x, y) = 0 is an equivalence relation, and d([x], [y]) = ρ(x, y) is a well-defined metric.
  Interpret this for integral discrepancy on Riemann-integrable functions.

  Method: Well-definedness must precede metric axioms
  A point of the quotient is an equivalence class, which has many possible representatives.
  Before declaring a distance, prove that changing either representative does not change the
  formula’s value.

  Worked model answer
  Reflexivity holds because ρ(x, x) = 0. Symmetry follows from ρ(x, y) = ρ(y, x). If x ∼ y
  and y ∼ z, triangle inequality gives 0 ≤ ρ(x, z) ≤ ρ(x, y) + ρ(y, z) = 0, so x ∼ z. Thus ∼ is
  an equivalence relation.
  If x ∼ x′ and y ∼ y ′ , then

                        ρ(x, y) ≤ ρ(x, x′ ) + ρ(x′ , y ′ ) + ρ(y ′ , y) = ρ(x′ , y ′ ).

  Interchanging primed and unprimed points gives the reverse inequality, hence equality. The
  formula for d is therefore independent of representatives.
  Its values are finite and nonnegative. It is symmetric because ρ is. Also d([x], [y]) = 0 iff
  x ∼ y iff [x] = [y], giving definiteness on classes. For any third class [z],

                 d([x], [z]) = ρ(x, z) ≤ ρ(x, y) + ρ(y, z) = d([x], [y]) + d([y], [z]).

  Thus it is a metric.
  For Riemann-integrable functions on a nondegenerate [a, b], ρ(f, g) = ab |f − g| is a pseudo-
                                                                            R

  metric. For example f ≡ 0 and g equal to 1 at one point and 0 elsewhere are distinct with
  zero discrepancy. The quotient identifies all functions whose absolute difference has integral
  zero; the distance between their classes is that integral. It is now a true metric because zero
  distance means equality of classes, not equality at every input.

  Exam tips and common mistakes
  Do not confuse a quotient class with a chosen function. The quotient construction deliberately
  treats some different pointwise functions as the same point, repairing the failed definiteness
  axiom.

Appendix I             Minkowski Inequality

  Appendix I: convexity and Minkowski, following the supplied proof
  A function f on an interval is convex if

                      f ((1 − t)a + tb) ≤ (1 − t)f (a) + tf (b) (0 < t < 1).

  For differentiable f , a nondecreasing derivative implies convexity: use the mean value
  theorem on the two subintervals about an intermediate point to compare secant slopes.
  Continuity extends the inequality to included endpoints. In particular u 7→ |u|p is convex
  for p ≥ 1.
  A subset of a vector space is convex if it contains the line segment between every two of its
  points. Linear images, translates, and closures of convex sets are convex; norm balls are
  convex. Coordinatewise convexity gives, when ∥x∥p , ∥y∥p ≤ 1,

                           |(1 − t)xi + tyi |p ≤ (1 − t)       |xi |p + t       |yi |p ≤ 1.
                      X                                    X                X

                       i                                   i                i

  Thus the ℓp unit ball is convex. For nonzero x, y, set a = ∥x∥p , b = ∥y∥p , xb = x/a, yb = y/b.
  Then
                                         x+y       a        b
                                              =       xb +     yb
                                         a+b     a+b       a+b
  is in that unit ball. Homogeneity gives ∥x + y∥p ≤ a + b, which is Minkowski. Zero-
  vector cases are immediate; p = ∞ follows coordinatewise. For complex vectors, use
  |xi + yi | ≤ |xi | + |yi | then real Minkowski on the nonnegative modulus vectors.

  Exam question: Appendix I practice, not an exam prediction
  Use convexity of the unit ball to prove the triangle inequality for ℓp .

  Worked model answer
  If either vector is zero, the inequality is equality. Otherwise write a = ∥x∥p > 0, b = ∥y∥p > 0.
  The normalised vectors x/a, y/b lie in the unit ball. Their convex combination with weights
  a/(a + b) and b/(a + b) is (x + y)/(a + b), so its norm is at most 1. Multiply by a + b to
  obtain ∥x + y∥p ≤ ∥x∥p + ∥y∥p . Convexity of the ball was proved using convexity of | · |p ,
  without assuming the triangle inequality under proof.

Appendix II              Lipschitz Extension Theorem

  Appendix II: extension from a set that need not be dense
  For continuous real-valued functions on a closed subset of a metric space, Tietze’s theorem
  gives a continuous extension, preserving bounds when bounded. The supplied appendix
  treats this as non-examinable.
  For f : A → R with Lipschitz constant L, at one new point p the permitted value z must
  satisfy
                        sup(f (a) − Ld(p, a)) ≤ z ≤ inf (f (a) + Ld(p, a)).
                        a∈A                            a∈A

  The interval is nonempty, since for a, b ∈ A,

                          f (a) − f (b) ≤ Ld(a, b) ≤ Ld(a, p) + Ld(p, b).

  The appendix extends one point at a time and uses Zorn’s lemma to obtain a maximal
  extension, which must have full domain. The optimal Lipschitz constant remains L because
  restriction already attains its supremal ratio.
  An alternative explicit real-valued extension for nonempty A is

                                  F (x) = inf {f (a) + Ld(x, a)}.
                                           a∈A

  It is finite: fixing a0 ∈ A, the expression is bounded below by f (a0 ) − Ld(x, a0 ) and above by
  f (a0 ) + Ld(x, a0 ). On A the Lipschitz inequality and the choice a = x give F = f . Triangle
  inequality gives F (x) ≤ F (y) + Ld(x, y) and the reverse, proving L-Lipschitz continuity.
  Unlike dense extension, extension from a nondense set need not be unique. The real-valued
  target assumption matters.

  Exam question: Appendix II practice: range of possible values
  For A = {0, 2} ⊂ R, f (0) = 0, f (2) = 2, which values at 1 permit a 1-Lipschitz extension?
  What if A = {0} and we allow constant at most 1?

  Worked model answer
  For the first case, the value z must satisfy |z| ≤ 1 and |z − 2| ≤ 1. Hence z ∈ [−1, 1] ∩ [1, 3] =
  {1}. In the second case the sole requirement is |z| ≤ 1, so every z ∈ [−1, 1] works on {0, 1}.
  For example F (x) = x, F (x) = −x and F (x) = 0 are different extensions with Lipschitz
  constant at most 1. This illustrates that nondensity can allow nonuniqueness; it does not
  assert that the optimal constant of the original singleton map is 1 (it is 0).
