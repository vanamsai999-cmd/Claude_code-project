1     How to use this guide

This expanded edition gives plain-English explanations, exam-writing tips, and suggested stepwise
mark allocations. Where a mark total is printed in the source notes it is retained; otherwise allocations
are explicitly illustrative, not official. This guide covers the mathematical definitions, examples and
main theorems in the two supplied documents, then gives worked solutions to all six numbered
Section 0 exercises and all nineteen numbered Section 1 exercises. Exercises repeated inside
the lecture notes are answered in their numbered exercise counterparts; two extra image/difference
identities appearing in the teaching slides are proved with Exercise 1.8. An optional-theory review is
included for Schröder–Bernstein and Zorn’s lemma.

    A good proof-exam strategy

    Write down the definition before calculating. For a metric, check non-negativity/finiteness,
    identity of indiscernibles, symmetry, and the triangle inequality. For an equality of sets, take
    an arbitrary element and show membership in both directions. For a bijection, give an explicit
    inverse and verify both compositions.



2     Section 0: The metric-space cheat sheet

2.1    What is the point of metric spaces?

In R, distance usually means |x − y|. In Rn , it might be straight-line distance. For functions, we may
measure the biggest difference between two graphs, or the total area between them. A metric space
packages all these possibilities into one language. The same proofs of continuity and convergence can
then be used in many settings.

    Metric: learn this precisely

    A metric on a set S is d : S × S → [0, ∞) with, for all x, y, z ∈ S,

                                   (MS1) d(x, y) = 0 ⇐⇒ x = y,
                                   (MS2) d(x, y) = d(y, x),
                                   (MS3) d(x, z) ≤ d(x, y) + d(y, z).

    The codomain [0, ∞) supplies non-negativity and finiteness. The notes also split MS1 into
    MS1a d(x, x) = 0 and MS1b d(x, y) = 0 ⇒ x = y. A metric space is the pair (S, d), not merely
    the set S.

    Think before using the ordinary triangle inequality

    If a distance is defined in cases, split your proof into cases. If it is defined by an integral, use
    |f − h| ≤ |f − g| + |g − h| pointwise then integrate. If it is defined by a supremum, use the same
    inequality then take suprema. If it counts differing positions or set membership, show that every
    difference between the endpoints must appear in at least one intermediate difference.

3.2    Products and the axiom of choice
                                                                  Q
S × T = {(s, t) : s ∈ S, t ∈ T }. An indexed Cartesian product λ∈Λ Sλ consists of all families (sλ )
such that sλ ∈ Sλ for every λ. It has one empty family if Λ = ∅; it is empty if some factor is empty.
Axiom of choice (AC): any indexed family of nonempty sets admits a choice function c(λ) ∈ Sλ . In
a substantial infinite family, choosing one element from each set may require AC.


3.3    Functions, domain, codomain, range

A function f : S → T specifies a value f (s) ∈ T for every s ∈ S. Its range is Ran f = {f (s) : s ∈ S} ⊆ T ,
which can be smaller than its codomain. The notes write the set of maps as F(S; T ).
Useful examples: idS (s) = s; inclusion ι : A ,→ S sends a 7→ a; indicator 1A (s) = 1 on A and 0
otherwise; a constant map sends everything to one fixed point. For finite |S| = n, |T | = m, the number
of maps S → T is mn . An empty domain has exactly one function into every T ; a nonempty domain
has no function into ∅.

   Injective, surjective, bijective

   Injective: f (x) = f (y) ⇒ x = y (different inputs cannot collide). Surjective: every t ∈ T
   has a preimage in S (range = T ). Bijective: both, so every output has exactly one input.
   Composition: (g ◦ f )(s) = g(f (s)): apply the right-hand function first.

A restriction f |A : A → T only changes the domain; a co-restriction f : S → B, Ran f ⊆ B ⊆ T ,
changes the codomain. Inverses: a left inverse g ◦ f = idS implies injectivity; a right inverse f ◦ h = idT
implies surjectivity. Conversely, for nonempty domain the left inverse can be constructed for an
injection; a surjection has a right inverse using choice. A bijection has a unique two-sided inverse.

3.5    Equivalence relations and partitions

An equivalence relation ∼ on S is reflexive (x ∼ x), symmetric (x ∼ y ⇒ y ∼ x), and transitive
(x ∼ y ∧ y ∼ z ⇒ x ∼ z). Its equivalence class is [x] = {y : y ∼ x}; the quotient S/∼ is the set of classes.
Equivalence classes are either identical or disjoint and partition S. Conversely, every partition into
nonempty disjoint blocks gives an equivalence relation: x ∼ y iff they lie in the same block. Example:
m ∼ n when p divides m − n.
Canonical factorisation of a function. The relation x ∼ y iff f (x) = f (y) yields a quotient S/∼;
the map S → S/∼ is surjective, the induced map S/∼ → Ran f is bijective, and Ran f ,→ T is injective.
Their composition is f . This separates the many-to-one, one-to-one, and codomain features of any
map.

3.6   Countability and Cantor

In the notes, a set is countable if it is finite or can be listed by natural numbers; equivalently, it is
empty or is the image of a surjection N → S. Basic facts: subsets of countable sets are countable; finite
products of countable sets are countable; countable unions of countable sets are countable (the general
statement uses choice). Z and Q are countable; a countable infinite set is bijective to N.

   Cantor’s theorem: a major result

   For every set S, there is no surjection S → P(S). The proof assumes a proposed list f : S → P(S)
   and forms D = {s ∈ S : s ∈     / f (s)}. If D = f (a), then a ∈ D ⇐⇒ a ∈  / D, a contradiction.
   Consequently P(N) and the set {0, 1}N are uncountable.


3.7   Orders and optional material

A partial order ≤ is reflexive, antisymmetric and transitive. A total order additionally compares any
two elements. A strict total order < is transitive and satisfies trichotomy: exactly one of x < y, x = y,
y < x. A chain is a totally ordered subset; a maximal element has no strictly larger element in the
poset.
Zorn’s lemma (optional section): If a nonempty partially ordered set has an upper bound for
every chain, it has a maximal element. Under the usual set-theoretic framework, it is equivalent to AC;
it can be used to prove that every vector space has a Hamel basis.
Schröder–Bernstein: If there are injections S → T and T → S, there is a bijection S → T . The
notes explicitly require knowing the statement, but say the proof is not examinable. Its key lesson is
that two injections suffice to prove equality of cardinality.

4     First-principles teaching: understanding the concepts

4.1    How to read mathematical statements

A definition is an instruction for checking whether an object has a property. Read ∀ as “for every” and
∃ as “there exists”. For example, the metric triangle inequality means: no matter which three points
you give me, travelling from the first to the third directly is no longer than travelling via the second. A
single counterexample is enough to disprove a universal statement.
The implication P ⇒ Q does not normally mean Q ⇒ P . To prove P ⇐⇒ Q, prove both directions.
To prove two sets equal, show both inclusions or write a reversible “if and only if” membership chain.
A contrapositive proof proves ¬Q ⇒ ¬P , logically equivalent to P ⇒ Q. A contradiction proof assumes
the negation of the target and derives an impossibility.

    How to earn proof marks

    Give the general arbitrary object first, state the definition you are applying, justify the non-
    obvious step (often triangle inequality, continuity, or an element witness), and explicitly state
    the requested conclusion. An isolated final formula often cannot earn the reasoning marks.


4.2    Metric axioms with small examples

Let S = {a, b, c}. The discrete metric assigns distance 0 from a point to itself and distance 1 between
all distinct points. For a ̸= c, the triangle inequality reads 1 ≤ d(a, b) + d(b, c): at least one leg is 1.
By contrast, the tempting formula d(a, b) = 2 for distinct points except d(a, c) = 5 fails if a, b, c are
distinct and d(a, b) = d(b, c) = 2, because 5 ≰ 2 + 2.
For a metric proof, MS0 verifies a finite nonnegative real value; MS1a verifies d(x, x) = 0; MS1b
verifies that no two distinct points have zero distance; MS2 reverses the arguments; and MS3 compares
the direct and two-leg distances. The first three often take a line each; the triangle inequality generally
needs the most explanation.


4.3    Distances between functions are not all the same

Suppose
R1 2     f (t) = 0 and g(t) = t2 . The integral metric measures total accumulated difference, d1 (f, g) =
 0 t dt = 1/3. The sup metric measures the largest single difference, d∞ (f, g) = 1. A tall, narrow
discrepancy can have a small integral but a large supremum.
For the integral metric’s definiteness, continuity is the central idea: if the function is nonzero even
at one point, it must remain noticeably nonzero throughout a short nearby interval, creating strictly
positive area. For the sup metric, zero supremum forces every single nonnegative difference to equal
zero, and continuity is needed for boundedness, not for that last argument.


4.4    What Hausdorff distance actually measures

Imagine two shapes drawn on paper. Thicken each shape by a radius r, as though tracing with a pen
of thickness r. The Hausdorff distance is the smallest r allowing each thickened shape to cover the
other original shape. This is a distance between sets, not simply between their centres. The proof
technique is a two-stage journey: a point of set L is within δ of a point in J, which is within γ of a
point in K; therefore it is within γ + δ of K.
Take singletons K = {(0, 0)} and J = {(3, 4)}. Their Hausdorff distance is 5, precisely their ordinary
Euclidean distance. This sanity check links the abstract formula back to geometry.

4.5    Symmetric difference as an error detector

A△B lists elements on which the answers to “does this belong to the set?” disagree. On S = {1, 2, 3, 4},
A = {1, 3} and B = {2, 3} disagree about 1 and 2, so their counting distance is 2. The triangle inequality
follows because any membership disagreement between A and C must occur between A and B or
between B and C (possibly both).


4.6    Domain, codomain and range: three different jobs

Consider f : R → R, f (x) = x2 . The domain tells you valid inputs (all reals), the codomain is the
declared target (all reals), and the range is the actual list of outputs ([0, ∞)). This function is neither
injective (since f (2) = f (−2)) nor surjective onto R (negative numbers cannot occur). If the domain is
restricted to [0, ∞) and the codomain to [0, ∞), the same formula becomes bijective. Thus, do not
discuss injectivity or surjectivity without looking at the exact domain and codomain.


4.7    Direct image versus inverse image

For f (x) = x2 on R, the direct image of [−2, −1] is [1, 4]. The inverse image of [1, 4] is [−2, −1] ∪ [1, 2]:
you ask for all inputs whose outputs land in the target set. The inverse image exists even though
the function itself has no inverse. Images need not preserve intersections because different inputs
can collapse to the same output; inverse images always preserve intersections because membership is
checked on the same input.


4.8    Equivalence relations as grouping rules

An equivalence relation is a defensible definition of “belongs in the same group”: every object belongs
with itself (reflexive); if a groups with b then b groups with a (symmetric); and grouping must chain from
a via b to c (transitive). Congruence modulo 3 groups integers by remainder: [0] = {. . . , −3, 0, 3, . . .},
[1] = {. . . , −2, 1, 4, . . .}, and [2] = {. . . , −1, 2, 5, . . .}. These classes partition Z into disjoint nonempty
blocks.


4.9    Why countability is not the same as finiteness

A set is countable when its elements can be arranged into a finite or natural-number-indexed list.
Both N and Z are infinite, but Z is listable as 0, 1, −1, 2, −2, . . .. Rational numbers are also countable,
despite their density on the real line. Real numbers cannot be listed this way. Cantor’s theorem
formalises the key obstacle: the power set P(S) always has strictly larger cardinality than S.

   A miniature proof of Cantor’s theorem

   Suppose a proposed surjection f : S → P(S) lists all subsets of S. Form the diagonal subset
   D = {s ∈ S : s ∈ / f (s)}. If f (a) = D, then a ∈ D ⇐⇒ a ∈/ f (a) = D, an impossibility. No
   surjection can exist.


4.10     Partial orders: a frequent conceptual trap

A partial order need not compare every pair. For example, inclusion ⊆ is a partial order on P({1, 2}),
but {1} and {2} are incomparable. In a total order every pair is comparable. A maximal element has
no strictly larger comparable element; a maximum is at least as large as every element. These words
are not interchangeable.

5    Examination writing: model structures and common pitfalls

Prove a distance is a metric
      State the set and the proposed map, then test MS0, MS1a, MS1b, MS2, MS3 in order. When
      the question asks only for MS3, do not spend most of your answer reproving the other axioms.

Prove a set identity
      Write x ∈ left-hand side, translate symbols into logic (“and”, “or”, “not”, “exists”, “for every”),
      then reconstruct the right-hand side.

Prove injectivity
      Assume f (a) = f (b) and deduce a = b. To disprove it, give distinct a, b with equal values.

Prove surjectivity
      Take arbitrary y in the declared codomain and solve f (x) = y with x in the domain. To
      disprove it, exhibit a target value not achieved.

Show a map is bijective
      An explicit inverse with both compositions verified is particularly clear, but an independent
      injectivity and surjectivity argument also suffices.

Count a collection
      Explain why the enumeration or encoding is exhaustive and why duplicates are impossible
      when claiming a bijection.

Handle an infimum
      Work with admissible numbers within an arbitrary ε > 0 of the infimum; do not automatically
      assume the infimum is attained.

6    Complete worked solutions: Section 0

Exercise 0.1: Discrete metric (10 marks)

Define d(s, t) = 0 when s = t, and 1 otherwise. MS0: values lie in {0, 1} ⊂ [0, ∞), so are finite and
nonnegative. MS1: by its definition d(s, t) = 0 precisely when s = t. MS2: s = t iff t = s, so the
same case applies to d(s, t) and d(t, s). MS3: let s, t, u ∈ S. If s = u, the left side is 0 and the
inequality follows. If s ̸= u, d(s, u) = 1. At least one of s ̸= t or t ̸= u must hold: otherwise s = t = u,

Exercise 1.10: Disjoint union of equivalence relations

Let S = A1 ∪A2 with A1 ∩A2 = ∅. Define x ∼ y if they belong to the same Ai and x ∼i y. Reflexivity:

Exercise 1.15: Total versus strict total orders

(a) From a total order ≤, define s < t iff s ≤ t and s =
                                                       ̸ t. Trichotomy: totality gives s ≤ t or t ≤ s;
if s ̸= t, antisymmetry prevents both, so exactly one strict direction holds. If equal, neither strict
direction holds. Transitivity: s < t and t < u give s ≤ t ≤ u, hence s ≤ u; if s = u, antisymmetry
applied along the chain forces s = t, contradiction. Therefore s < u.
(b) Conversely define s ≤ t iff s < t or s = t. Reflexivity: s = s, hence s ≤ s. Antisymmetry: if s ≤ t
and t ≤ s with s ≠ t, then s < t and t < s, contradicting trichotomy. Transitivity: if s ≤ t ≤ u, cases
involving equality are immediate; otherwise s < t and t < u, hence s < u by strict transitivity. Totality:
trichotomy gives one of s < t, s = t, t < s, ensuring s ≤ t or t ≤ s. Thus ≤ is a total order. □

Exercise 1.19: A set is infinite iff it contains a copy of N

(⇐) If f : N → S is injective, its outputs f (1), f (2), . . . are all distinct. A finite S cannot contain
infinitely many different elements (pigeonhole principle), so S is infinite.
(⇒) Suppose S is infinite. Choose s1 ∈ S. After selecting distinct s1 , . . . , sn , the complement
S \ {s1 , . . . , sn } is nonempty: otherwise S would be finite. Choose sn+1 from this complement.
Recursively obtain distinct elements and define f (n) = sn . Then f is injective. Set-theoretic nuance:
the unrestricted infinite-set-to-injection direction uses a choice principle (typically dependent choice) in
this recursive construction. In standard mathematics with AC, as in these lecture notes, the argument
is valid; without choice, infinite sets need not contain a countably infinite subset. □

8.1    Which method should I use?

“Show this is a metric.” Verify MS0, MS1a, MS1b, MS2 and MS3 separately; use cases, absolute
values, cardinality inclusion, a supremum or integral as appropriate.
“Show two sets are equal.” Start “Take x in the left-hand side” and show it belongs to the right;
reverse direction. Or build a chain of equivalent membership statements.
“Find the range / inverse.” Set y = f (x), solve for x and identify forbidden outputs. If a left inverse
 must be defined outside the range, supply arbitrary legal values there.
“Prove countability.” Exhibit a list/bijection, inject into a known countable set, or express the set as
 a countable union of countable sets.
“Show uncountability.” Use Cantor’s theorem and an injection from a known uncountable set;
alternatively construct a diagonal contradiction.
“Prove equivalence relation.” Check reflexive, symmetric and transitive one by one; if asked whether
 a condition always holds, one valid counterexample is enough to disprove it.
